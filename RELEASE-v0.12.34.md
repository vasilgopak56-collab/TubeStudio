# TubeStudio v0.12.34 — SEO-аудит: запрос до расхода квоты

Продолжение пункта 9 плана vidIQ/NexLev. Шесть локальных наблюдений и методика v1 сохранены: без SEO-балла, реальных позиций YouTube, прогноза CTR или допуска к публикации.

## Добавлено

- Обязательный локальный предпросмотр точных публичных параметров `search.list`: endpoint, запрос, язык, необязательный регион, `relevance`, до 50 видео и `safeSearch=moderate`. API-ключ не показывается и не сохраняется в снимке. ID сопоставления остаётся локальным, в Google не передаётся.
- Хеш связывает сохранённый текст, ID/дату родителя и параметры. Изменение параметров или исходника требует нового предпросмотра; сервер отклоняет устаревший хеш до внешнего запроса. Хеш — контроль согласованности, не подпись подлинности.
- Новые снимки v2 закрепляют показанный запрос рядом с результатами и в JSON. Локальная проверка v2 имеет `request:null`. Сохранённые v1 читаются без перезаписи и без выдуманных сведений о прежнем запросе; интерфейс явно объясняет ограничение архива.
- Уход из раздела отменяет предпросмотр/локальный запрос и предотвращает позднее изменение интерфейса или маршрута. Уже завершённая локальная запись не откатывается и может остаться в истории.
- Повторная проверка открытого файла перед ограниченным чтением; строгие схемы и согласованность v2 при чтении/записи. Повреждённые снимки пропускаются, не становятся фиктивным успехом.

## Расходы и приватность

Предпросмотр, локальный список, история и экспорт не повторяют поиск и не вызывают AI. Сам поиск — отдельная кнопка, одна свежая страница, 100 базовых единиц YouTube; повторы, резервные ключи и общая диагностика могут расходовать квоту отдельно. Порядок строк API не является персонализированной выдачей зрителя, отсутствие ID на одной странице не доказывает отсутствие во всём поиске.

Новых AI/OAuth/MCP/Chrome-прав нет. JSON и общий ZIP содержат введённые тексты и запросы — храните приватно. Файлы 0600 не являются шифрованием. Подробности и HTTP-контракт: `SEO-SEARCH-REVIEW-README.md`.

- **261 браузерный/интеграционный тест — PASS, ошибок 0.** Включая все 12 SEO-сценариев: обязательный предпросмотр, отсутствие расхода до поиска, закреплённый JSON, архив v1, повреждённый v2, отмена, поздние ответы и ZIP-восстановление.

## Обновление

1. Остановить приложение и сохранить резервную копию `.env`, текущего DATA_DIR, пользовательских промптов; дополнительно экспортировать общий ZIP данных.
2. Заменить исходники из архива, не перезаписывая свои секреты и данные. Установить зависимости и собрать приложение обычным способом.
3. v0.12.34 читает архивные SEO-снимки v1 без миграции; новые записи — v2. Для отката хранить резервную копию: старые версии могут не поддерживать v2. JSON отчёта не является отдельным импортом снимка; для переноса хранилища используется общий ZIP.
