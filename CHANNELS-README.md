# Дополнение v0.12.37 — проверяемый запрос сводки

## Порядок работы
1. Подключите или активируйте свой канал. Во вкладке **Каналы** задайте название и период.
2. Нажмите **Предпросмотр сводки**. Локально будут показаны ID/название канала и точный GET к https://youtubeanalytics.googleapis.com/v2/reports: ids=channel==ID, startDate/endDate, dimensions=day, metrics=views,estimatedMinutesWatched,subscribersGained,subscribersLost, sort=day, maxResults=366, startIndex=1. Authorization и секреты не показываются. Нет вызова Google, обновления access token, AI или записи снимка.
3. Проверьте канал и даты, затем отдельно нажмите **Запросить сводку и сохранить**. Изменение названия/дат сбрасывает предпросмотр. После смены подключения требуется новый предпросмотр; при скрытой смене на диске сервер отклонит устаревший запрос до Google.
4. Кнопками остановки отменяйте предпросмотр или получение сводки. Уход со страницы также отменяет задачу. Ранее открытая сводка и файлы сохраняются; незавершённый новый снимок не публикуется. Отмена не гарантирует возврата квоты уже принятого Google запроса. Возможны прежние сетевые повторы при временных ошибках.
5. В новом снимке раскройте **Сохранённый точный запрос сводки**. Экспорты JSON/Markdown и общий ZIP содержат этот запрос, а не текущую несохранённую форму.

## Привязка и формат
Предпросмотр закрепляет выбранные поля, ID/название канала, точные параметры и SHA-256. HMAC-отпечаток локального подключения зависит от refresh credential, channel ID, connectedAt и OAuth Client ID; токены в снимок не попадают. Обновление access token/срока действия не инвалидирует корректный предпросмотр. Это контроль соответствия, не цифровая подпись, проверка прочтения или доказательство подлинности ответа Google. Не публикуйте приватные экспорты.

Снимок version: 2 содержит request с предпросмотром и хешем. Чтение проверяет параметры, хеш и соответствие ID/дат/названия сохранённой сводке. Читается локально и после отключения OAuth. Старые version: 1 без request остаются без изменений; UI/Markdown явно сообщают, что исторический точный запрос не сохранён. Нынешние параметры не подставляются за старые. Остальные расчёты/каталоги/панель и ограничения из разделов ниже сохранены.

## API и совместимость
- POST /api/my-analytics/channels/preview принимает {title,startDate,endDate}; возвращает локальный предпросмотр без Google.
- POST /api/my-analytics/channels/generate принимает те же поля и обязательный previewHash; возвращает jobId, результат/ошибки приходят по SSE. Проверка устаревшего хеша выполняется в задаче до провайдера. Отмена — общий механизм заданий.
- POST /api/my-analytics/channels/runs остаётся синхронным вариантом, но тоже требует previewHash. Старый клиент должен обновиться. Отсутствующий хеш — 400 до постановки задания; устаревший — 409 в синхронном API либо ошибка задания в SSE.
- Прежние APP_PASSWORD и запрет доступа токену Chrome действуют также на новые маршруты; MCP доступ не расширен.

До 366 календарных дней включительно и 366 строк, конец не позже вчера UTC; ни CTR, ни доход, ни результаты A/B этот запрос не получает. Новые scopes не добавлены. Нет автоматических сводок, нескольких одновременно активных каналов или живой проверки Google/Windows. Этот выпуск не закрывает весь пункт 12 дорожной карты.

# Панель сохранённых каналов — v0.12.14

## Как пользоваться
1. Моя аналитика → Обзор: настройте OAuth-клиент и подключите свой канал.
2. Вкладка **Каналы**: задайте название и календарный период; нажмите **Предпросмотр сводки**, проверьте запрос и отдельно нажмите **Запросить сводку и сохранить**.
3. Нажмите **Выбрать другой канал в Google**, подтвердите смену и выберите доступный вам канал. После успешной проверки он заменит активное подключение; прежние снимки останутся. Неудачный/отменённый вход не перезаписывает прежнее подключение. В каждый момент активно только одно OAuth-подключение. Начиная с v0.12.15 его можно отдельно запомнить в локальном хранилище и позже активировать после проверки; см. дополнение выше.
4. Сохраните второй канал за тот же период. В панели выберите сохранённый период либо вручную введите точные даты и нажмите **Показать сохранённые каналы**. Названия могут совпадать: идентичность определяется ID канала.
5. Откройте снимок из панели/истории, экспортируйте JSON или Markdown. Открытие не меняет форму или период панели; несохранённые поля не влияют на экспорт. После редактирования периода панели он применяется только по кнопке.

## Что запрашивается и что считается
Только явный read-only запрос YouTube Analytics API с закреплённым ID активного канала, dimensions=day, metrics=views,estimatedMinutesWatched,subscribersGained,subscribersLost, sort=day, maxResults=366, startIndex=1. До 366 дней включительно, с 2005 года, конец не позднее вчерашнего дня UTC. Часовой пояс Настроек не меняет эти календарные даты. При изменении подключения во время получения данных результат отклоняется без нового снимка. Отказ API не сохраняется как пустая статистика.

Суммы относятся только к возвращённым строкам. Пропуски дней/неизвестные/некорректные числа не заменяются нулями. Приобретённые минус потерянные подписки — разность за эти строки, **не** текущее число подписчиков; отрицательная разность допустима. Пустой ответ не означает нулевую активность. Неполные/переполненные суммы остаются неизвестными. Начальная и последняя возвращённые даты, число дней и дата сохранения показываются, но не доказывают полноту или свежесть API. При 366 строках отдельное предупреждение; следующая страница не запрашивается.

Панель выбирает последний сохранённый снимок на ID канала и точное совпадение обеих дат запроса. Более новый снимок за другой период его не заменяет. Равная дата сохранения разрешается по UUID; порядок каналов — по названию, затем ID, не по результативности. Показатели каналов не суммируются; одинаковые периоды могут иметь различное покрытие и свежесть. Нет рейтинга, роста, общего CTR или автоматического победителя A/B. Экспорт панели фиксирует выбранные снимки/UUID, период, даты сохранения и дату локального чтения; открытие JSON/Markdown не обновляет Google.

## История и пределы
DATA_DIR/yt-channel-runs: отдельные UUID JSON, проверка схемы/сумм/идентичности, файл до 2 МиБ, без symlink. Новые файлы 0600 и новый каталог 0700; Windows защищает ACL, ZIP не гарантирует перенос прав ОС. Файлы не перезаписываются и не удаляются автоматически. История показывает последние 50 всех каналов/периодов; панель читает весь допустимый каталог, а не только эти 50. Каталог периодов показывает последние 100 с предупреждением; более старый точный период доступен ручным вводом. До 50 каналов в панели по названию, с явным числом всех найденных и предупреждением, если больше. При более 5000 UUID-файлов чтение прерывается явной ошибкой, не выдаёт усечённый полный результат. Повреждённые/недоступные файлы помечаются и не удаляются.

Локальные история/фильтры/экспорт доступны после отключения Google. Для свежих данных нужного канала активируйте его сохранённое подключение (v0.12.15) либо снова войдите через Google, затем явно сохраните новый снимок. Нет расписания или автоматического массового обновления. Другие старые отчёты Обзора, географии, дохода и A/B не объединяются автоматически.

## Доступ, стоимость и конфиденциальность
Без AI, платных моделей и финансовых метрик. Используется обычное подключение; новые финансовые права не запрашиваются. Старое подключение с неизвестным scope разрешается для базового отчёта, фактический доступ проверяет API. Выбор аккаунта использует prompt=consent select_account. Google может сохранить ранее выданные разрешения при incremental authorization; эта кнопка их не отзывает. Это не финансовая панель.

Выбор периода и обновление локальной панели не вызывают Google. Только кнопка запроса создаёт новый отчёт; сетевой слой может повторить временную ошибку. Автозагрузка существующего Обзора — прежнее отдельное поведение, не запрос снимков вкладки Каналы.

Новый каталог входит в общий ZIP переноса. Он содержит приватную аналитику и ID каналов, но не OAuth-токены/ключи. **Общий ZIP** может содержать OAuth и другие приватные данные; .env исключён. Передавайте экспорты только доверенным получателям. MCP и ограниченный токен Chrome не имеют доступа к этому каталогу/маршрутам; обычная защита APP_PASSWORD применяется. Отключение Google не удаляет снимки. Для удаления остановите сервер, сделайте защищённую копию и обслужите каталог вручную.

## Что остаётся
Это первый общий экран сохранённых каналов, не полноценная система одновременных OAuth-аккаунтов. Автоматические показы/CTR, получение результатов A/B, массовое обновление и живая приёмка реального канала остаются открытыми. Синтетические тесты не заменяют живой OAuth, Windows/ярлык, установленное расширение и платных провайдеров. Полные результаты локальных проверок — RELEASE-v0.12.14.md.
