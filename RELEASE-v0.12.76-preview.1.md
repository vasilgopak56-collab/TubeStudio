# TubeStudio 0.12.76-preview.1 — независимые подключения помощника

## Новое

Требование независимости от AnyModel внесено в основной план помощника как обязательное. Доступны прежние прямые Anthropic/Gemini/AnyModel и новый текстовый адаптер OpenAI-совместимого Chat Completions. Это не обещание подключить любой существующий API одной формой.

Форма профиля: название, base URL без /chat/completions, Bearer key либо отсутствие авторизации, max_tokens/max_completion_tokens, передача temperature. Сохранение локальное — никаких автоматических метаданных или платной пробы. Внешние сервисы: HTTPS стандартного порта с публичным IPv4/DNS. Локальные: явный HTTP loopback 127.0.0.1/localhost/::1 на компьютере TubeStudio. LAN, внешний IPv6, Responses API, нестандартные заголовки и не-Chat-Completions протоколы пока не поддержаны.

Для ролей помощника выбирается профиль и точный model ID. В предпросмотре вызова показан получатель и точный текст без ключа. Один вызов без скрытого fallback/HTTP retry/JSON-repair/каталога моделей. Сервис может иметь собственную маршрутизацию: TubeStudio не доказывает внутреннюю идентичность модели за шлюзом.

«Сменить модели этого диалога» создаёт по подтверждённому просмотру новую ветку со всей перепиской, файлами, источниками и подходом. История не переписывается, подписи старых результатов сохраняются. Старое подключение может быть уже недоступно или отсутствовать. Миграция локальная, без AI; новые роли применяются только к следующим отдельно подтверждённым вызовам. Лимит 10 ответов не сбрасывается.

## Ключи и сеть

Профили неизменяемые, до 100. Для ротации ключа/адреса создаётся новый профиль. Локальное хранилище .model-connections с файлами mode 0600 на Linux; ключи в открытом виде на диске, не шифрование и не проверка Windows ACL. Приватные профили исключены из обычного ZIP-переноса. На другом компьютере нужно создать подключение и явно переназначить роли. Приложение не возвращает ключи списком/API/AI-просмотром и не добавляет их в сообщения/навыки/localStorage. Не вводите секреты в название профиля, base URL и чат.

Для публичного API проверяются IPv4-адреса DNS, приватные/служебные адреса запрещены; соединение закреплено на проверенном адресе. TLS проверяется штатно, перенаправления не выполняются. Loopback доступен только по явному локальному профилю. Статусные ошибки не пересылают произвольное тело API в UI; ответ до 2 МиБ, HTTP-таймаут 180 секунд. Отмена/таймаут не отзывает уже отправленный запрос; он мог быть оплачен.

Тарифы чужих сервисов не переносятся на новый адаптер. Стоимость совместимого подключения пока неизвестна; режим block останавливает отправку. Подтверждённые тарифы по паре профиль/модель ещё требуют реализации. Локальная модель не считается автоматически бесплатной. Полный финансовый пакет не объявлен завершённым.

## Что не входит

Новый адаптер пока только для текстовых задач встроенного помощника (сценарий, текстовые промпты, уточнения/план). Он не подключён к остальным генераторам программы и не генерирует изображения/голос/видео. Нет редактирования/удаления профилей, автоопределения возможностей, импорта профиля без секрета, автоматического переключения провайдера или универсальных нестандартных API. Эти пункты остаются в плане.

Возможности .74/.75 сохранены: подтверждённые навыки, TXT/MD, отдельные ролики, ограниченные комментарии, необязательные субтитры, проверка цитат и создание нового проекта. Автономного полного цикла, всего канала, PDF/DOCX и обновления существующего проекта из чата пока нет.

Перед обновлением — приватная резервная копия и отдельная распаковка новой версии. Живая приёмка сервиса, качества моделей и настоящей Windows не заменяется локальными тестами. Результаты: LOCAL-CHECK-v0.12.76-preview.1.md. Первый запуск: ASSISTANT-START-RU.md.
