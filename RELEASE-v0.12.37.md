# TubeStudio v0.12.37 — Каналы: проверяемый запрос сводки

## Что изменилось
- Обязательный локальный предпросмотр канала, периода и точного GET YouTube Analytics API перед получением дневной сводки. Без Google, обновления токена, AI и записи файла на этапе предпросмотра.
- Проверка SHA-256 формы/запроса и HMAC-привязки подключения до внешнего вызова. Смена канала, учётных данных или OAuth Client ID требует нового предпросмотра; штатное обновление access token допустимо.
- Снимок v2 хранит исходный предпросмотр/параметры и хеш; JSON/Markdown/общий ZIP сохраняют его независимо от дальнейшего изменения формы или подключения.
- Старые v1 читаются локально без перезаписи: точный исторический запрос не восстанавливается из текущих параметров.
- Получение сводки через отменяемое SSE-задание; остановка предпросмотра и защита от поздних ответов после ухода. Ошибки/отмена не заменяют открытый снимок и не публикуют незавершённый файл.
- Справка и CHANNELS-README.md обновлены. Расчёты, панель и прочая аналитика не менялись.

## Проверки
Проверки v0.12.37: типы и production-сборки трёх workspace прошли; **568 модульных и 278 браузерных/интеграционных тестов**, ошибок 0. Просмотрены предпросмотр и раскрытый сохранённый запрос на экранах 1440/390 px, переполнения страницы нет. Windows — только файловая проверка на Linux, без подтверждения нативного запуска.

Проверены показанные параметры против запроса на границе синтетического Google-провайдера, устаревшие название/даты/ID/credentials, отсутствие хеша, нормальное обновление access token, отмена во время сети/записи, уход и поздний предпросмотр, сбои API, целостность v2, старый v1, отключённый OAuth, JSON/Markdown и настоящий ZIP round-trip. Проверки APP_PASSWORD и запрета Chrome распространяются на новые маршруты. Изолированные тестовые данные и синтетические ответы, без реальных токенов/Google.

## Совместимость и ограничения
Новые /api/my-analytics/channels/preview и /generate; синхронный POST /runs теперь также требует previewHash. Старому клиенту нужно обновление страницы. Схема входа проверяется до постановки задания; устаревший предпросмотр даёт 409 синхронно либо ошибку SSE-задания до Google. Запрос/отпечаток — не цифровая подпись и не доказательство чтения пользователем.

Один активный OAuth-канал; до 366 календарных дней, конец не позже вчера UTC, maxResults=366. Пропуски/неизвестные значения не нули; суммы только по возвращённым строкам. Разность подписок не текущее число подписчиков. Нет нового CTR, дохода или результатов A/B. Сетевые повторы прежние; отмена не возмещает уже принятый Google запрос. Новые OAuth scopes, MCP/Chrome-права, AI, расписание и массовое обновление не добавлены.

Живые Google/OAuth/Reporting и нативный запуск Windows не проверены; файловая проверка Windows на Linux не заменяет их. Весь пункт 12 и вся дорожная карта не закрыты.

## Обновление Windows
1. Завершите задания, остановите сервер и сохраните защищённые копии программы, .env, данных и пользовательских промптов.
2. Распакуйте содержимое tubestudio в существующую папку с заменой файлов, без лишней вложенной tubestudio. Не удаляйте .env, data или apps/server/data.
3. Запустите update-windows.bat, дождитесь успешной сборки, затем Ctrl+F5. Нужен установленный Node.js.

Архив — редактируемые исходники без node_modules, сборок, ключей и пользовательских данных. .env.example — только пример. Отдельные экспорты данных могут содержать OAuth и приватную аналитику; храните их защищённо.
