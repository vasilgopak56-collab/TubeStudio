# Перенос и экспорт сравнения обложек — v0.12.33

Откройте **Обложки → Сравнение в ленте**. Это локальный условный макет, а не настоящая страница YouTube, не A/B-тест, не оценка победителя и не прогноз CTR. Материалы должны быть вашими или разрешёнными.

## Явное сохранение

- **Скачать макет JSON**: `tubestudio-feed.json`, format `tubestudio-feed`, version 1. Включает дату экспорта, свою карточку и до пяти конкурентов, тексты, порядок/позицию, сетку/колонку, светлый/тёмный фон и отметку своей карточки.
- Изображения встроены в JSON как PNG, нормализованные до 1280 px по большей стороне без увеличения. Это не оригиналы: исходные имена, метаданные и URL не переносятся. Размеры в JSON описывают нормализованный растр; после импорта интерфейс показывает их, не размеры исходного файла.
- **Восстановить макет JSON** заменяет текущий черновик после полной проверки всех полей/изображений. Дополнительного подтверждения нет: предупреждение написано у поля. Отмена диалога или ошибка оставляет текущий черновик. Отсутствующая картинка — допустимая пустая карточка, не пропуск записи.
- Формат строгий: неизвестная версия/поля, повторные/некорректные ID, длинные тексты, ссылки HTTP/`/files/`, SVG и неподдерживаемые данные отклоняются. Только встроенный PNG с проверкой сигнатуры, размеров до декодирования, декодированием и повторным растеризованием. Нет выполнения HTML из текстов.
- JSON непустой и до **16 МиБ**, один встроенный PNG до **5 МиБ**, по стороне до **1280 px**. Совокупный предел может быть достигнут раньше, чем лимит шести картинок; уменьшите изображения. Ничего не обрезается и не экспортируется частично. Для исходных загрузок действуют прежние 5 МиБ, 8192 px/20 Мп.

## PNG для просмотра

**Скачать макет PNG** создаёт `tubestudio-feed.png` из состояния на момент нажатия, с изображениями целиком в одинаковых рамках 16:9, выбранным фоном/порядком/отметкой. Пока идёт обработка, редактирование отключено; **Очистить сравнение** остаётся доступно и отменяет применение/скачивание. Уход из раздела также отменяет поздний результат.

- Сетка: до трёх колонок по 360 px, промежутки 20 px, поля 24 px. Колонка: 360 px + поля, PNG шириной 408 px. Ширина экрана не изменяет размер экспортного файла. Неполный последний ряд допустим.
- Заголовки и названия каналов в PNG до двух строк с многоточием. Это отдельный фиксированный экспортный макет, не пиксельная копия адаптивного интерфейса: типографика/скругления могут отличаться. Полные тексты остаются в JSON. Unicode/RTL рисует браузер; набор доступных шрифтов зависит от ОС.
- Пустые изображения остаются подписанными заглушками. На PNG есть постоянная подпись о локальном макете и отсутствии A/B-теста/прогноза. Счётчики, даты публикации и победитель не выдумываются.
- PNG не импортируется как макет: для редактируемого переноса нужен JSON.

## Сеть и приватность

Загрузка своих изображений, импорт JSON и PNG-рендер выполняются в браузере без отправки на сервер. Выбранный ранее вариант проекта в `/files/` читается с того же локального приложения **при явном экспорте**, ограниченно по размеру, без перехода по редиректу. Если медиа удалено/недоступно, показывается ошибка без частичного файла и без замены макета. Произвольных URL, AI/YouTube-вызовов и новых прав нет. Другие разделы приложения работают независимо.

Автосохранения нет. Перезагрузка/уход теряет несохранённый черновик; переключение вкладок Обложек сохраняет его до ухода. localStorage, IndexedDB, DATA_DIR, проекты и общий ZIP не получают макет. Скачанные JSON/PNG — приватные файлы на вашем устройстве, сохраняйте их отдельно от ZIP и исходных изображений. Оригиналы храните отдельно. Служебные object URL освобождаются после обработки/скачивания.

Нет автоподбора конкурентов, публикации/смены обложки на YouTube или измерения кликабельности. Реальная Windows-приёмка, живые провайдеры и весь план не закрыты; исторические PDF/DOCX не пересобраны.
