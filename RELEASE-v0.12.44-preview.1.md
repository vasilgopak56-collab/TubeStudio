# v0.12.44-preview.1 — понятные ошибки Google в Reach Basic

## Что изменилось

В «Моя аналитика → Показы и CTR» вместо одной общей ошибки HTTP добавлена безопасная расшифровка известных ответов Google:
- API выключен в проекте OAuth-клиента;
- токену недостаточно разрешений;
- исчерпана квота или ограничена частота запросов;
- авторизация не принята, ресурс недоступен или у Google серверная ошибка.

Причина определяется только по разрешённым структурированным кодам ответа и совместимому HTTP-статусу. Произвольный текст Google не анализируется и не выводится. Неизвестный или противоречивый HTTP 403 остаётся неизвестной причиной, а не автоматически «API выключен».

Отдельно указан источник: YouTube Data API при проверке принадлежности канала либо YouTube Reporting API при чтении заданий/отчётов и командах. Это не изменение диагностик всех Google-сервисов приложения: обычная Analytics API и обмен OAuth-токенов здесь не переработаны.

Подсказка не включает API, не расширяет права и не восстанавливает квоту сама. Создание/удаление заданий не повторяются автоматически; после неопределённого исхода нужно сначала перечитать список. Новых фоновых запросов, автоматического скачивания CSV, изменения сохранённых снимков и пересчёта CTR нет.

## Защита данных

Ошибка Google читается с ограничением 16 КиБ и 1,5 секунды. HTML, повреждённый JSON/UTF-8, превышение размера, зависший поток и редирект дают безопасную общую диагностику. В API возвращаются только фиксированное русское сообщение и разрешённые поля provider/upstreamStatus/reason/evidence/method. Текст ответа, metadata, project ID, URL, Client secret и токены не возвращаются и этим обработчиком не журналируются. Ошибка остаётся UPSTREAM/502, retryable=false.

- 631 модульный тест, ошибок 0; в том числе 17 новых тестов диагностики.

- Проверены 6 причин через настоящий локальный HTTP-маршрут с подставным Google, количество запросов, отсутствие автоматических повторов, отсутствие секретных маркеров в ответах и неизменность файлов истории.
- На 1440/390 px проверены сообщения, перенос строк, отсутствие HTML-выполнения и горизонтального переполнения. Отдельно просмотрены 4 PNG: выключенный Reporting API и недостаток прав при Data API-проверке канала.
- Проверка файлов Windows на Linux и 7 отдельных сценариев API-переноса данных — пройдены; 42 файла, 28 каталогов, 0 внешних запросов в тесте переноса.

Общий регрессионный прогон: **297 E2E, ошибок 0, пропусков 0**, расширение исключено. Результат записан в PREVIEW-CHECKS.json. Целевые 11 Reach-сценариев входят в общий прогон, не прибавляются к нему повторно. Расширение Chrome исключено по решению пользователя.

## Что ещё не принято

Это preview, а не окончательно завершённая программа. Скриншоты пользователя показывают успешное чтение списка заданий Google, создание одного Reach Basic и отсутствие готовых отчётов сразу после создания. Это не подтверждение загрузки реального CSV, правильности масштаба CTR или восстановления на другой машине.

Открыты: живой отчёт и сверка CTR для одного видео/дня, нативная остановка/обновление/восстановление Windows, платный AI и бюджеты на реальных провайдерах, подключение установленного внешнего MCP-клиента. Ручной A/B-журнал не превращён в автоматический эксперимент. Расширение не разрабатывается. Исторические документы старых версий не переписаны.
