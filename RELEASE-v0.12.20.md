# TubeStudio v0.12.20 — минутный сценарий и живой прогон

## Исправлено
- Сценарист и API pipeline принимают от 60 слов вместо 300. Пресет 120 слов доступен в «Одной кнопке»; для короткого сценария план не навязывает три длинных акта. Слишком малый объём символов отклоняется до запуска платного задания.
- Оценка объёма в подсказке: примерно 120 русских слов в минуту, а не 1500 слов за 1–2 минуты. Фактическое время зависит от озвучки.
- Панель: ограничены ширины grid/card, длинные статусы API переносятся. Проверены 390, 1440 и 1911 CSS px.
- Загрузка версии сценария: явный сохранённый заголовок имеет приоритет над старым заголовком плана.
- Формальная проверка явно отделена от проверки достоверности. Уверенность модели и наличие ссылок не объявляются подтверждением фактов.

## Живой прогон
См. LIVE-ROME-RUN.md. Реальные платные вызовы выполнены в отдельной Linux-установке с предоставленными ключами. Исходники не содержат ключей, проектов, логов или персональных настроек. Материалы проекта поставляются отдельно.

Не проверены этой приёмкой: обновление v0.12.20 на Windows пользователя, OAuth/Reach/Revenue, все прочие инструменты, публикация на YouTube. Скриншот и пользовательский отчёт о запуске v0.12.19 не заменяют этих проверок.
