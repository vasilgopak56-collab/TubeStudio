# Локальная проверка 0.12.76-preview.1

## Итог

- Полный модульный набор: **971/971**, ошибок, пропусков и отмен 0. Адресный помощник/источники/подключения: **62/62**, в том числе 20 новых проверок подключений.
- Единый полный настольный прогон: **448/448**, 41 файл-набор; ошибок, пропусков и отмен 0. Адресный помощник: **18/18**, включая 4 новых сквозных сценария подключения/миграции моделей.
- Production build web/server/MCP, typecheck и статическая проверка файлов Windows прошли. Последняя выполнялась на Linux, не на настоящей Windows.
- Резервный перенос двух установок с перезапуском и повторным импортом: **8/8**, 52 записи, 34 каталога. Источники и переписка сохранились, приватный API-профиль и ключ не попали в ZIP. После переноса подтверждённое переназначение роли сохраняет все материалы и прежние ответы. В серверных процессах этого теста запрещены fetch и исходящие http/https.request.
- Справка и Markdown-руководство: **63 главы**. Старые провайдерские промпты и Chrome-расширение не менялись.

## Подключения

Проверены строгие схемы и явное согласие; локальное сохранение/список без сетевого запроса; отсутствие ключа в ответах API/AI-просмотре/сообщениях/localStorage; mode 0600 приватных файлов на Linux; неизменяемые ID/отпечатки, отсутствие профиля, повреждение/ссылка на файл. Обычный ZIP исключает .model-connections и синтетический ключ не встречается в содержимом записей архива.

Проверены ограничения HTTPS/loopback, запрет URL с credentials/query/hash, запрет LAN/служебных IPv4/внешнего IPv6. Подставной DNS с приватным IP не вызывает HTTP. Для публичного HTTPS тестовый request фиксирует использование проверенного адреса в lookup и точной модели/заголовка; реальный публичный запрос не выполняется. Тесты реального HTTP работают только с изолированным синтетическим loopback-сервером, а не с пользовательским провайдером.

Текстовый контракт: точные messages/model, выбранный параметр max_tokens/max_completion_tokens, возможность не передавать temperature, авторизация Bearer/none. Нет каталога, скрытого fallback и повторов. Redirect не открывается; статусная ошибка с синтетическим ключом в теле не раскрывает его пользователю. Неполный/tool/слишком большой/не-JSON ответ отклоняется без повторной генерации. Отмена до отправки не делает HTTP, отмена во время завершает вызов без автоматического повторения. Режим block с неизвестным тарифом останавливает отправку. Чужие тарифы не присваиваются новому подключению.

## Переназначение моделей

Локальный предпросмотр, stale hash, подтверждение, повтор той же операции. Новая ветка сохраняет контекст и полную переписку; подпись старого результата не подменяется новой моделью. Отсутствующий старый профиль не мешает явной миграции. Следующий AI-вызов требует отдельного просмотра и согласия; получает первоначальные документы и прежние ответы.

UI через настоящие HTTP/API/SSE: сохранить профиль без генерации; очистить поле ключа; выбрать профиль для роли; увидеть получателя; выполнить ровно один запрос к синтетическому совместимому API; сменить модель с подтверждением без генерации; продолжить диалог без потери материалов. Смена полей снимает подтверждение. Тёмная тема 1440 и светлая 1024: снимки просмотрены, pageerror и горизонтального переполнения нет.

## Честные ограничения

Внешние провайдеры и реальные ключи не использовались. Публичный HTTPS транспорт проверен подставным request/DNS, локальный HTTP — настоящим соединением к тестовому серверу. Это не живая приёмка API, TLS конкретного сервиса, качества модели, внутренней маршрутизации шлюза или корпоративного прокси. Автономного полного цикла нет. Новый адаптер только для текстовых задач помощника, не для остальных генераторов/картинок/голоса/видео. Произвольные протоколы и заголовки, Responses API, LAN/внешний IPv6 и управление/удаление профилей остаются в плане.

Ключи на диске не зашифрованы. Windows ACL, запуск на настоящей Windows, сетевые/FAT-файловые системы, сбои питания/диска не приняты. Стоимость совместимого подключения остаётся неизвестной, block запрещает запросы. Финансовый пакет не объявлен завершённым. Локальное подключение само по себе не доказывает бесплатность.

Первый адресный прогон обнаружил, что строгая схема Message ещё не разрешала два поля происхождения совместимой модели. Добавлены только известные connectionId/connectionHash, строгий запрет остальных полей сохранён; затем весь адресный и полный наборы выполнены заново. Предварительная ошибка типов по autoSelectFamily исправлена использованием family и корректного callback lookup без неподдерживаемого поля типов; проверки IP/TLS не ослаблены.

Первый общий настольный прогон дал 447/448: тест редактора промптов читал файл до завершения сохранения, ожидая уже видимую строку истории. Исправлен только тест: он ждёт текст выбранного файла, успешный PUT и сообщение «Сохранено». Проверка наличия правки в файле, запрет потери переменных и откат к заводской версии не убраны. Производственный редактор и промпты не менялись. После адресной проверки весь настольный набор заново выполнен с начала; финальный результат не склеен из разных запусков. Диагностический лог сохранён отдельно.

Второй общий прогон выявил гонку новой формы: сброс подтверждения через useEffect мог запаздывать после изменения адреса. Исправлен производственный интерфейс: общий обработчик полей синхронно снимает согласие при каждом изменении; фоновый эффект удалён. Сквозной тест усилен: проверяет адрес, название и ключ, а также отключённую кнопку сохранения. После новой сборки и адресного набора весь настольный набор выполнен ещё раз с начала. Оба предварительных диагностических лога сохранены, финальные результаты не объединены.
