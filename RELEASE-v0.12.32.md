# TubeStudio v0.12.32 — транскрипты: точный предпросмотр до AI

## Этап плана

Продолжение пункта 7. Перед summary/remix — локальный предпросмотр точных system/user и обязательный previewHash. Изменение источника, формы, языка или промпта отклоняет устаревший контекст до LLM. Новый AI-снимок хранит запрос и фактическую модель; старый помечается архивным без выдуманного происхождения. Отправляется исходный текст, не прежний AI-ответ и не несохранённый ввод.

Скрытый JSON-repair отключён; сетевые повторы/резервные модели по общим настройкам остаются возможными. Невалидный ответ не создаёт снимок. Ограниченное чтение/схема/безопасные ссылки, приватная атомарная запись и отмена при уходе со страницы. История/JSON/Markdown/ZIP остаются локальными; новых OAuth/MCP/Chrome-прав нет.

## Совместимость и ограничения

Формат version:1 расширен необязательным request. Старые валидные снимки читаются без перезаписи, повреждённые/небезопасные пропускаются. API analyze без previewHash теперь отклоняется: сначала preview. История остаётся массивом, без отдельного счётчика пропусков. Контроль размера 4 МиБ/снимок и 5000 файлов; нет шифрования.

Неофициальные субтитры хрупкие; ручной TXT/SRT/VTT остаётся основным резервным путём. Нет распознавания аудио, внешнего фактчекинга, гарантии прав/оригинальности и точного объёма. Предпросмотр не замораживает цены/маршрутизацию модели. PDF/DOCX не пересобраны. Подробности: TRANSCRIPT-REVIEW-README.md.

## Обновление

Архив содержит исходники, не готовый Windows-бинарник. Остановить сервер/задачи, защищённо сохранить .env, DATA_DIR и промпты. Копировать содержимое tubestudio в существующую установку, без вложенной второй папки и без замены своих данных/секретов. Запустить update-windows.bat по WINDOWS-CHECK-README.md. ZIP данных проверять сначала в отдельной тестовой установке. Живая приёмка — LIVE-ACCEPTANCE.md.
