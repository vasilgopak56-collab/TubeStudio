# Анализ комментариев — v0.12.26

**Исследование → Комментарии** (`/comments`). Два отдельных действия: загрузить проверяемую выборку без AI, затем явно отправить показанный контекст модели. Старый архив сохранён, но его прежние проценты/портрет/цитаты не подтверждены полной сохранённой выборкой.

## Работа
1. Вставьте ссылку или ID одного опубликованного видео. Выберите до 20/50 корневых комментариев и порядок `relevance` либо `time`. Каналы в новом режиме не поддерживаются. Переход из другого раздела только заполняет форму; `auto=1` не запускает загрузку.
2. Нажмите **Загрузить выборку (1 ед.)**. Это одна свежая страница `commentThreads.list`, `part=snippet`, `textFormat=plainText`. Ответы в ветках, следующая страница и дополнительные метаданные не запрашиваются; кеш не используется. Новая кнопка — новый запрос.
3. Раскройте сохранённые тексты. Пустые пропускаются, остальные ограничены 800 единицами UTF-16 с отметкой сокращения; последний неполный surrogate не сохраняется. Имена авторов и ответы в ветках не сохраняются. Личные сведения могут остаться внутри самих текстов.
4. Выберите язык и необязательный фокус до 300 единиц UTF-16, нажмите **Предпросмотр AI-запроса**. Он локальный: показывает точные `system` и `user`. В контексте — тексты, ID комментариев, даты/лайки, ID видео, параметры и время выборки, фокус. Это не автоматическое обезличивание.
5. Нажмите **Разобрать показанную выборку (AI)**. Смена формы, промпта или исходника требует нового предпросмотра. Модель присваивает каждому C1–C50 одну метку: положительная, нейтральная, отрицательная, смешанная, неясная; предлагает до 8 тем и 1–5 идей. Программа проверяет структуру, полноту меток, существование ссылок и отсутствие повторов ссылок/названий, но не истинность смысла. Скрытого AI-исправления ответа нет.
6. Раскройте исходные тексты под меткой/темой/идеей; ссылка ведёт к комментарию на YouTube. Текст берётся из снимка, не из цитаты модели. Удалённый/скрытый комментарий может уже не открыться. **Открыть тему в Сценаристе** заполняет тему, не запускает AI.

## Ограничения выводов и стоимости
Это ограниченная страница ответа API, не все комментарии, не аудитория и не репрезентативный опрос. Наличие следующей страницы показывается; её отсутствие не доказывает полного охвата. Неизвестные лайки не становятся нулём. Лайки не используются как веса опроса. Показаны количества AI-меток, не проценты зрителей. Сарказм/спам/язык могут быть поняты неверно; ссылки подтверждают наличие текста, не его истинность. Идеи — гипотезы, не измеренный спрос, не прогноз просмотров и не проверка фактов/прав.

Одна страница — **1 базовая единица YouTube**; общие повторы и резервные ключи могут увеличить расход. AI оплачивается отдельно по действующим настройкам модели/токенов, бюджета, очереди, повторов и резервов. Отмена не возвращает уже понесённые затраты. Общая диагностика ключей приложения может независимо вызывать Google и минимальный запрос текстовой модели; настроенный трекер работает отдельно. Открытие приложения не следует считать гарантированно бессетевым.

## Хранение и совместимость
- Успешные выборки и разборы — разные UUID-файлы `comment-samples` / `comment-reviews`. Разбор включает полный использованный снимок, точный запрос, хеш, ответ и фактическую модель. Хеш обнаруживает несовпадение контекста, но не доказывает подлинность и не является цифровой подписью.
- JSON закреплён за видимым сохранённым объектом, а не текущей формой. Новый результат не переписывает прежние файлы. Ошибка/невалидный ответ/отмена до фиксации не заменяют прежний результат. После успешного сохранения остановка не является удалением результата.
- История показывает последние 50 каждого типа, не удаляя старые файлы. Повреждённые/неподдержанные/символические ссылки пропускаются со счётчиком. Размер снимка до 512 КиБ. При более 5000 элементов каталога историю нужно разгрузить при остановленном сервере.
- Запись через временный файл; режимы файла/каталога 0600/0700 там, где ОС поддерживает. Не шифрование и не гарантия Windows ACL. JSON/ZIP содержат тексты и ID; храните приватно. Общий ZIP может включать и другие приватные данные/OAuth — см. BACKUP-README.md.
- Общий экспорт/импорт данных переносит оба каталога и редактируемый `comment-review/review.md`. Старые `comment-runs` сохранены в «Архиве прежних анализов» с предупреждением. Старый `/comments` API оставлен для совместимости, новая страница его не вызывает. Настройки прежнего анализа не управляют новой формой. Старые сохранённые отчёты автоматически не пересчитываются.
- Новые HTTP-маршруты `/comment-review/*` наследуют пароль приложения, Chrome-токен к ним не допущен; новых прав OAuth/MCP нет. Тело POST ≤8192 байт. Пустая выборка сохраняется, но AI для неё недоступен.

## Приёмка
Синтетические тесты не заменяют реальный Google/AI и Windows. Новая живая загрузка, качество реальной классификации, обновление Windows и пользовательское восстановление ZIP ещё не проверены. Пункт 6 реализован в ограниченном двухэтапном режиме, а не как полный анализ всех зрителей/канала. Весь план, CTR Reporting и автоматические результаты A/B этим выпуском не закрыты.
