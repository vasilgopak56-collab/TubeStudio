# TubeStudio v0.12.36 — AI Coach: проверяемый запрос

## Что изменилось
- Локальный обязательный предпросмотр system/user до каждого AI-вызова, без автоматической генерации.
- Вопрос, язык, ID снимка, контекст, вся переписка и текущий промпт входят в проверку SHA-256. Отказ при устаревшем предпросмотре до провайдера; это не цифровая подпись или подтверждение прочтения.
- Запрос последнего успешного ответа хранится в lastRequest нового снимка и не зависит от дальнейшего редактирования промпта/источников. Фактическая модель сохраняется в сообщении ответа.
- Старые диалоги version: 1 без lastRequest остаются читаемыми. UI/Markdown явно отмечают отсутствие исторического запроса, не подставляют текущие инструкции.
- JSON/Markdown и общий ZIP-перенос сохраняют lastRequest; новый JSON не предназначен для отдельного импорта через Coach.
- Отмена предпросмотра и AI; защита от поздних локальных/AI-ответов после ухода. Ошибка/отмена не очищает вопрос, не добавляет неполную пару и не перезаписывает исходный снимок.

## Проверки
типы и production-сборки трёх workspace прошли; **561 модульный и 273 браузерных/интеграционных теста**, ошибок 0. Просмотрены экраны 1440/390 px: предпросмотр и сохранённый запрос

Проверены точный payload на границе синтетического провайдера, обновление вопроса/языка/промпта, ветки, старый архив, сохранение после удаления источника, экспорты, настоящий ZIP round-trip, ошибки, отмена и уход. Изолированные данные, тестовый провайдер вместо живого AI; внешние сетевые вызовы в тестах заблокированы. Глобальная диагностика моделей отдельно от Coach-запросов.

В регрессионном тесте транскриптов устранена гонка EPIPE: ранний отказ HTTP 413 теперь проверяется по завышенному Content-Length без одновременной отправки большого тела. Рабочий API транскриптов не менялся.

## Ограничения и совместимость
API /api/coach/ask теперь требует previewHash. /api/coach/preview готовит запрос без AI и записи снимка; старый клиент должен обновить страницу. Проверка stale hash выполняется внутри задания, ошибка приходит по SSE.

Лимиты прежние: 8 ответов; вопрос 3–4000 символов после trim; JSON контекста до 22 000; system+user до 60 000; ответ до 10 000. Нет скрытого урезания истории или повторной «починки» ответа. Провайдер/модель, общие резервы, бюджет и сетевые повторы действуют на момент вызова; предпросмотр не фиксирует стоимость. Уже принятый платный вызов отмена не возмещает. Сохраняется только запрос последнего ответа каждого снимка; для более раннего откройте его снимок.

Новых OAuth/MCP/Chrome-прав, расписания, фонового AI, live YouTube, поиска, файлового доступа или записи ответов в проект нет. Советы модели и старые AI-планы не являются проверенными фактами. Исходный набор возможностей/открытые пункты плана этим выпуском не закрыты.

## Обновление Windows
1. Дождитесь завершения заданий, остановите сервер и сохраните резервную копию программы, .env, данных и пользовательских промптов.
2. Распакуйте содержимое папки tubestudio в существующую папку с заменой файлов, не создавайте лишнюю вложенную tubestudio. Не удаляйте .env, data или apps/server/data.
3. Запустите update-windows.bat и дождитесь успешной сборки, затем Ctrl+F5 в браузере. Нужен установленный Node.js.

Архив — редактируемые исходники без node_modules, сборок, ключей и пользовательских данных. .env.example содержит только пример. Передача самого архива данных и экспортов может раскрывать переписку и OAuth — храните приватно.
