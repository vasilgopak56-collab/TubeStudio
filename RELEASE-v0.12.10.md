# TubeStudio v0.12.10 — Chrome MV3 1.1.0

## v0.12.10 — расширение Chrome MV3 1.1.0

- Пункт 16 плана: бейджи в поиске/каналах и панель видео. Запросы метрик только по явной кнопке; пакеты до 50 ID, базы до 20 каналов, кэш и объединение одинаковых параллельных запросов.
- VPH подписан как средний с публикации. Для Outlier — медиана других последних видео того же приблизительного формата старше 48 часов, минимум 3 значения; отсутствующая база остаётся неизвестной. Среднее канала — отдельный явно подписанный режим.
- Сохранение темы создаёт связанный проект (совпавшее название возвращает существующую тему). Переходы только открывают формы без авто-AI; трекер открывается без автоматического добавления канала.
- Токен расширения ограничен ping, метриками и сохранением темы. Хранится локально в профиле Chrome, не Sync; не шифрование. API-ключи не нужны расширению. ZIP собирается только из 11 разрешённых файлов.
- Обновите и сервер, и прежнюю папку расширения, перезагрузите его карточку и вкладки YouTube. Руководство: EXTENSION-README.md, примечания: RELEASE-v0.12.10.md.
- Синтетические локальные тесты не заменяют приёмку установленного Chrome MV3, живого YouTube и Windows. Весь план ещё не завершён; PDF/DOCX v0.11 не пересобраны.

## Обновление без потери данных

1. Дождитесь окончания задач. Сохраните резервную копию всей рабочей папки, `.env`, фактической `DATA_DIR` и своих промптов. ZIP-экспорт данных не содержит `.env`; архив данных может содержать приватные тексты и OAuth-токены — не публикуйте его.
2. Остановите сервер TubeStudio. Распакуйте полный архив исходников отдельно и скопируйте **содержимое** папки `tubestudio` в существующую папку программы с заменой файлов. Не создавайте вложенную папку `tubestudio/tubestudio`. Не удаляйте свои `.env` и данные; в архив они не включены.
3. Если вы изменяли исходники или промпты, сначала сравните свои изменения с новой версией: копирование с заменой может их перезаписать. `.env.example` — пример, не замена действующей `.env`.
4. Windows: запустите `update-windows.bat` и дождитесь успеха установки зависимостей и сборки. Node.js 20+ должен быть установлен. Для других систем: `npm install`, `npm run build` из корня, затем обычный запуск. Веб-страницу обновите с Ctrl+F5.
5. Обновите файлы в **прежней папке установленного расширения**: либо из `extension` полного архива, либо из отдельного ZIP 1.1.0. В `chrome://extensions` нажмите «Обновить» на карточке TubeStudio и перезагрузите вкладки YouTube. Не создавайте вторую копию.
6. В окне расширения проверьте адрес сервера и при необходимости токен из веб-программы. Смена `APP_PASSWORD` меняет токен. Старому расширению больше не разрешено обращаться к произвольным API через токен: нужен комплект новой версии.

Исходники доступны для редактирования в VS Code, Cursor и других редакторах: откройте корень `tubestudio`, содержащий `package.json`. Полный ZIP не включает установленные зависимости и `dist`; требуется установка/сборка. Отдельный ZIP расширения готов для распакованной установки и не заменяет сервер.

## Проверки текущего выпуска

- Проверка типов всех трёх workspace и production-сборка прошли.
- Все 219 модульных тестов прошли, включая 13 новых проверок расширения: валидация пакетов, медиана/форматы/возраст/неизвестные значения, средний VPH, нули, URL, список API-действий, переходы без auto, отправитель сообщений, миграция токена, объединение параллельных запросов, предел баз и кэш при изменении настроек.
- Все 92 браузерных/интеграционных теста прошли, включая 8 новых проверок расширения: синтетический YouTube DOM, ручная загрузка, безопасный текст, настоящее локальное сохранение темы/проекта, ручные пакеты 50+20, смена превью и SPA, ошибки/повтор, мобильные 390 px/Справка, ZIP из 11 файлов, окно настроек и настоящий HTTP-доступ ограниченного токена.
- Проверки выполнялись на искусственных временных данных. Реальные ключи, Drive-файлы и платные провайдеры не использовались. Это локальная регрессия, не живая приёмка всех разделов.
- Установленный Chrome MV3, текущий YouTube DOM, Windows/ярлык, живые API и OAuth не проверены. PDF/DOCX v0.11 не пересобраны. Сборка успешна; предупреждение Vite о крупном чанке Справки сохраняется.

## Что не подтверждено

Это не завершение всего плана. Локальные моки не доказывают работоспособность текущего YouTube DOM, установленного Chrome MV3, optional permissions, Windows-ярлыка или живых провайдеров/OAuth. Реальные ключи и предоставленные Drive-файлы не использовались. Крупный чанк Справки остаётся предупреждением сборки. Исторические PDF/DOCX v0.11 не пересобраны.
