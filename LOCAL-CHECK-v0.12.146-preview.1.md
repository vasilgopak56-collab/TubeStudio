# Локальные проверки v0.12.146-preview.1

Среда: Linux; данные изолированные и подставные. Это не приёмка на Windows и не проверка реального платного провайдера.

- До исправления на исполняемом сервере .145 воспроизведены два отказа: мягкая остановка и SIGTERM могли считать сервер чисто остановленным после разрыва клиента, пока локальный обработчик не завершился. Отдельная локальная задержка файлового чтения не выполняла сетевых запросов.
- После исправления прошли проверки: мягкая остановка отказывает до окончания отключённого обработчика и сохранения; сигнал при таком обработчике оставляет блокировку; два отключённых обработчика удерживают блокировку до завершения обоих.
- TypeScript для сервера, веб-интерфейса и MCP — пройден. Production build — пройден; сборщик предупреждает о крупных веб-бандлах.
- Модульные тесты: 1456 пройдено, ошибок 0. Целевые интеграционные/desktop-тесты: 21 пройден, ошибок 0. Это не полный E2E приложения. Проверены восстановление аудиораскадровки, разрешения, блокировка и остановка на изолированных данных.
- Статическая проверка файлов Windows пройдена на Linux; настоящий PowerShell, обновление приложения, Windows ACL и работа пользовательской установки на Windows не проверены. Реальные AI-запросы, списания и восстановление пользовательских данных не выполнялись.
- Отслеживается обещание серверного обработчика и HTTP-ответ; произвольная отсоединённая фоновая работа и дочерние процессы не гарантированно отслеживаются. Подробности и переход — RELEASE-v0.12.146-preview.1.md.
