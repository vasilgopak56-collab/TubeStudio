# Локальные проверки 0.12.138-preview.1

Проверки выполнены на Linux с Node 24, FFmpeg и искусственными данными; реальные ключи и платные запросы не использовались.

- `npm run typecheck` и `npm run build`: успешно. Сборщик предупредил о крупном главном JS-бандле; скорость не измерялась.
- `npm run test:unit`: 1426/1426. Новые проверки: реальное декодирование коротких примеров всех восьми расширений, отклонение HLS/concat-содержимого, переименованного во все восемь расширений, и отклонение MP3 под именем WAV. Это не доказательство безопасности произвольных медиа или всех версий FFmpeg.
- Выборочная desktop-регрессия: 68/68. В ней отмена подтверждения и отсутствие запуска/сохранения черновика, успешные имитированные платные действия, прежние проверки аудио, копирования, справки, версии, а также действующего блока тарифов и отдельного протокола согласия. Полный desktop-набор не запускался.
- `npm run check:windows`: проверка структуры файлов запуска прошла. Нативное приложение и FFmpeg в Windows не запускались.
- Не проверены: поведение FFmpeg в песочнице (она не реализована), все кодеки и версии FFmpeg, реальные цены, фактическое списание и живой AnyModel. Прямой API не требует подтверждения из интерфейса, резервирование бюджета не добавлялось.
