# TubeStudio v0.12.13 — оценочный доход

## v0.12.13 — оценочный доход своего OAuth-канала

Моя аналитика → **Доход**: отдельное opt-in финансовое разрешение Google, явный запрос дневных views / estimatedRevenue / estimatedAdRevenue в USD, период до 366 дней. Не окончательная выплата и не прибыль; реклама уже входит в общий доход и не складывается с ним. Неизвестные значения и пропущенные дни не подменяются нулями.

Отдельные неизменяемые снимки, история последних 50, Markdown/JSON сохранённого результата и общий ZIP-перенос. История доступна после отключения OAuth. MCP и токен Chrome не получают доступа к финансовым снимкам. Отказ API не сохраняется как нулевой доход; изменение подключения во время запроса отклоняет результат.

Подробности: REVENUE-README.md, RELEASE-v0.12.13.md. Пункт 12 остаётся частичным: автоматические CTR/показы/результаты A/B, многоканальная панель и живая приёмка своего OAuth-канала не завершены. Весь план не закрыт. Исторические PDF/DOCX v0.11 не пересобраны.

## Проверки

- Проверка типов всех трёх workspace и финальная production-сборка прошли.
- Все 278 модульных тестов прошли, включая 23 новых: даты/границы, named-column projection, суммы без двойного счёта, отрицательные корректировки, неизвестность/нули, повреждённые/повторные дни, предел 366, строгие сохранённые суммы/UUID/версии, файлы/ссылки/размеры, история 50/предел 5000, backup-категория, отсутствие внешних запросов без scope, фиксированный запрос/канал/USD, неизменяемость/0600, отказ API, смена подключения, opt-in scopes, одноразовый state/TTL, отказ/невалидное повышение OAuth без перезаписи, фактически выданные разрешения, refresh/downgrade и гонка отключения.
- Все 117 браузерных/интеграционных тестов прошли, включая 9 новых: блокировка без финансового разрешения, явное согласие/реальный локальный callback/частичный grant, ручной денежный запрос/отрицательные корректировки/пропуски/Unicode, сохранённые JSON/Markdown, отказ API без потери результата, пустые/нулевые/неполные ответы, валидация HTTP/лимиты, пароль и запрет Chrome-токена, локальная история после отключения, мобильные 390 px/Справка и настоящий ZIP export → import. После последних текстовых уточнений финальная сборка повторно проверена всеми 16 тестами MCP и дохода; все прошли.
- Новые тесты используют временные искусственные данные и блокируют внешние запросы сервера. Реальные ключи и Drive-файлы не использовались. Не проверены живой OAuth/доход реального монетизированного канала, Windows/ярлык, установленное MV3 и платные провайдеры.
- Это локальная регрессия, не живая приёмка всей программы. Исторические PDF/DOCX v0.11 не пересобраны. Предупреждение Vite о крупном чанке Справки не мешает успешной сборке.
