# Проверка TubeStudio v0.12.46-preview.1 на Windows

Сначала проверьте новую версию отдельно. Рабочую v0.12.45 на 8787 пока не заменяйте.

Архив исходников не является вашей резервной копией. В нём нет ваших ключей и данных.

## 1. Подготовка

1. Сохраните ранее проверенный ZIP с данными. Не загружайте его в чат: он может содержать OAuth-токены и приватный контент.
2. Если старый тестовый экземпляр на 8788 ещё работает, завершите его через Ctrl+C в его окне CMD и закройте окно. Рабочий 8787 не трогайте.
3. Распакуйте новый архив так, чтобы файл package.json находился здесь:
   `C:\TubeStudio-0.12.46-test\tubestudio\package.json`.
4. Не копируйте в тестовую папку старый node_modules, .env или data. Не запускайте start-windows.bat / update-windows.bat: они могут изменить основной ярлык.
5. Откройте новое обычное окно CMD. Node.js 24.19.0 подходит; проверка: `node -v`.

## 2. Установка и сборка

```bat
cd /d C:\TubeStudio-0.12.46-test\tubestudio
npm ci
npm run build
```

Команды выполняйте последовательно. При ошибке остановитесь и пришлите текст ошибки; не применяйте npm audit fix --force. Ожидается отсутствие известных уязвимостей на дату подготовки сборки; база npm со временем меняется. Предупреждение о funding не является ошибкой.

Сборка должна завершить web, server и mcp. Если npm требует проверки install scripts, не разрешайте все скрипты вслепую — пришлите предупреждение.

## 3. Изолированный запуск

В том же окне CMD:

```bat
set "PORT=8788"
set "HOST=127.0.0.1"
set "DATA_DIR=C:\TubeStudio-0.12.46-test\data"
set "PROMPTS_DIR=C:\TubeStudio-0.12.46-test\tubestudio\apps\server\prompts"
set "ENV_FILE=C:\TubeStudio-0.12.46-test\absent.env"
cd apps\server
node dist\index.js
```

Убедитесь, что файл `C:\TubeStudio-0.12.46-test\absent.env` не существует. Эти переменные действуют только в данном CMD. Не используйте setx. Откройте http://127.0.0.1:8788 — рядом с логотипом должна быть версия v0.12.46-preview.1, без предупреждения о несовпадении сервера и интерфейса.

Отсутствие ключей в чистом тестовом экземпляре ожидаемо. Вводить ключи для этой проверки не надо.

## 4. Проверка на копии данных

1. На 8788 откройте Настройки → Импорт из ZIP и выберите ранее проверенную резервную копию.
2. После успешного импорта остановите сервер Ctrl+C и снова выполните `node dist\index.js` в том же CMD.
3. В истории калькулятора откройте прежний расчёт: прибыль 200 $, доход 250 $, затраты 50 $, окупаемость 20 000 просмотров. Сверьте прежнее время сохранения.
4. В истории «Моя аналитика → Показы и CTR» откройте прежний Reach: 0 строк, показы «неизвестно», открытие без вызова Google.
5. Нажимать «Подготовить отчёты в Google», заново подключать YouTube или запускать AI не нужно.
6. При желании проверьте на тестовой копии календарь: смена только названия не должна менять статус, формат и напоминание.

После проверки остановите тестовый сервер Ctrl+C и закройте CMD. Основной экземпляр и ярлык не менялись. Решение о замене рабочей установки принимаем после результата этой проверки.

Проверка этих двух записей не доказывает целостность всех остальных файлов или работоспособность живого OAuth.
