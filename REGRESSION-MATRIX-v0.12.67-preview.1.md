## Исключено намеренно

- Мобильные окна, мобильные меню и разработка мобильной версии.
- Живые платные/внешние API, настоящий Google-вход, внешний генератор, MV3 на реальном YouTube.
- Реальная Windows. `check:windows` здесь только статический анализ файлов.
- Ранее описанные функциональные изменения: они требуют отдельного согласования.

## Воспроизведение

После установки зависимостей и сборки: `npm run test:unit`, затем `npm run test:desktop` (или `npm run test:e2e`). `npm test` теперь тоже использует явный настольный список. Список: `tests/desktop-manifest.json`; исторические мобильные оригиналы оставлены в репозитории, но в эти команды не входят. `node --test tests/e2e/*.test.mjs` вручную запускать не нужно: такой glob включит исторические наборы и дубли.

Снимки могут иметь исторические имена с `mobile`/`390`; в настольных производных ширина браузера заменена на 1440, ветки открытия мобильного меню исключены. Размеры исходных изображений не менялись. Есть также настольные проверки на ширине 1911 и стандартных настольных размерах Playwright.

Полный перенос: `npm run test:backup-transfer`. Тестам нужны локальный Chromium и FFmpeg; это инженерная Linux-проверка, не готовая Windows-сертификация.
