# Расширение TubeStudio для Chrome — 1.1.0

Первая доработанная версия пункта 16 плана, для TubeStudio v0.12.10 и новее. В v0.12.11 функции расширения не менялись. MV3, распакованная установка. Это не публикация в Chrome Web Store и не подтверждение совместимости с любыми будущими изменениями YouTube.

## Установка и обновление

1. Запустите обновлённый TubeStudio. В программе откройте **Система → Расширение Chrome** и скачайте ZIP расширения. Или используйте папку `extension` из полного архива исходников.
2. Распакуйте ZIP в постоянную папку, например `tubestudio-extension`. Не запускайте файлы прямо внутри ZIP.
3. Chrome → `chrome://extensions` → **Режим разработчика** → **Загрузить распакованное** → выберите эту папку. В ней должен находиться `manifest.json`.
4. Если расширение уже установлено, замените файлы в прежней папке и нажмите **Обновить** на карточке расширения в Chrome. Не устанавливайте вторую копию. Обновите также сервер TubeStudio: старое расширение несовместимо с новыми ограничениями токена.
5. Перезагрузите открытые вкладки YouTube. Поддерживаются страницы `https://www.youtube.com`, а не все сторонние или мобильные домены.
6. Закрепите значок расширения. В его окне укажите адрес TubeStudio, обычно `http://127.0.0.1:8787`. Вводится только origin: без `/api`, пути, имени/пароля и параметров.
7. Если задан `APP_PASSWORD`, войдите в веб-программу, скопируйте **токен расширения** с её страницы расширения и вставьте в окно расширения. Не вставляйте API-ключи YouTube, AnyModel или других провайдеров.
8. Сохраните настройки. Проверка подключения вызывает только служебный ping, не YouTube и не AI. После изменения настроек перезагрузите YouTube.

Нужен работающий сервер TubeStudio. HTTP разрешён только для loopback (`127.0.0.1`, `localhost`, `[::1]`). Удалённые серверы в текущей версии не поддерживаются. Не открывайте локальный сервер в интернет ради расширения.

## Метрики — только по кнопке

- Поиск и страницы каналов: нажмите **Загрузить бейджи: до 50 видео**. Следующий пакет — только следующим нажатием. Появление новых превью и прокрутка сами не расходуют квоту.
- Страница `/watch`: нажмите **Получить метрики**. Переход между видео удаляет старую панель и не запрашивает новые данные автоматически.
- Настройка показа панели/бейджей управляет видимостью, не автоматической загрузкой. По умолчанию бейджи доступны на поиске/каналах, не на главной. Поддержка конкретной разметки YouTube ограничена используемыми селекторами.
- Ошибка не сохраняется как отрицательный результат: запрос можно повторить вручную. Идентичные параллельные пакеты на сервере объединяются.
- Данные показываются как текст; названия видео не интерпретируются как HTML.

### Что означают числа

**VPH средний** = просмотры / max(1 час, возраст с публикации). Это не скорость за последний час, не «текущий VPH» и не прогноз. При неизвестных просмотрах или некорректной дате VPH неизвестен.

**Outlier** = просмотры / база. В режиме медианы база берётся из других последних загрузок того же приблизительного формата, старше 48 часов: нужно не менее трёх известных значений и ненулевая медиана. Само рассматриваемое видео исключается. Shorts определены приблизительно по длительности, а не официальному статусу.

Если базы нет, выводится «—» с объяснением, без скрытой подмены средним. В режиме среднего в Настройках используется среднее просмотров всех видео канала: это отдельно подписано как `channel-average`, форматы могут быть смешаны. Размер выборки и тип базы показываются в панели.

Скрытые подписчики, неизвестные просмотры и отношения с нулевым знаменателем не превращаются в выдуманные числа. Известный ноль просмотров остаётся нулём. Правило вирусного потенциала из Настроек — эвристика, не обещание успеха.

### Квота и свежесть

Один явный пакет: до 50 ID и до 20 баз каналов. При полном отсутствии кэша номинальная оценка: 1 запрос videos + 1 channels + до 2 на канал, до **42 единиц YouTube**. Это не точный счётчик: повторы, ошибки и переключение ключей могут увеличить расход. Остальным каналам в пакете база остаётся неизвестной; сами видео не отбрасываются. В режиме среднего загрузки каналов не запрашиваются.

Результат расширения кэшируется до 30 минут, последние загрузки — до 12 часов, данные канала — до 6 часов. Дата расчёта не означает свежий запрос каждого поля. Выборки ограничены настройкой последних загрузок (не более 50), не всей историей канала. Нет фонового сканирования, принудительного обновления кэша, бесконечного автоповтора или обещания не расходовать квоту. Ключи YouTube настраиваются на сервере TubeStudio.

## Действия с видео

- **Сохранить тему и проект** — явная запись в TubeStudio: локальная тема и связанный проект. Название, ссылка и снимок метрик сохраняются в заметке. Совпадающее название возвращает существующую тему; это не гарантированно новый проект и не дедупликация по ID видео.
- **Похожие outliers**, **Комментарии**, **В сценарий**, **Ремикс обложки** открывают заполненные формы. Переход сам не начинает поиск, AI, анализ или генерацию.
- **Открыть трекер** только открывает раздел конкурентов. Канал нужно добавить вручную в TubeStudio; автоматического отслеживания нет.
- **Открыть сохранённые темы** открывает локальный раздел сохранённого.

## Токен и границы доступа

Токен нужен только при `APP_PASSWORD`. Он разрешает GET `/api/ext/ping`, GET `/api/ext/videos` и POST `/api/saved-topics`. Не даёт доступа к настройкам, ключам, чтению всех проектов, произвольным файлам и очистке данных. Бэкграунд дополнительно проверяет отправителя, пути и тело запросов; передаёт скрипту YouTube только настройки видимости, не origin и токен.

Токен хранится в `chrome.storage.local`, не Sync. При первой миграции прежние настройки переносятся из Sync и удаляются оттуда. Это локальное хранение в профиле, **не шифрование и не защита от владельца профиля/вредоносной локальной программы**. Не передавайте профиль Chrome посторонним. Смена `APP_PASSWORD` меняет токен; после неё вставьте новый в расширение.

Без `APP_PASSWORD` сервер сохраняет прежний режим без входа: ограничения токена не заменяют защиту сети. Используйте loopback и доверенные локальные программы. Не открывайте этот сервер в интернет; расширение не создаёт сетевую защиту.

## Проверки и ограничения приёмки

Локально проверяются настоящие HTTP-маршруты, метрики на фикстурах, квотные границы, кэш и объединение запросов, синтетическая разметка YouTube, имитация Chrome messaging, безопасное отображение текста, сохранение темы/проекта, ошибки, ручные пакеты, SPA-переходы, ZIP и мобильный экран настройки.

Это **не установка настоящего MV3 в Chrome пользователя** и не живая проверка текущей разметки YouTube. Реальные ключи/Drive-файлы и платные вызовы в проверках не использованы. Windows, реальное разрешение optional host permissions и работа на живом YouTube ещё требуют приёмки. Если панель отсутствует, проверьте сервер, версию 1.1.0, настройки, перезагрузку расширения и вкладки; приложите текст ошибки без токенов и ключей.
