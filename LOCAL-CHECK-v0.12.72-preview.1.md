## Покрытие новых тестов

Фактические AM text/image/TTS/audio листья, прямая генерация текста Anthropic/Gemini, изображения OpenAI (включая edits с референсом)/Gemini, grounded-поиск с отдельной задачей search и голосовая проба. Нулевые известные тарифы, отсутствующие/неполные/отрицательные данные; known=true без коэффициентов не принимается за достаточную цену.

Очередь: запрет после удаления тарифа во время ожидания и разрешение после явной загрузки каталога. HTTP 503: перед повтором цена проверяется заново; ставший неизвестным тариф не отправляется второй раз. Успешный повтор сохраняет новую фактически использованную ставку. Неудачный ответ JSON не обходит новую проверку; существующий refresh метаданных не считается генеративным POST.

Проверены отсутствие fallback при финансовом отказе, отдельная включённая задача поиска, лимит 0, неокруглённый порог, неизвестный прошлый расход, pending и локальное восстановление, повреждённый журнал с сохранностью исходных байтов, отмена после асинхронной проверки до fetch, сохранение типа ошибки без transport retry. Ошибка не содержит промптов и ключей.

HTTP/desktop: приватность endpoint, реальный HTTP 402 и retryable=false, SSE error с исходным кодом без done/повторного запуска, видимое сообщение голосовой пробы, объяснение режима block/лимита 0/незавершённого warn. Тёмная/светлая темы на 1440 px и настольная ширина 1024 px; pageerror и горизонтальное переполнение проверяются. Явный GET каталога разрешён, после него известный нулевой тариф допускает один подставной TTS POST. Warn явно проверен как прежнее поведение, **не как готовое согласие**.

## Изоляция и ограничения

Настоящие ключи, платные AI и Google OAuth не использовались. В новых тестах все внешние fetch перехвачены; `realFetchForwarded=0`. В полном новом HTTP-сценарии намеренно разрешены два синтетических POST озвучки (известный нулевой тариф и проверка прежнего warn); запрещённые сценарии не добавляют генеративных POST. Это не означает отсутствие локальных тестовых HTTP-запросов.

Предварительные настольные прогоны были остановлены; после обнаружения сохранившегося дочернего процесса оба подтверждённых тестовых дерева завершены. Окончательный результат берётся только из отдельного единого запуска `ts72-desktop-final`, без объединения предварительных логов. Предварительная unit-фикстура использовала несуществующее значение priority=primary вместо first; исправлена только фикстура. Проверка JSON сначала ошибочно считала существующий GET метаданных вторым генеративным запросом; теперь проверяет отдельно POST и общий список. Производственная валидация не ослаблялась.

Нет резервирования, транзакционного общего потолка, долговечного pending и полного учёта ошибок/таймаутов/отмен/неизвестного исхода. Новая проверка не доказывает, что уже отправленный параллельный запрос остановлен или что все частичные результаты любого инструмента переживут сбой. Не проверены реальные Windows ACL, полный диск, отключение питания, живая цена/качество провайдера. Остаток — `REMAINING-BEFORE-LIVE-TESTS-RU.md`.
