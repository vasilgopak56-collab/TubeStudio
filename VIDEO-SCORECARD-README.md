# Разбор опубликованного видео — v0.12.23

**Исследование → Разбор видео** (`/video-scorecard`). Это не прежняя проверка «Перед публикацией» (`/check/scorecard`), которая остаётся отдельно.

## Как пользоваться
1. Вставьте ID (11 символов) или HTTPS-ссылку YouTube: watch, youtu.be, shorts, live, embed. Без авторизации и нестандартных портов. Введённый URL не загружается: извлекается только ID, запрос идёт в фиксированный Google API.
2. Выберите, нужна ли база сравнения с последними загрузками канала.
3. Нажмите «Разобрать видео». Нет автозапуска по `?v=…&auto=1` и нет автоматического повторения разбора. `?v=…` только заполняет форму.
4. Проверьте счётчики, выборку с причинами исключения и методику. «Снимок JSON» выгружает именно видимый сохранённый результат, не изменённую форму.
5. История и `?run=<UUID>` читают локальные снимки. Неудачный запрос не убирает предыдущий результат; при сбое базы сохраняется явно частичный результат без Outlier. Остановка отменяет ещё выполняющиеся запросы, но не возвращает израсходованную квоту.

## Что измеряется
- Публичные просмотры, лайки, комментарии. Отсутствующее, отрицательное, дробное или некорректное значение — неизвестность, а не ноль; известный ноль сохраняется.
- **VPH** = просмотры / max(1, часов с публикации). Средняя за всё время, НЕ текущая скорость. Неверная/будущая дата и нулевой возраст не дают VPH.
- **Вовлечение** = (лайки + комментарии) / просмотры × 100. Нужны оба известных счётчика и просмотры > 0. Это отношение событий к просмотрам, не доля уникальных людей.
- **Outlier** = просмотры ролика / медиана базы. Нужны ≥3 подходящих ролика и медиана > 0, известные просмотры целевого видео и его возраст ≥48 часов. Никакой подмены средним по каналу.
- База: до 50 последних загрузок одной страницы. Исключаются сам ролик, повторы ID, другой канал, другая/неизвестная группа длительности, неизвестные просмотры, неверная/будущая дата и возраст <48 ч. Причины видны у каждой строки.
- Группы **≤180 с / >180 с** — только длительность, НЕ подтверждение статуса Shorts. Возраст не выравнивается; когорты не приводятся к одинаковому периоду. Разные правила подсчёта просмотров и возраст могут искажать сравнение. Outlier не объявляет ролик вирусным и не прогнозирует результат.
- Локальные наблюдения: длина заголовка/описания, число и список возвращённых тегов, описание. Без оценки смысла, поискового спроса, эффективности тегов, SEO-позиции и «готовности» 0–100.

## Запросы и стоимость
Без базы — 1 базовая единица YouTube Data API (`videos.list`). С базой — до 4: видео + канал + страница playlistItems + метаданные до 50 видео. Повторы, смена ключа и общая диагностика ключей приложения могут расходовать дополнительную квоту. Диагностика общего Sidebar существовала ранее и может сработать при открытии приложения; она не является запуском разбора.

Каждый явный запуск получает свежие данные (кеш канала/выборки обходится), ответы собираются последовательно, не в один момент. Сохранённый снимок имеет дату завершения. Ни AI, ни OAuth, ни платные провайдеры контента не вызываются. Поиска и скрейпинга YouTube нет. Внешние миниатюры не подгружаются. Ссылки на YouTube открываются только пользователем.

## Хранение и доступ
Неизменяемый файл версии 1: `DATA_DIR/video-score-runs/<UUID>.json`. Хранятся исходные нормализованные метаданные и выборка; производные показатели пересчитываются из них и сохранённой даты. Экспорт JSON включает также формулы/предупреждения и вычисленный результат. Новое выполнение создаёт новый UUID. Старые файлы не перезаписываются.

История возвращает последние 50 валидных снимков; повреждённые/неподдерживаемые пропускаются с количеством. Каталог ограничен 5000 записями, один снимок — 256 KiB. Символические ссылки на каталог/файл не принимаются, ID проверяется. Файлы не шифруются: храните DATA_DIR защищённо. Общий ZIP данных включает этот раздел и восстанавливает его, но ZIP также может включать старый активный OAuth — не публикуйте его.

Новые API защищены обычной авторизацией приложения. Ограниченный Chrome-токен не открывает этот раздел; MCP/расширение не получают новых разрешений.

## Что не входит
CTR, показы, удержание, доход, dislikes, реальные поисковые позиции, AI-анализ содержания/рекомендации и числовой SEO-рейтинг не реализованы этим инструментом. Полный пункт 5 и весь план не объявляются завершёнными. Проверка живого Google на пользовательском канале и обновления Windows остаётся отдельной приёмкой.
