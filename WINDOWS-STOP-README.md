# Остановка TubeStudio v0.12.147-preview.1 на Windows

Дождитесь окончания задач и сохраните изменения. Запустите `stop-windows.bat` и подтвердите Y. Помощник проверяет владельца настроенного порта и дополнительные распознаваемые процессы Node.js. При занятости, другом сервере этой установки, неоднозначном процессе или недоступной проверке он отказывает без принудительного завершения. Проверка может ошибочно остановить обновление из-за сторонней программы с похожим относительным путём. Не завершайте все процессы Node.js.

Успешная проверка не гарантирует отсутствия всех процессов: запуск из другого пути, ссылка или новый процесс после проверки могут не обнаружиться. Не запускайте TubeStudio и не меняйте файлы параллельно с обновлением. Возможна ситуация, когда выбранный сервер уже остановился, а последующая проверка обнаружила другой и прервала обновление; проверьте состояние, прежде чем повторять.

Проверка `--dry-run` подтверждает только владельца указанного порта и не является разрешением на обновление. Подробности и переход со старых версий — `RELEASE-v0.12.147-preview.1.md`; изолированная проверка на Windows — `WINDOWS-STOP-TEST-README.md`.
