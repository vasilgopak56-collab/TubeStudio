# TubeStudio v0.12.38-preview.1 — тестовая сборка калькулятора

## Статус
Это редактируемые исходники для отдельной проверки, **не полностью проверенный релиз**. Не выдавать результаты v0.12.37 за результаты preview. Пункт 13 остаётся открытым.

## Изменения
- Раскрываемое основание расходов: AnyModel по ID, балансовые токены, ставка и сумма; совпадающие текстовые/графические счётчики показаны, но повторно не складываются.
- Прямые модели: input/output/вызовы или изображения, первое подходящее правило ставки и формула. Нет ставки — неизвестно, не 0. Произвольные поля журнала не копируются.
- POST /api/profit/calculate в workspace-month требует costsHash из GET /api/profit/workspace-costs. Сервер проверяет повторно прочитанное основание; изменение счётчиков, применённых ставок, покрытия или дня UTC даёт 409. Нет хеша — 400. Ручной режим без хеша.
- Новые снимки v2 сохраняют costBasis/reviewHash внутри workspace. JSON/Markdown/ZIP сохраняют основание. Старые v1 остаются читаемыми без подстановки нынешних ставок.
- Чтение v2 сверяет формулы/хеш и результат; новые приватные файлы пишутся через temp/rename. Необычный файл, symlink или файл больше 2 МиБ не читается. Лимиты журнала — 1000 записей суммарно и ID до 300 символов, без усечения; истории — 5000 UUID-файлов перед ручным обслуживанием.
- MCP разрешает v2 в прежней opt-in категории profit, но возвращает прежнюю проекцию итогов, без нового основания. Права не расширены.
- Поздние локальные ответы после ухода не должны заменять другую страницу; этот UI-путь ещё требует браузерной проверки.

## Проверки
Проверки preview: проверка типов и production-сборки трёх workspace прошли; **575 модульных тестов**, ошибок 0. Файловая проверка Windows на Linux прошла. Браузерные проверки, визуальная приёмка и нативный запуск Windows не выполнены.

Браузерные проверки, визуальная приёмка 390/1440 px и нативный запуск Windows **не выполнены**. Добавление/запуск новых браузерных сценариев были заблокированы инструментом; в архиве их нет. Имеющийся тест калькулятора обновлён под новое поведение отказа 409, но не запускался на preview. Полный набор E2E требует подготовки Linux-среды; часть старых файлов содержит абсолютные пути окружения разработки. Не заявляется переносимость полного набора на Windows.

## Как проверять
Распакуйте в отдельную папку, без рабочей .env и данных. Следуйте LOCAL-CHECK-v0.12.38-preview.1.md. Не импортируйте рабочие OAuth/ключи ради калькулятора. Для его арифметики внешние сервисы не нужны.

## Ограничения
Арифметика прежняя: просмотры × RPM / 1000 минус указанные расходы. Учёт всей установки, не проекта/канала; нет исторических тарифов, сверки счетов, дохода OAuth или подтверждения монетизации. Хеш — контроль соответствия, не цифровая подпись или доказательство прочтения. Время повторного чтения в тот же день может отличаться без смены чисел; изменение неиспользуемой настройки не инвалидирует основание.

Нет новых AI/OAuth/MCP/Chrome-прав, автоматических платных вызовов и расписаний. Точность чисел JavaScript, USD в UI до 4 знаков; микросуммы могут визуально округляться. Неизвестные расходы не позволяют вычислять итог прибыли и окупаемость. Приватные финансовые экспорты не публикуйте.
