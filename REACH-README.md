# Показы и CTR — предварительная интеграция Reach Basic

## Настройка и использование
1. Обновите программу. В проекте своего OAuth-клиента включите **YouTube Reporting API**, кроме уже используемых Data API v3 / Analytics API.
2. Подключите свой канал в Моя аналитика. Финансовые права не требуются. Одновременно активен один канал.
3. Откройте **Показы и CTR → Обновить задания Google**. Чтение истории само не вызывает Reporting API.
4. Если задания нет, нажмите **Подготовить отчёты в Google** и подтвердите. Сначала читается полный список до 500 заданий; существующее неистёкшее Reach Basic используется без нового POST. При неполном списке создание блокируется.
5. Google готовит ежедневные отчёты независимо от открытой программы. Первый файл может появиться в течение 48 часов; история предыдущих дней не гарантирована сразу. Нет автоматического опроса. Позже нажмите **Показать готовые отчёты** нужного задания; до 50 на страницу, далее по кнопке.
6. Введите название и нажмите **Загрузить и сохранить CSV** нужного отчёта. Каждый запуск создаёт отдельный неизменяемый снимок, включая исправленные отчёты. Общий период не объединяется. Старые файлы не удаляются; не суммируйте дубли.
7. Удалить задание можно только отдельной кнопкой с вводом точного ID. Это команда Google, прекращающая подготовку новых файлов, не удаление локальной истории. Нельзя удалить системное задание. При неизвестном исходе сетевой команды сначала обновите список, не повторяйте её вслепую.

## Что именно показано
Только `channel_reach_basic_a1`: date / channel_id / video_id / video_thumbnail_impressions / video_thumbnail_impressions_ctr. Reach Combined и экспорт Studio не импортируются. Один суточный файл, до 8 МиБ и 10 000 строк, без усечения. Дата CSV — **America/Los_Angeles (Pacific time)**, включая переходы летнего времени; интервалы Google показываются UTC [начало, конец).

**CTR API выводится исходным числом, без умножения/деления и без знака %. Единица числового представления пока не подтверждена реальным CSV.** Поэтому не вычисляются интегральный CTR и число кликов. Отсутствующие/неверные показатели — неизвестно; нулевые показы известны, но CTR при них не выводится. Заголовок без строк не равен нулевой активности. Сумма показов — только полные безопасные значения возвращённых строк файла, не весь канал.

Это общий CTR ролика, **не CTR отдельной обложки A/B**. Нет атрибуции вариантам, статистической значимости, автоматического победителя или изменения видео. Данные не переносятся в журнал A/B. Нет фоновой загрузки, объединения дней, массового обновления каналов и AI.

## Хранение и защита
Снимки в `DATA_DIR/yt-reach-runs`, файлы 0600 / каталог 0700 на поддерживающей это ОС. Сохраняются UUID, канал, Google job/report и время подготовки, SHA-256 исходного CSV и проверенные строки. Не сохраняются URL загрузки, исходный CSV и OAuth-токены. Адрес загрузки берётся только сервером из метаданных Google: разрешён HTTPS youtubereporting.googleapis.com/v1/media/, перенаправления запрещены. Запрос связан с точным активным каналом и OAuth-клиентом; смена подключения блокирует сохранение.

История последних 50 снимков всех каналов доступна без OAuth; более старые файлы не удаляются. Повреждённые файлы пропускаются с предупреждением. На экране 100 строк на страницу, JSON/Markdown содержат все строки открытого снимка, не несохранённое название. История включена в общий приватный ZIP. MCP и Chrome-токен не получают к ней доступа. Никаких реальных ключей в исходном архиве.

## Ограничения приёмки
Сборка и синтетические проверки описаны в RELEASE-v0.12.16.md. Реальный Reporting API, фактическая доступность Reach Basic для вашего канала и единица CTR ещё не проверены. Нужен действующий OAuth-клиент, доступ владельца канала, включённый API и готовый CSV. При 403 проверьте проект API и разрешения; при отсутствии готовых файлов дождитесь подготовки. Не отправляйте секреты в чат.
