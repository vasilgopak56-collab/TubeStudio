# Проверки v0.12.148-preview.1

Среда: Linux, изолированные каталоги, тестовые данные и ключи; внешний платный API не использовался.

- До исправления воспроизведено в Chromium: форма с другого origin на .147 без APP_PASSWORD получила 200, тестовый файл кэша был удалён. После исправления запрос получил 403 и файл сохранился.
- В Chromium на .148 повторены сценарии без пароля и с тестовым паролем: межсайтовые формы и GET отклонены; обычная команда из origin приложения проходит. Для атакующего использован другой порт 127.0.0.1. На реальный Google или YouTube браузер не переходил.
- Проверены допустимые и недопустимые Host, абсолютный URL, Origin, Fetch Metadata, ограниченное исключение для расширения и проверка его токена, а также отказ OAuth callback при отсутствующем state. Для Google и расширения использовались искусственные заголовки, не реальный MV3 или логин.
- Через настоящий локальный Vite proxy и Chromium проверен same-origin запрос `/api/auth/status` (200). Это не тест удалённого proxy.
- Сборка production и проверка TypeScript прошли. Общий прогон модульных тестов: 1473/1473; после финальных правок текстов дополнительно прошли 20 целевых модульных тестов. 42 выбранных интеграционных/desktop-теста прошли; после финальных правок повторены все 8 тестов имитации расширения. Полный E2E всего приложения не запускался.
- Статическая проверка файлов запуска Windows прошла в Linux; Windows, PowerShell/CIM, установка реального расширения Chrome, живой YouTube/Google OAuth и AnyModel не проверялись.
- Автотест `tests/e2e/browser-origin-desktop.test.mjs`: сетевые проверки запускаются всегда; два сценария с реальным браузером пропускаются без `CHROMIUM_PATH`. Перед выполнением нужна собранная версия и локальный Chromium. Тестовые пароли не пользовательские.
- Защита не является аутентификацией локальных процессов/расширений, сетевым экраном или защитой от XSS/отсутствующих заголовков. Подробности и порядок обновления — RELEASE-v0.12.148-preview.1.md.
