# TubeStudio v0.12.11 — география своего OAuth-канала

## v0.12.11 — география своего OAuth-канала

- Моя аналитика → География и история: явный запрос стран, просмотров и минут за календарный период, до 366 дней включительно. Без AI, дохода, CTR и дополнительных OAuth-разрешений.
- Закреплённый ID канала, даты и отдельные неизменяемые снимки. При смене подключения, отказе API или повреждённом ответе результат не сохраняется и прежний снимок не теряется.
- ZZ означает неопределённую страну; неизвестные числа не подменяются нулями. Доли и суммы относятся только к возвращённым строкам, не ко всему каналу. До 250 строк, предупреждение о возможном пределе; задержка API не маскируется датой запроса.
- История последних 50 снимков, Markdown/JSON и копирование без нового запроса; чтение после отключения OAuth. Новый каталог входит в ZIP-перенос, но не добавлен в MCP. Токен Chrome не даёт доступа к приватной географии.
- Подробности и границы: GEOGRAPHY-README.md, RELEASE-v0.12.11.md. Живая приёмка своего канала через OAuth и Windows ещё нужна; реальные ключи/Drive-файлы не использовались.
- Пункт 12 реализован частично: доход, CTR, полноценная история A/B и многоканальный дашборд этим выпуском не закрыты. Весь план не завершён. PDF/DOCX v0.11 не пересобраны.

## Обновление

1. Дождитесь завершения задач, сделайте резервную копию всей рабочей папки, фактической DATA_DIR, `.env` и своих промптов. Общий ZIP может содержать OAuth-токены и приватные данные; не публикуйте его. `.env` храните отдельно.
2. Остановите сервер. Распакуйте архив отдельно и скопируйте **содержимое** `tubestudio` в существующую папку программы с заменой файлов. Не создавайте `tubestudio/tubestudio` и не удаляйте свои `.env` и данные. Их нет в архиве исходников.
3. Если меняли код или промпты, сравните и сохраните свои правки до замены. `.env.example` не заменяет ваш действующий `.env`.
4. На Windows запустите `update-windows.bat`, дождитесь успешной установки зависимостей и сборки. Node.js 20+ должен быть установлен. Для других систем: `npm install`, `npm run build` из корня и обычный запуск. Обновите вкладку Ctrl+F5.
5. Откройте **Моя аналитика → География и история**. Существующее подключение OAuth используется без новых scopes; не нужно переавторизовывать исправное подключение только ради обновления.
6. Расширение Chrome осталось версии 1.1.0, его функции этим выпуском не менялись. Если оно уже обновлено с v0.12.10, повторная установка не требуется. Полная программа и MCP теперь сообщают версию 0.12.11.

Архив содержит редактируемые исходники для VS Code/Cursor и других редакторов. Не содержит установленных зависимостей и `dist`: требуется сборка. Инструкции по ручному редактированию — DEVELOPMENT-RU.md.

## Оставшаяся приёмка

На реальном канале требуется обычное OAuth-подключение с разрешением чтения YouTube Analytics. Ключи провайдеров не заменяют это разрешение. Реальные ключи/Drive-файлы не использовались; не присылайте приватные токены в чат. Windows/ярлык, живой YouTube/Chrome MV3 и другие внешние провайдеры этим локальным прогоном не подтверждены. Исторические PDF/DOCX v0.11 не пересобраны; предупреждение Vite о крупном чанке Справки сохраняется.
