# TubeStudio v0.12.27 — проверяемый Keyword Research

## Что изменилось
Базовая часть пункта 2: **Исследование → Ключевые слова** теперь разделяет подсказки и поиск. Один свежий запрос неофициальных подсказок для одной фразы без Data API/AI, до 30 уникальных непустых строк в порядке ответа. Исходная фраза искусственно не добавляется; дубли/пустые/слишком длинные строки отфильтровываются по раскрытой методике. Номер строки не выдаётся за популярность.

Поиск — отдельная явная кнопка: одна свежая страница `search.list` до 50 видео, затем публичные счётчики видео/уникальных каналов, без кеша или следующей страницы. Порядок API и недоступные строки сохраняются; скрытые/неизвестные значения не становятся нулём. Доступны медиана известных накопительных просмотров, медиана подписчиков **по уникальным каналам**, срез <10 000 и число заголовков с нормализованной подстрокой. У каждого показателя раскрыты знаменатель и ограничения. Нет расчётной частотности, балла конкуренции/популярности/общего рейтинга, автовыбора по эвристикам и прогноза роста.

Ручной выбор до 30 фраз, копирование/передача в SEO без автогенерации. Подстановка подсказки/переход по ссылке, включая `auto=1`, не запускают новый сетевой поиск. История 50, отдельные UUID-снимки, закреплённый JSON, ZIP-перенос. Изменение формы не меняет прежний снимок. Ошибка/отмена до фиксации не заменяют результат; после успешного сохранения отмена не является удалением.

Новые снимки доступны как источник Daily Ideas: первые 10 подсказок либо названий/ID/дат/известных просмотров поисковой выборки. Баллы спроса/конкуренции и сводные медианы не передаются; прежний точный локальный предпросмотр/явная AI-кнопка сохраняются. Пустой источник для AI недоступен.

Старые отчёты сохранены в архиве с предупреждением об ограничениях прежних оценок; полный JSON доступен. Старые API/настройки и зависимые прежние разделы сохранены для совместимости, не переписаны целиком. Их эвристики не становятся измеренным спросом. Новый интерфейс не вызывает прежний автовыбор и AI-описание канала. Комментарии, SEO-аудит, Scorecard и другие разделы сохранены.

## Стоимость, безопасность, ограничения
Подсказки без единиц Data API, но это внешний запрос. Поиск — 100 базовых единиц за поиск + 1 videos + 1 channels для непустой страницы (102); пустая страница — 100. Это базовая успешная цепочка, не точный счёт всех повторов/резервных ключей. Общие сетевые повторы, диагностика ключей и настроенный трекер могут отдельно расходовать квоту; отмена её не возвращает. AI в новом разделе не вызывается.

Счётчики разновозрастных видео не являются месячным объёмом поиска. Нет измерения спроса, реальной выдачи у зрителей, поискового трафика/CTR, монетизации, лёгкости продвижения или полноты рынка. Нет подсказок/пустая страница не означает отсутствия спроса. Метаданные читаются последовательно, не одновременно. Сервис подсказок неофициальный/нестабильный.

Новые маршруты защищены паролем приложения, Chrome-токен не допущен. Новых OAuth/MCP-прав нет. Строгие схемы/размеры, безопасное чтение, пропуск повреждённых/неподдержанных/символических ссылок, запись через временный файл. Это не шифрование/цифровая подпись и не гарантия Windows ACL. JSON/ZIP содержит фразы, параметры, ID/заголовки/публичные счётчики; храните приватно. Подробности — KEYWORD-EVIDENCE-README.md и Справка.

Реальные Google/подсказки и обновление Windows в этом этапе не проверены. Пункт 2 реализован в ограниченном базовом режиме, весь план не закрыт. CTR Reporting и автоматические результаты A/B остаются открытыми. Chrome остаётся 1.1.0, исторические PDF/DOCX не пересобраны.

- Проверены строгие поля/язык/регион/размер HTTP/невалидный JSON, нормализация NFKC/ё/пробелы, отсутствие искусственной исходной фразы, пустые/слишком длинные/повторные/ограниченные подсказки, ограничение размера ответа; точные параметры одной свежей страницы и двух пакетов метаданных; исходный порядок/пропуски/нули/скрытые значения/знаменатели; независимая арифметическая проверка медиан по сырым синтетическим счётчикам; квота 102/100; ошибки каждого этапа без сохранения и без утечки текста провайдера; отсутствие ключа и отмена до сети/в ответе/при фиксации/при уходе; неизменность прежнего результата/JSON; схема/версия/ID/размер/порядок/символические ссылки/история 50; пароль и запрет Chrome; глубокая ссылка/архив/Справка без автоматической сети; ручной SEO-переход; новые локальные источники Daily Ideas; настоящий ZIP export/import.
- Исправлен обнаруженный браузерным тестом пустой язык старых настроек: выбирается поддержанный язык исследовательских настроек/контента либо ru, а не отправляется пустая строка. Тестовые ошибки выбора пустого источника и искусственной будущей истории исправлены в самих тестах: пустая выборка намеренно недоступна для AI, история намеренно ограничена 50.
- Новые сценарии используют только временные каталоги, фиктивные ключи и синтетического провайдера с блокировкой неизвестных внешних запросов. Пользовательские данные/ключи и реальные платные провайдеры не использовались.
- Просмотрены 5 экранов: пустой 390 px, подсказки/ручной выбор 1440 px, поиск/методика 1440 px, ошибка с прежним результатом 390 px, раскрытая методика/недоступные значения/история 390 px. Нет горизонтального переполнения страницы/перекрытий в проверенных состояниях; HTML-подобный текст отображается буквально, внешние картинки не загружаются.
- Переносимая Windows-файловая проверка — PASS на Linux. Это не приёмка Windows/PowerShell/COM/ярлыка/обновления пользовательской установки.
- Исходный ZIP исключает .env, пользовательские данные/OAuth, node_modules, dist, логи и архивы. Целостность, обязательные новые/прежние файлы и известные значения секретов проверяются. Сканирование известных значений не является универсальным обнаружением любых секретов.

## Обновление
Сохраните защищённую копию установки, .env и DATA_DIR, завершите задания и остановите сервер. Распакуйте архив отдельно, перенесите содержимое `tubestudio` в прежнюю папку без второй вложенной `tubestudio`, не удаляя .env/data. Запустите `update-windows.bat`, дождитесь успешной сборки и обновите вкладку. Новый каталог создаётся при первом сохранении; старые отчёты не пересчитываются автоматически. Импорт проверяйте только в отдельной тестовой установке. См. UPDATE-README.txt, BACKUP-README.md и LIVE-ACCEPTANCE.md.
