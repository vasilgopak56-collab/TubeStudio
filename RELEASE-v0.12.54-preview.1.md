# 0.12.54-preview.1 — практические уроки для новичка

Система → Справка: 62 главы вместо 59. После «Первое видео» добавлены:

1. Практика 1 — сценарий с нуля: отключение ДНК для черновика, конкретная тема, настройки, источники, проверка, сохранение.
2. Практика 2 — новая история по ДНК: референсы, наблюдения вместо догадок, своё направление, пять разных конфликтов, проверка десяти пар, NotebookLM, R#, реконструкция, драматургия, применение брифа и проверка текста.
3. Практика 3 — текст, голос и сцены: короткая проба, выбор графического стиля, альтернативные пути раскадровки, различие промпта/кадра/клипа и ручная приёмка.

Все примеры условные, а не результаты реального анализа канала или платной генерации. В каждом уроке есть точки проверки, сохранение, типичные проблемы и расходы. Нет гарантии художественного качества, отсутствия заимствований или достоверности автоматически полученного текста.

DOCUMENTATION-RU.md обновляется из того же источника. Количество глав в генераторе определяется автоматически. Генерация сценариев, API и мобильные экраны не изменены. Номер версии обновлён для различения архивов.

Перед установкой сохраните резервную копию, data, .env и приватные подключения. Остановите приложение, обновите программные файлы, сохранив свои данные, и запустите update-windows.bat. Новая справка: Система → Справка. Старые статические PDF/DOCX не являются текущей документацией.
