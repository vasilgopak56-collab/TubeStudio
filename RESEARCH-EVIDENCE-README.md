# Research / Outliers — v0.12.29

## Что изменилось

Новый `/research` — явный запрос одной свежей страницы YouTube, до 50 видео. Доступны язык, необязательный регион из двух латинских букв, порядок relevance/viewCount/date и фильтр публикации 7/30/90/365 дней либо любое время. Ссылка, открытие раздела, изменение формы, история и фильтры запрос не запускают. AI не вызывается.

База запрашивается отдельно выбранным пределом: первые 0/5/10 уникальных каналов **в исходном порядке страницы API**, а не после сортировки по просмотрам. Для каждого — одна страница до 50 загрузок и метаданные возвращённых видео. Недоступные метаданные поискового видео не удаляют его строку. Отсутствующие метаданные загрузок не выдумываются: база содержит только видео, возвращённые videos.list. Пустая загруженная база не доказывает, что на канале нет видео.

## Формулы и ограничения

- Outlier = накопительные просмотры цели / медиана известных просмотров базы того же канала. Не менее трёх подходящих роликов, медиана >0. Цель и база не моложе 48 часов на момент завершения снимка.
- Из базы исключены само видео, повтор ID, другой канал, неизвестная длительность, другая группа длительности, неизвестные просмотры, неверная/будущая дата и возраст <48 ч. Порядок проверки причин именно такой; показывается первая причина исключения.
- Группы ≤180 с и >180 с — только длительность, **не фактический статус Shorts**. Разные правила просмотров и возраст видео не выравниваются. Это не сравнение за одинаковый период.
- Нет скрытого fallback на среднее канала, lifetime-статистику канала или другие форматы. Не запрошена/недоступна база, слишком мало подходящих видео, медиана 0, неизвестная или слишком молодая цель — Outlier неизвестен.
- Средний VPH = просмотры / max(1, часы с публикации), только при корректном положительном возрасте и известных просмотрах. **Не скорость сейчас**, не временной ряд и не прогноз. Округление до двух знаков.
- Вовлечение = (лайки + комментарии) / просмотры ×100, только если все счётчики известны и просмотры >0. Это не доля уникальных зрителей. Просмотры/подписчики — также не доля аудитории, знаменатель должен быть >0.
- Ноль известного счётчика отличается от неизвестного/скрытого. Неизвестное не проходит числовой фильтр и сортируется последним. Фильтры/сортировка работают локально; исходный порядок и JSON не меняются. Для возраста используется число часов, не календарных дней.
- Нет CTR, показов, удержания, дохода, dislikes, позиций у зрителя, определения спроса, SEO-балла, анализа содержания и прогнозов вирусности. Обложки не загружаются автоматически; для просмотра откройте исходное видео. Новая страница не включает прежние пресеты «вирусности», ремикс сетки обложек и скрытый подсказочный поиск.

## Запросы, стоимость, ошибки

Успешная непустая цепочка: search.list 100 + videos.list 1 + channels.list 1; для каждого выбранного канала до двух единиц (playlistItems.list и videos.list). Максимум 102/112/122 базовых единицы при 0/5/10 базах. Пустая поисковая страница — 100. Это консервативный предел, **не счётчик фактического расхода**. Повторы, резервные ключи, диагностика ключей и настроенный трекер приложения работают отдельно и могут расходовать квоту. Все запросы свежие, без кеша. Ответы приходят последовательно, не одновременно.

Сбой отдельной базы сохраняет статус «недоступна» и неизвестный Outlier, без подмены числом. Отмена, отсутствие ключа и исчерпание квоты не превращаются в частично успешную базу. Ошибка основного поиска/метаданных/сохранения не заменяет прошлый снимок. Во время запуска форма заблокирована; есть отмена; уход со страницы отменяет задачу. Уже отправленные запросы расходуют квоту независимо от отмены. Успешный новый запуск создаёт новый UUID, не перезаписывая прежние записи.

## История, экспорт, совместимость

Новые снимки `DATA_DIR/research-evidence-runs/<UUID>.json`, версия формата 1. Сохраняются только исходные параметры/поисковые строки/метаданные/базы, а не доверенные агрегаты. Производные числа и причины исключения пересчитываются локально из закреплённых данных при чтении. История показывает последние 50; до 5000 файлов в каталоге; один файл до 2 МиБ. Неподдерживаемые/повреждённые/несогласованные/слишком большие файлы и симлинки не используются. Чтение не удаляет их. Файлы пишутся через временный файл, права 0600 на POSIX; отмена после rename удаляет только новый снимок.

JSON экспортирует полный выбранный снимок с расчётами, не изменённую форму и не текущие фильтры. Новая папка включена в общий ZIP экспорт/импорт. ZIP может содержать приватные данные и OAuth из других разделов — не публикуйте его. Daily Ideas получает только первые десять сохранённых строк: названия, ID, даты, известные просмотры; без Outlier/VPH/рангов/баз и без нового YouTube-запроса. Генерация Daily Ideas по-прежнему отдельная явная операция.

Старые ссылки с `?run=<8 hex>` открывают архив без нового поиска. Старые `research-runs` доступны в раскрываемом архиве и как исходный архивный JSON. Они не пересчитаны и исходные базы не придуманы. Прежние API `/research/*`, «Аномалии», старые настройки исследования и зависящие от них разделы оставлены для совместимости. Их методика **не исправлена глобально**: возможны прежние fallback/эвристики; в «Аномалиях» добавлено предупреждение. Новые OAuth scopes, MCP/Chrome-доступы и права не добавлены. Chrome extension остаётся 1.1.0.

## Обновление и приёмка

1. Остановите программу и сохраните защищённую копию старой установки, `.env`, DATA_DIR и промптов.
2. Распакуйте исходники отдельно; перенесите свои настройки/данные по UPDATE-README.txt. Не заменяйте приватные данные тестовыми.
3. Установите зависимости и соберите (`npm install`, `npm run build`) либо используйте штатный Windows-лаунчер.
4. В отдельной тестовой установке проверьте локальное чтение архива и импорт ZIP. Реальный поиск запускайте явно с согласованным расходом квоты.

Linux-проверки используют только фиктивный YouTube. Реальные Google API, платные AI-вызовы, нативное обновление Windows и живой OAuth в этом выпуске не проверялись. Старые PDF/DOCX не пересобирались: актуальные правила находятся здесь и во встроенной справке. Это базовая версия пункта 1, а не закрытие всего плана.
