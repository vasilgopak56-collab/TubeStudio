# TubeStudio v0.12.16

## v0.12.16 — суточные показы и CTR (Reach Basic)

Моя аналитика → **Показы и CTR**: управление заданиями YouTube Reporting API по подтверждению, список готовых отчётов с пагинацией и явная загрузка одного CSV. Проверяется точный OAuth-канал, тип задания, ID отчёта, адрес Google и строки файла. История, JSON/Markdown и ZIP-перенос; чтение сохранённого без Google. Без AI, финансовых прав, автоматического опроса и смены видео.

**Предварительная интеграция:** CTR пока выводится исходным числом API, без пересчёта в проценты; единица требует проверки реальным отчётом. Нет интегрального CTR, восстановления кликов, объединения дней или автоматических результатов A/B. Первый отчёт Google может потребовать до 48 часов. Задание продолжает работать в Google при закрытой программе; удаление требует отдельного подтверждения.

Подробности: REACH-README.md, RELEASE-v0.12.16.md. Пункт 12 и весь план остаются частичными: нужны живая приёмка, проверка единицы CTR и отдельная работа с результатами A/B. Исторические PDF/DOCX v0.11 не пересобраны.

## Проверки
- Проверка типов и production-сборка всех трёх workspace прошли.
- Прошли все **343 модульных теста**, включая 22 проверки Reach: строгий CSV, границы/кодировка, Pacific/DST, нули/неизвестность, точная привязка канала, создание без дубля, неизвестный исход команды без повторов, пагинация, безопасный адрес/запрет редиректов, смена подключения, приватные снимки, повреждения и ZIP-whitelist.
- Прошли все **144 браузерных/интеграционных теста**, включая 9 новых: явные подтверждения, ожидание/пагинация, сохранение и закреплённый экспорт, ошибки без потери результата, офлайн-история, 101 строка с пагинацией, HTTP-схемы/лимиты/пароль/запрет Chrome-токена, мобильные 390 px/Справка, удаление задания и реальный ZIP export/import.
- Новые сценарии использовали только временные искусственные данные; неизвестные внешние запросы тестового провайдера блокировались. Реальные ключи не использовались. Отсутствие горизонтального переполнения 390 px проверено автоматически; актуальный мобильный снимок также просмотрен вручную.
- Сборка сообщает предупреждение Vite о крупном чанке Справки; это не ошибка сборки.


Реальные ключи и Drive-файлы не использовались. Не проверены живые OAuth / Reporting API, единица CTR реального CSV, реальная статистика и финансовые права, Windows/ярлык, установленное MV3 и платные провайдеры. Это локальная регрессия, не приёмка всей программы. Исторические PDF/DOCX v0.11 не пересобраны.

## Обновление
Остановите TubeStudio и сделайте защищённую копию установки и данных. Скопируйте содержимое tubestudio из архива в существующую папку с заменой исходников, без второй вложенной папки tubestudio. Не удаляйте .env, DATA_DIR, настройки, OAuth и промпты. Запустите update-windows.bat, дождитесь успешной сборки и обновите страницу. Новый модуль: Моя аналитика → Показы и CTR. Версия расширения Chrome остаётся 1.1.0.
