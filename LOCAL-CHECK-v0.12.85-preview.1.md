## Проверки нового этапа

Полные проверенные части строго по порядку. Недостающие/неизвестные части блокируют сборку без TTS. Запросы строгие: нельзя передать собственные пути/URL/порядок/текст/ложное согласие. Суммарный размер ограничен в коде 128 МиБ, работа FFmpeg — 120 секунд; стресс этих пределов не принимался. Несовпадающая частота частей блокируется без перекодирования.

Одно- и двухчастный синтетический тон действительно собран локальным FFmpeg и декодирован обратно в PCM; сверены положительная длительность и допустимое отличие суммы кадров. Исходные MP3 сохраняются побайтово. Сборка не добавляет артефакт автоматически и не вызывает провайдера. Повторные/конкурентные подтверждения возвращают тот же файл/хеш без изменения mtime. Приватная временная папка содержит только генерируемые имена; FFmpeg разрешён только файловый протокол, shell не используется, диагностические пути не отправляются в ошибку UI.

Предварительный снимок хеша записывается до публикации MP3, финальная квитанция после. Ошибка публикации результата допускает только локальный повтор, ошибка финальной квитанции восстанавливается из уже полученного файла без изменения MP3. Подмена структурно валидным другим MP3 отвергнута. Повреждённые исходники/результаты, символические и жёсткие ссылки не превращаются в пустую запись. Отмена до работы и на точке прогресса оставляет исходники и не публикует итог. Отдельный дочерний процесс без доступного FFmpeg получает безопасную ошибку, не TTS.

Добавление итогового аудио — отдельный preview/consent/save. Сценарии, подготовка, старые аудио и заметки сохраняются. При изменении проекта старое согласие отклоняется; повтор сохранённого подтверждения идемпотентен. SourceArtifactId и хеши закреплены; сегменты приблизительны по частям, не speech alignment.

Интерфейс: preview всех частей, отключённая кнопка до согласия, результат, точный хеш скачанных байтов, отдельное добавление в проект; смена подготовки сбрасывает согласие. Закрытие/открытие панели показывает прежний готовый файл через локальную проверку, без TTS. HTTP auth/Origin/schema/false consent/stale/replay проверены. Тёмная тема 1440×1000 и светлая 1024×900 просмотрены; pageerror и горизонтального переполнения нет.

## Границы

Реальные ключи, платные голоса, качество произношения, идеально бесшовные стыки, YouTube и настоящая Windows не проверялись. Провайдер перехвачен заглушкой; новый тестовый тон сгенерирован локально. Плеер preload=none может показывать 0:00 до загрузки metadata; это не измерение длительности реальной речи.

Сборка только stream-copy одинакового формата, без эффектов и независимых TTS-профилей. FFmpeg нужен только для новой сборки, не для скачивания/повторного открытия готового файла. Неизвестная платная TTS-попытка остаётся заблокированной; разрешение повторить локальную склейку не даёт права повторить TTS.

Один сервер на DATA_DIR, без параллельного импорта/ручной правки. До 500 снимков сборок, проект до 10 МиБ. Нет гарантии fsync/питания/Windows ACL/сетевой ФС/межсерверного exactly-once. Приватный архив содержит тексты и аудио, публиковать его нельзя. Удаление владельцем данных может удалить результат. Предыдущие отчёты исторические; актуальные журналы — docs/checks/v0.12.85.
