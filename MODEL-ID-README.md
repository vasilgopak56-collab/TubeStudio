# TubeStudio v0.12.1 — ручной ID модели

## Где вводить

- **Сценарист → Модель сценария — ручной ввод ID (AnyModel)**: впишите свой ID либо выберите подсказку. Пустое поле использует настройку «Сценарии — топ-модель». Поле сохраняется в черновике; лишние пробелы по краям удаляются перед отправкой.
- **Настройки → AnyModel**: ручной ввод для всех задач сохранён, добавлены пояснения и примеры. В полях Claude используются ID AnyModel, например `cc/claude-opus-5` и `cc/claude-sonnet-5`.
- **Настройки → Прямые ключи → Claude — тексты и анализ**: ручной ID прямого Anthropic API. Примеры: `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`. Префикс `cc/` здесь не нужен.
- Вводите только ID: без кавычек, названия тарифа и URL. После изменения настроек нажмите «Сохранить настройки».

## Порядок подключения и резерв

В Сценаристе поле относится только к AnyModel: плану, актам и подгонке объёма. Оно не переопределяет модель прямого Anthropic API и не изменяет отдельные модели проверок/SEO. Чтобы выбранный ID AnyModel шёл первым, включите AnyModel и порядок «AnyModel основной». Для прямого Claude выберите «Прямые основные» и «Claude» в генерации текстов.

Обычный переход на резерв сохранён. Выбор ID не гарантирует, что резерв не будет использован при ошибке/отсутствии доступа/недостаточном балансе. Фактическая модель отображается в результате Сценариста. Каталог и доступность меняются: новые ID можно вписывать вручную без обновления списка в программе. Примеры не проверялись платным запросом вашего аккаунта.

## Claude Pro

Claude Pro — подписка на чат Claude, не модель и не API-ключ. Использование Claude API оплачивается отдельно через Claude Console. TubeStudio использует API: для прямого подключения нужен API-ключ Anthropic, для AnyModel — ключ и баланс AnyModel. Логин/пароль или подписку Claude Pro в поле модели вводить не нужно.
