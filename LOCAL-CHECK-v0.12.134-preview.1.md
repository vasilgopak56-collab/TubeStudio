# Локальные проверки 0.12.134-preview.1

Проверены итоговые исходники и сборка в изолированной Linux-среде с Node 24; тестовые данные временные. Результаты не являются приёмкой на компьютере пользователя.

- `npm run typecheck` — успешно (server, web, MCP).
- `npm run build` — успешно (web, server, MCP). Сборщик сообщает о крупном главном JavaScript-бандле; скорость приложения не измерялась.
- `npm run test:unit` — **1402/1402** прошли после последнего изменения; без реальных секретов и пользовательской папки данных.
- Адресные desktop/e2e-тесты проекта, сохранения сценария и справки — **39/39**; в том числе 1 сценарий нового предупреждения и 4 сценария сценария. Браузер работал с локальным временным сервером; внешние запросы в тестах блокировались или имитировались.
- Новые серверные тесты проверяют корректные и отсутствующие проекты; некорректный JSON и базовую структуру; ошибку доступа к файлу/папке; исчезновение файла во время формирования списка; оборванную ссылку; сохранность байтов проекта и медиа при отказе операций. Ошибки EACCES имитировались, не проводилась настоящая приёмка прав Windows.
- `npm run test:backup-transfer` — **8/8**, 91 тестовая запись и 37 папок; два TTS-вызова имитированы. Это не доказательство атомарного восстановления.
- `npm run check:windows` — статическая проверка файлов запуска пройдена. Windows, установщик и ярлык на настоящей Windows-машине не запускались.
- Общая desktop-регрессия была запущена на промежуточной сборке, но не завершена; **полный набор desktop-тестов итоговой сборки не выполнен**. Адресные 39 тестов не заменяют полную регрессию.
- Реальные API AnyModel/Google и платные запросы не использовались. Проверка не подтверждает совместимость со всеми существующими проектами и конфигурациями Windows, защиту от внешних процессов или полную целостность данных.
