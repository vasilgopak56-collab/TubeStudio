# Разбор видео — происхождение данных v0.12.31

Раздел `/video-scorecard` и API сохранены, AI не добавлен. Явный запуск по ссылке/ID, без автозапуска по ссылке, истории или форме.

## Снимок v2

- `observations.targetAt` — после метаданных цели; `channelAt` — после ответа канала; `pageAt` — после одной свежей страницы загрузок; `sampleAt` — после пакетных метаданных, null для пустой страницы. `createdAt` — завершение снимка. Это время получения ответов приложением, не гарантированное время измерения счётчиков Google. Ответы последовательные, не одновременные.
- Возраст и средний VPH цели считаются на targetAt, зрелость базы — на sampleAt. Ожидание/повторное открытие не увеличивают возраст. VPH = просмотры/max(1, часы); не скорость сейчас. Дата неверна/будущая или возраст ноль — VPH неизвестен.
- `page.ids` — до 50 уникальных ID в исходном порядке; `hasMore` фиксирует наличие следующей страницы, но она не загружается. Это не полная история канала.
- Каждому ID соответствует строка sample. `metadata: missing` сохраняет ID, остальные сведения пусты/null: неизвестность, не ноль и не придуманная публикация. Возвращённые строки показывают ID канала, дату, длительность и счётчик; HTML-подобные названия — буквальный текст.
- Повторные/чужие ID, чужой канал, недоступная или некорректная страница/метаданные дают частичный результат только с целью и статусом unavailable. Нет 404→пусто и кеша загрузок. Успешная пустая страница остаётся loaded с нулём строк, без Outlier. Ошибка самой цели не создаёт снимок.

## Проверяемая метрика

Outlier = просмотры цели/медиана минимум 3 других подходящих роликов; медиана >0, цель и база ≥48 ч. Сам ролик, неизвестные счётчики/даты/длительности, чужая группа и молодые ролики исключены с причиной. Настоящий ноль просмотров сохраняется. Группы ≤180 и >180 с — не подтверждённый статус Shorts; возраст не нормализуется, нет прогноза вирусности. Недоступность Outlier объясняется явно. Вовлечение — события/просмотры, не доля уникальной аудитории.

## Совместимость и хранение

v1 читается как архив с прежней датой завершения: не дописываются page/observations/исходники и не меняются байты. JSON закреплён за результатом, а не несохранённой формой. Ошибка/отмена/уход не заменяют предыдущий результат. История до 50, до 5000 файлов каталога, 256 КиБ/снимок; ограниченное чтение, валидация порядка/дат/placeholder, symlink-защита и атомарная запись с отменой. ZIP включает прежний video-score-runs, отдельный JSON не восстанавливает установку.

## Расход и ограничения

Без базы 1 базовая единица, с базой до 4 (цель, канал, страница, пакет метаданных); пустая страница не требует последнего вызова. Повторы/резервные ключи, общая диагностика и настроенный трекер отдельно. Чтение/экспорт без YouTube/AI; нет новых OAuth/MCP/Chrome-прав. Публичный API не даёт здесь CTR/удержание/доход/поисковую позицию/анализ содержания. Полные исходные JSON-ответы Google не хранятся: только перечисленные ограниченные поля.

Реальные Google/Windows и весь план не закрыты. Синтетические тесты и снимки UI не заменяют живую приёмку. Старые PDF/DOCX-инструкции не пересобраны; актуальны Markdown-дополнения.
