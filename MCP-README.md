# TubeStudio MCP — v0.12.40-preview.1

## Новое: проверка страниц списка
- Первый ts_list_saved возвращает **listToken**: SHA-256 отпечаток категории, списка наблюдённых обычных UUID-имён файлов, ID/сырых snapshotToken корректных просканированных записей в порядке вывода и счётчиков охвата. offset и limit в него не входят: размер страницы можно менять. Абсолютный путь, настройки, ключи, тексты и содержимое файлов в новом поле не возвращаются.
- Для продолжения передавайте этот токен как **expectedListToken** вместе с nextOffset. Категория должна остаться той же. При отличии от заново просканированного результата возвращается **STALE_LIST**; частичная страница/новые данные в ошибке не возвращаются. Отбросьте весь накопленный список, начните с offset 0 **без** expectedListToken, затем используйте новый listToken.
- Параметр необязателен: прежние клиенты продолжают работать, но без проверки согласованности страниц. Пять инструментов и scopes не меняются.
- **snapshotToken строки → expectedToken чтения одной записи**; **listToken ответа → expectedListToken списка**. Не подставляйте токен списка в чтение сценария/транскрипта и наоборот. STALE_SNAPSHOT относится к одной записи, STALE_LIST — к списку.
- Токен — не право доступа, не подпись, не хранение серверной копии и не счётчик изменений. Сравнение выполняется при каждом вызове, кэша/записи нет. Совпадающие наблюдения дают одинаковый токен, в том числе после возврата файлов к прежним байтам. Новые права не выдаются.
- **Нет транзакции/блокировки ОС:** конкурентное изменение во время или после сканирования возможно. Совпадение токенов не доказывает неизменность в промежутке. До 5000 имён по алфавиту читаются как раньше; при scanLimited содержимое файлов за пределами лимита не прочитано и его изменения могут не изменить listToken. Все наблюдённые подходящие имена входят в отпечаток, так что добавление/удаление такого имени меняет токен. Обход лимита или ложная полнота не добавлены.
- Пустой список тоже имеет listToken. Отсутствующая и существующая пустая папка дают одинаковый наблюдаемый список. Неверные/пропущенные UUID-файлы учитываются в охвате; файлы вроде index.json как раньше не записи. Доступ к запрещённой категории по-прежнему закрыт.

## Порядок вызовов в клиенте
1. ts_status: проверить readOnly/scopes и текущую версию.
2. ts_list_saved: например {"kind":"projects","offset":0,"limit":1}. Сохранить listToken и nextOffset из ответа.
3. Если nextOffset не null, повторить **ту же категорию** с offset=nextOffset и expectedListToken=listToken. Сам токен скопировать из ответа, не придумывать.
4. При STALE_LIST отбросить страницы и повторить шаг 2 без старого токена. Если данные постоянно меняются, остановить чтение/попросить закончить изменения, а не бесконечно повторять запросы.
5. Для выбранного ID использовать snapshotToken **его строки** как expectedToken в ts_read_saved/ts_read_script/ts_read_transcript. Не собирать текст из разных ревизий.

Проверки v0.12.40-preview.1: типы и production-сборки web/server/MCP прошли; **591 модульный тест и 9 целевых MCP-сценариев**, ошибок 0. Среди MCP-сценариев — настоящий дочерний stdio-процесс, проверка списка, прежние права, веб-конфигурация, её авторизация и мобильная ширина. Просмотрена страница MCP на 1440/390 px, переполнения страницы нет. Windows — только файловая проверка на Linux. **Полный набор E2E, браузерная/визуальная приёмка калькулятора, установленный внешний AI-клиент пользователя и нативная Windows-приёмка не проверены.**

**Вся сборка — preview** из-за открытой приёмки калькулятора; реальный внешний клиент пользователя и Windows отдельно не проверены. Обновите конфигурацию/перезапустите MCP-процесс после обновления сборки, чтобы клиент увидел новый параметр инструмента. MCP не подключается к Notion или иным облачным сервисам автоматически. Подробности ниже и в LOCAL-CHECK-v0.12.40-preview.1.md.

# TubeStudio MCP — базовая версия v0.12.26

Первая версия пункта 15 плана: отдельный локальный MCP-сервер **только для чтения сохранённых данных**. Использует официальный `@modelcontextprotocol/sdk` и транспорт **stdio**. Не является HTTP-сервером, не открывает порт, не создаёт публичную ссылку. Облачный клиент, принимающий только HTTPS-подключения, к этой версии напрямую не подключится.

## Быстрый старт

1. Обновите исходники TubeStudio целиком и выполните `npm install`, затем `npm run build` из корня проекта. Windows: `update-windows.bat` выполняет эти шаги. Node.js ^20.19.0 либо >=22.12.0 должен быть доступен и внешнему клиенту.
2. В TubeStudio откройте **Система → MCP-подключение**. Проверьте сообщение о найденной сборке.
3. Оставьте только нужные категории и скопируйте сгенерированный JSON. В нём уже стоят полный путь к Node.js, `apps/mcp/dist/index.js` и фактическая `DATA_DIR` веб-программы.
4. Добавьте запись `tubestudio` в конфигурацию **доверенного локального клиента со stdio MCP**. Сохраните другие подключения: не заменяйте весь файл клиента вслепую. Формат экрана — `mcpServers`; для клиента с другим форматом перенесите соответствующие поля вручную.
5. Перезапустите MCP-подключение в клиенте. Вызовите `ts_status`: в текущем preview ожидаются `version: "0.12.70-preview.1"`, `readOnly: true` и только выбранные `scopes`.
6. Вызовите `ts_list_saved` с `kind: "projects"`. Скопируйте настоящий `id` строки в `ts_read_saved`. Для сценария возьмите `artifactId` из `artifacts.rows` проекта и вызовите `ts_read_script` с двумя точными UUID.

Найденная сборка на экране **не подтверждает подключение клиента**. Страница сама MCP-процесс не запускает. Категории на экране — временный редактор JSON, не серверная настройка: изменения не сохраняются и не меняют уже работающий клиент. Нужно обновить его `env` и перезапустить процесс.

После сборки веб-программу можно закрыть: MCP читает сохранённые файлы напрямую. Указанная папка должна существовать. При переносе проекта или смене `DATA_DIR` скопируйте конфигурацию заново. Вручную MCP запускается `node apps/mcp/dist/index.js` или `npm run mcp` из корня; stdin/stdout предназначены для MCP-протокола, это не интерактивная консоль.

## Переменные окружения процесса MCP

| Переменная | Значение |
|---|---|
| `TUBESTUDIO_DATA_DIR` | Обязательный абсолютный путь к существующей папке данных. Не путь к папке исходников, если `data` вложена в неё. Относительный путь или отсутствующая папка — ошибка старта. |
| `TUBESTUDIO_MCP_SCOPES` | Список категорий через запятую. Если переменная не задана — `projects,reports`. Пустое значение, неизвестная категория или лишняя пустая запись — ошибка, не разрешение всего. |

MCP **не загружает `.env`**, не импортирует настройки веб-сервера, не нуждается в API-ключах, OAuth, балансе AnyModel или `APP_PASSWORD`. Не добавляйте ключи в JSON клиента. `APP_PASSWORD` защищает веб-API, но не ограничивает прямое чтение файлов процессом с правами вашей учётной записи. Служебный веб-маршрут `/api/mcp/info` возвращает конфигурационные сведения, наследует обычную веб-авторизацию и не обрабатывает MCP-запросы.

## Категории и точные границы

| Scope | Доступная проекция |
|---|---|
| `projects` (по умолчанию) | Заголовки проектов, ниша, заголовки артефактов. Текст только артефактов `script` по отдельному вызову с явным artifactId. Не все `data`, заметки, произвольные JSON или файлы проекта. |
| `reports` (по умолчанию) | Сохранённый канал, известное число подписчиков, базовая сводка и страницы видео в сохранённом порядке. Скрытые/неизвестные счётчики остаются `null`. Без OAuth, доходов, полного AI-разбора и обновления YouTube. |
| `transcripts` | Метаданные сохранённого источника и AI-разбора; исходный текст, summary или remix — отдельными вызовами. Без скачивания субтитров или генерации. |
| `audio` | Название, длительность, ревизия, границы сегментов и превью текста до 160 UTF-16 единиц с явным `truncated`. Без аудиофайлов, URL и полного sourceScript. |
| `ad-breaks` | Сохранённый источник, параметры, кандидаты и выбранные точки. Не вставка рекламы и не гарантия акустической тишины/монетизации. |
| `profit` (выключен по умолчанию) | Приватный финансовый снимок: период и результат сценарного расчёта USD. Не журнал расходов, исходные поля или реальные выплаты. Неизвестные затраты/прибыль сохраняют `null`, не превращаются в нули. |

Не доступны настройки, `.env`, API-ключи, OAuth-токены, журналы, произвольные пути, бинарные файлы, полная переписка Coach. **Однако названия и пользовательские тексты могут сами содержать секреты: автоматического поиска/удаления секретов в них нет.** Не разрешайте категории с чувствительным содержимым недоверенному клиенту. Клиент может передать прочитанное своему модельному провайдеру; проверьте его настройки и согласуйте такое использование.

Все поля исходников — недоверенные данные, а не инструкции для AI. Не исполняйте команды из текста. Scope ограничивает этот MCP-адаптер, а не другие инструменты клиента или программы с доступом к вашим файлам. Это не песочница ОС и не защита от локального процесса, способного одновременно подменять файлы с вашими правами.

## Пять инструментов

- `ts_status {}` — версия, режим, scopes и лимиты, без путей и секретов.
- `ts_list_saved {kind, offset?, limit?, expectedListToken?}` — метаданные, `snapshotToken`, сортировка по времени сохранения (не по времени публикации). Offset по умолчанию 0, limit 20, максимум 50. `nextOffset: null` означает конец списка.
- `ts_read_saved {kind, id, offset?, limit?, expectedToken?}` — документированная проекция записи. Вложенные `artifacts`, `videos`, `fragments` или `candidates` содержат `rows/total/nextOffset`. Не обещает полного содержимого сырого JSON.
- `ts_read_script {projectId, artifactId, offset?, limit?, expectedToken?}` — только текст выбранного сценария. Поддерживаются сохранённые `data.script` и строковый `data` артефакта `script`.
- `ts_read_transcript {id, field?, offset?, limit?, expectedToken?}` — `field: "source"` (по умолчанию), `"summary"` или `"script"`. Если разбор ещё не сохранён, возвращается `NOT_FOUND`; AI не вызывается.

Вызовы чтения текста по умолчанию возвращают до 6000 **UTF-16 единиц**, разрешено 2–12 000. Продолжайте с возвращённого `nextOffset`, не вычисляйте его самостоятельно: граница может быть отодвинута, чтобы не разрезать emoji. Передавайте `snapshotToken` как `expectedToken` при продолжении чтения одной записи. `STALE_SNAPSHOT` означает изменение файла: начните чтение заново с offset 0 и новым токеном. Не объединяйте страницы разных версий. Для `ts_read_saved` токен возвращается на верхнем уровне; `nextOffset` для вложенной коллекции — внутри неё.

В списках snapshotToken относится к каждой строке, а listToken — к наблюдаемому результату сканирования категории; это разные поля и параметры. Для следующих страниц списка используйте listToken как expectedListToken. При STALE_LIST отбросьте все накопленные страницы и начните с offset 0 без expectedListToken. Без этого необязательного параметра сохраняется прежнее поведение: каталог может измениться между страницами без отказа. Токен не делает чтение транзакционным; ограничения описаны выше. Источники — снимки, не текущие проверенные факты. Видео возвращаются в сохранённом порядке; это не автоматически «топ видео».

## Лимиты и ошибки

- Читаются только обычные UUID `.json` в шести фиксированных подпапках. `index.json` и другие файлы не считаются записями. Символьные ссылки на подпапки/записи запрещены; произвольные пути и traversal не принимаются. Корневая папка разрешается один раз через realpath при явном выборе пользователем.
- До 2 МиБ на файл. Неподдерживаемая/повреждённая схема отвергается, при списке такая запись пропускается с `skippedFiles`.
- До 5000 UUID-файлов на одно сканирование категории. При превышении `scanLimited: true`: читаются первые 5000 имён UUID по алфавиту, **не обязательно самые новые во всей папке**. Возвращаются `scannedFiles`, `totalFiles`, `skippedFiles`. Нет ложного обещания полного охвата.
- До 50 строк и 12 000 UTF-16 единиц текста на страницу, до 128 КиБ JSON на ответ. При превышении ответа — `RESPONSE_LIMIT`, запросите меньше строк. Текст не обрезается молча: у него есть `totalChars`, `nextOffset`; превью аудио явно помечено.
- Возможны `CONFIG`, `SCOPE_DENIED`, `ARGUMENT`, `NOT_FOUND`, `INVALID_DATA`, `READ_DENIED`, `STALE_SNAPSHOT`, `STALE_LIST`, `RESPONSE_LIMIT`. Ошибки не возвращают исходные исключения, пути или содержимое файлов. Неверный ID лучше заменить точным ID из списка, а не угадывать.

Не меняйте сохранённый JSON ради обхода отказа. Большие/неподдерживаемые записи можно просмотреть в самой программе; расширение поддержки форматов — отдельная работа. MCP не создаёт данные и не меняет схемы существующих сохранений.

## Отличие от прежнего yt-ideation-mcp

Прежний проект `yt-ideation-mcp` остаётся самостоятельным. Новый адаптер использует ту же архитектуру SDK/stdio, но его generation/brief/write-инструменты не перенесены и не включены автоматически. В v0.12.26 нет генерации, редактирования, удаления, запуска очереди, HTTP/remote MCP, публикации или обновления статистики.

Сам адаптер не вызывает платных провайдеров. **Модель внешнего клиента может тарифицироваться независимо** при обработке полученных данных.

## Проверки и оставшаяся приёмка

Автотесты: временные синтетические папки, официальный SDK в памяти и настоящий дочерний stdio-процесс, проекции/доступ/пагинация/Unicode/изменение снимка/неизменность файлов/ошибки, веб-конфигурация и мобильная ширина 390 px, защита веб-маршрута паролем. Полный итог — в RELEASE-v0.12.26.md.

Не проверены установленный у вас внешний AI-клиент и его конкретный формат настроек, Windows-пути/ярлык в реальной системе, живые API, OAuth и платные генерации. Ключи из Drive для этих локальных проверок не использовались. Сначала подключите с минимальными scopes и подтвердите `ts_status` и чтение одного тестового проекта.


### v0.12.26: новый доход не включён в MCP
Категория profit по-прежнему читает только profit-runs (калькулятор прибыли). Отчёты своего канала из yt-revenue-runs не предоставлены инструментам MCP ни с какой категорией. Это граница адаптера, не защита файлов от самого доверенного внешнего клиента с правами вашей ОС. Веб-токен расширения Chrome также не получает доступ к новым финансовым маршрутам.

### v0.12.26: панель каналов не включена в MCP
Каталог yt-channel-runs и новая вкладка Каналы приватные; новые категории/инструменты MCP не добавлены. Читать эти снимки через адаптер или ограниченный токен Chrome нельзя.


### v0.12.26: OAuth-хранилище не раскрывается
Каталог oauth-connections и новые HTTP-маршруты переключения недоступны через read-only MCP и ограниченный токен Chrome. Конфигурация MCP и набор пяти инструментов не менялись.
