# TubeStudio v0.12.12 — локальный журнал A/B

## v0.12.12 — локальный журнал A/B-проверок

- Моя аналитика → Журнал A/B: план 2–3 вариантов заголовка/обложки, гипотеза, ручные периоды, показы и CTR. Без OAuth, AI, платных вызовов и изменения YouTube. Обложки — описания/имена файлов, без загрузки изображений.
- Пустые показатели остаются неизвестными. Разницы CTR в п.п. описательные, не статистическая значимость, причинный эффект или автоматический победитель. Решение автора — отдельно, с обоснованием, только для завершённой проверки.
- Сохранение создаёт отдельную версию с parentId/experimentId, включая ветвление от старого снимка. История 50, переходы к предыдущему/первому снимку, подтверждение замены несохранённого черновика, Markdown/JSON сохранённого результата и общий ZIP-перенос. Ошибка не стирает прежний результат.
- Каталог ab-test-runs не добавлен в MCP; токен Chrome не имеет доступа к приватному журналу. Повреждённые/недоступные файлы отмечаются без удаления; сканирование ограничено 5000 файлов.
- Подробности: AB-JOURNAL-README.md, RELEASE-v0.12.12.md. Пункт 12 остаётся частичным: автоматические CTR/показы/результаты A/B, доход и многоканальная панель не добавлены. Весь план не завершён. Исторические PDF/DOCX v0.11 не пересобраны.

## Обновление

1. Завершите задания и сделайте резервную копию всей установки, фактической DATA_DIR, `.env`, промптов и собственных изменений кода. Общий ZIP может содержать OAuth-токены и приватные данные: не публикуйте его. `.env` сохраните отдельно.
2. Остановите сервер. Распакуйте архив отдельно и перенесите **содержимое** `tubestudio` в существующую папку программы с заменой файлов. Не создавайте вложенную `tubestudio/tubestudio`, не удаляйте `.env` и данные: действующих данных и секретов в архиве исходников нет.
3. Если редактировали код/промпты, сначала сравните файлы и сохраните свои правки; замена может их перезаписать. `.env.example` не заменяет ваш `.env`.
4. Windows: запустите `update-windows.bat`, дождитесь успешной установки зависимостей и сборки. Node.js 20+ нужен. На других системах: `npm install`, `npm run build` из корня и обычный запуск. В браузере Ctrl+F5.
5. Откройте **Моя аналитика → Журнал A/B**. Для этого раздела OAuth и ключи не нужны. Сохраните план, затем вручную внесите наблюдения в новую версию. Существующая география и другие разделы сохранены.
6. Расширение Chrome осталось версии 1.1.0: если обновлено с v0.12.10, повторная установка не требуется. Полная программа и MCP сообщают версию 0.12.12, но функции и scopes MCP не расширены.

Полный архив содержит редактируемые исходники для VS Code/Cursor и других редакторов. `node_modules`, `dist`, реальные `.env`, данные, журналы запуска и приватные файлы исключены; нужна сборка. DEVELOPMENT-RU.md описывает структуру проекта.

## Проверки текущего выпуска

- Проверка типов трёх workspace и production-сборка прошли.
- Все 255 модульных тестов прошли, включая 20 новых: строгая схема вариантов/решений, даты, числовые границы и неизвестность, нулевой знаменатель, разность CTR в п.п. без победителя/кликов, предупреждения, отсутствие внешних вызовов, версии и параллельные ветки, закреплённая идентичность, ошибки без потери снимков, UUID/повреждение/ссылки/размеры, история 50/предел 5000, перенос каталога, экранирование и сохранённый Markdown.
- Все 108 браузерных/интеграционных тестов прошли, включая 8 новых: локальный план без OAuth, Unicode/безопасный текст, три варианта и ручной итог, неизменяемые версии, сохранённый экспорт JSON/Markdown, история/подтверждение замены черновика/ветвление, ошибки без потери данных, обложки без загрузки URL, нули/неизвестность, пароль и запрет токена Chrome, мобильные 390 px/Справка и настоящий ZIP export → import со связями версий.
- Новые тесты выполнялись на временных искусственных данных с блокировкой внешних запросов сервера. Реальные ключи и Drive-файлы не использовались. Не проверены реальный эксперимент/показатели YouTube, живой OAuth и внешние провайдеры, Windows/ярлык и установленное расширение Chrome на текущем YouTube.
- Это локальная регрессия, не живая приёмка всей программы. Исторические PDF/DOCX v0.11 не пересобраны. Vite предупреждает о крупном чанке Справки; сборка успешна.

## Что ещё требует приёмки

Сохранение реального плана и ручной перенос раздельных показателей вариантов проверяются пользователем по собственному исходному отчёту. Локальные искусственные данные не подтверждают реальный результат эксперимента. Для проверки OAuth нужен вход в собственный канал в программе, не ключи провайдера и не отправка токенов в чат. Реальные ключи/Drive-файлы не использовались. Запуск Windows/ярлык, живой YouTube/расширение Chrome и доступность внешних провайдеров этим выпуском не подтверждены. PDF/DOCX v0.11 не обновлены.
