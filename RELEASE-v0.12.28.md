# TubeStudio v0.12.28 — проверяемые похожие каналы

## Результат этапа
Продолжен пункт 3 расширенного плана. Новые сравнения Niche Finder v2 закрепляют публичные поля видео/канала и время расчёта. В раскрываемой базе каждой карточки видны исходные ID/названия/каналы/даты/длительности/известные просмотры, участие в среднем/медиане/частоте, причины исключения, точные границы интервала и формула частоты. Текстовая база буквального совпадения тоже доступна.

Ноль остаётся нулём, неизвестное — неизвестным. Повторные ID и видео другого канала не входят в расчёты. Группы ≤180/>180 секунд рассчитываются из известной длительности, а не кешированного флага Shorts; это не официальный формат. Для просмотров нужны возраст ≥48 ч и известный счётчик; для частоты свежие/без просмотров допускаются, если подходят группа и дата. При чтении v2 производные показатели пересчитываются локально из закреплённой базы, не из текущего времени/новых настроек и не из непроверенных сохранённых агрегатов.

Доля каналов ≥100 тыс. подписчиков — только описание известной части выборки, не насыщенность/конкуренция/спрос. Число ID поиска и число кандидатов с метаданными показаны отдельно. Условный сценарий RPM вынесен в раскрываемый блок; монетизация и фактические доходы не установлены.

Старые v1 сравнения сохранены как архивные без придуманных исходных видео; прежние значения не пересчитаны. Ошибка/отмена до фиксации не заменяют последний видимый сохранённый результат и JSON. Форма блокируется на время запуска; остановка доступна, уход отменяет незавершённый запрос. История 50, полный закреплённый JSON и общий ZIP сохраняются. Мобильный экран 390 px проверен. Исправлена повреждённая надпись «Язык поиска».

## Границы
Поиск всё ещё текстовый, одна страница до 20 каналов и одна страница до 50 загрузок на канал. Закреплены только возвращённые метаданные videos.list, недоступные строки не восстанавливаются. Нет следующих страниц, полного рынка, семантических рекомендаций, прогноза роста, внешней проверки истинности, автоматических экспериментов или реальных доходов. Сбой загрузок отдельного канала — неизвестность с предупреждением, не отсутствие его видео.

Кеш до 6 ч для поиска/каналов, 12 ч для загрузок; обход по явному переключателю. Время расчёта не выдаётся за время наблюдения каждого счётчика, запросы последовательны. Консервативная оценка квоты сохранена: `101 + 2×лимит + 104 в режиме исходного канала`, без повторов/резервов/диагностики/трекера. Отмена не возвращает уже потраченную квоту. Новый раздел не вызывает AI; новых OAuth-прав и MCP/Chrome-доступа нет.

История ограничивает файл 4 МиБ, каталог 5000 именами, проверяет схему/ID/версии/согласованность. Повреждённые/неподдержанные файлы и символические ссылки пропускаются, символический корень отклоняется. v1 с несовместимыми полями v2 отвергается, а не передаётся в компонент оснований. Это не шифрование, цифровая подпись, антивирус или гарантия Windows ACL. JSON/ZIP содержит запросы и исходные публичные тексты; храните приватно.

Реальные Google и Windows-обновление не проверены этим этапом. Полный пункт 3 и весь план не закрыты; единица CTR Reporting и автоматические результаты A/B остаются открытыми. Chrome остаётся 1.1.0, исторические PDF/DOCX не пересобраны. Прежние комментарии/ключевые слова/SEO/Daily Ideas и другие функции сохранены.

## Проверки
- Типы и production-сборки web/server/mcp: успешны; сохраняется предупреждение Vite о крупном чанке.
- Полная модульная регрессия: **500 тестов, ошибок 0**, из них 12 новых сценариев оснований Niche Finder. Независимая проверка арифметики по сырым синтетическим значениям: среднее/медиана 150 по четырём зрелым известным просмотрам; 6 дат/9 суток дают 3,89 публикации/неделю.
- Полная браузерная/интеграционная регрессия: **221 тест, ошибок 0**, включая 7 новых сценариев Niche Finder. После финальной пересборки и усиления проверки старой структуры повторно прошли **76 тестов Niche Finder/tools/MCP**, ошибок 0.
- Проверены точная принадлежность базы просмотров/частоты, граница 48 ч и суток, известный ноль/неизвестные/небезопасные счётчики, длительность/тип, повторы/чужой канал, неизменность исходников/закреплённого JSON, пересчёт v2 без сети, старый v1, несовместимые/повреждённые/подменённые ID/версии, символические ссылки/размеры, HTTP/язык/лишние поля/размер/невалидный JSON до постановки задания.
- Браузер: настоящий локальный HTTP/SSE с синтетическим YouTube; одна страница поиска/метаданных/загрузок, отсутствие автозапуска при открытии/auto-ссылке, сырой текст Unicode/HTML, нули/скрытые, группы и локальные фильтры, закреплённый JSON после изменения формы, предыдущий результат и байты файлов после ошибки/отмены/ухода, частичный сбой загрузок, локальное открытие истории, предупреждение v1, настоящий ZIP export/import, пароль и запрет Chrome-токена.
- Просмотрены 4 состояния: пустой 390 px, раскрытые источники 1440 px, группа длительности/источники 390 px, частичный сбой и история 390 px. Проверены отсутствие переполнения/перекрытий и буквальное отображение HTML-подобного текста; внешние картинки/платные запросы не загружаются. После просмотра убрано вертикальное растягивание соседней карточки при раскрытии длинной базы.
- Тесты работают во временных каталогах с фиктивными ключами и блокировкой неизвестных внешних запросов; пользовательские данные и реальные платные провайдеры не использовались.
- Переносимая Windows-файловая проверка: PASS на Linux, не приёмка Windows/COM/ярлыка/обновления.
- Исходный архив исключает .env, пользовательские данные/OAuth, node_modules, dist, логи и ZIP. Проверяются целостность, обязательные новые/старые файлы и известные значения секретов (не универсальный детектор любых секретов).

## Обновление
Сделайте защищённую копию установки, .env и DATA_DIR, завершите задания и остановите сервер. Распакуйте архив отдельно, перенесите содержимое `tubestudio` в прежнюю папку без дополнительной вложенной `tubestudio`, не удаляя .env/data. Запустите `update-windows.bat`, дождитесь успешной сборки и обновите вкладку. Старые отчёты не переписываются автоматически; ZIP-восстановление проверяйте в отдельной тестовой установке.
