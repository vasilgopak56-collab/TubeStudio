# TubeStudio v0.12.19

## Выполнено: первый шаг этапа установки Windows

- Исправлен `create-desktop-shortcut.bat`: управляющий символ вертикальной табуляции вместо буквального `\v` ломал путь к Windows PowerShell. Сохранены CRLF, ожидание в окне и возврат кода результата.
- Добавлен `diagnose-windows.bat`: проверка файлов, Node.js, наличия зависимостей/сборки и существующего ярлыка. На Windows читаются перенаправленный рабочий стол и свойства .lnk, без сохранения ярлыка. Проверяются текущая установка, команда запуска и значок.
- Добавлен `npm run check:windows` для переносимой проверки UTF-8, CRLF, управляющих символов, обязательных файлов, путей PowerShell и BOM русских PS1.
- Проверка поддержки `--env-file-if-exists` использует `node --help`, а не `allowedNodeEnvironmentFlags`: последний относится к NODE_OPTIONS и ошибочно давал FAIL на поддерживаемом Node.js.
- Отчёт сохраняется только по `--report` (включён в BAT); предусмотрен резервный путь в TEMP. Разделены версия исходников, успешная проверка конкретных пунктов и реальная приёмка.
- Актуализированы инструкции обновления, открытия исходников, диагностики и ручной приёмки. Подробности: WINDOWS-CHECK-README.md.

Диагностика не запускает сервер, браузер, npm, обновление и API; не читает .env, OAuth, проекты и журналы приложения. Не создаёт и не изменяет ярлык. Сама процедура update-windows.bat, в отличие от диагностики, устанавливает зависимости, собирает приложение и создаёт ярлык.

## Проверено локально на Linux / Node.js 24.14.1

- Типы и production-сборка трёх workspace — успешно.
- **413 модульных тестов — успешно**, на 15 больше v0.12.18. Покрыты исходный управляющий символ, неправильный путь, LF BAT, некорректный UTF-8, отсутствие файла, BOM PowerShell, malformed COM-ответ, перенаправленный/отсутствующий Desktop, чужая установка, изменённая команда и значок, Unicode/кавычки в пути, read-only состав PowerShell-пробы, поддержка Node.js и реальные коды CLI/запись отчёта с искусственным секретом, который не выводится.
- **160 браузерных/интеграционных тестов — успешно**: регрессия существующих функций, включая обновлённую версию MCP. Новых экранов в этом выпуске нет.
- `npm run check:windows` — PASS для всех переносимых проверок.
- Режим `--diagnose` на Linux возвращает **код 2** и WARN о невыполненной Windows-проверке, а не ложный полный успех. Проверка поддержки Node.js проходит.
- Тесты используют временные искусственные данные; реальные API/платные модели и пользовательские ключи не использовались. Сборка сохраняет предупреждение Vite о крупном чанке Справки; сборка успешна.

Архив содержит полные редактируемые исходники, не только патч. Не включены .env, ключи, OAuth, пользовательские данные, node_modules, dist и журналы. Chrome остаётся 1.1.0; PDF/DOCX v0.11 остаются историческими и не пересобраны.
