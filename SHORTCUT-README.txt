TubeStudio — ярлык Windows

1. Распакуйте файлы этого обновления ВНУТРЬ существующей папки TubeStudio
   (рядом со start-windows.bat). Не создавайте отдельную установку.
2. Запустите update-windows.bat для обновления или start-windows.bat
   для первой установки. После успешной сборки ярлык создаётся автоматически.
   Для ручного пересоздания используйте create-desktop-shortcut.bat.
3. Дальше открывайте TubeStudio через ярлык на рабочем столе.

Окно командной строки при обычном запуске не показывается.
Сервер стартует в фоне, браузер открывается после готовности.
Если TubeStudio уже запущен, второй сервер не создаётся.
Ключи, проекты и подключение YouTube не изменяются.
Node.js должен оставаться установленным.
После переноса папки заново создайте ярлык.
Закрытие браузера не выключает фоновый сервер; он работает до
завершения процесса Node.js или перезагрузки Windows.
Ошибки запуска сохраняются в launcher-logs внутри папки программы.
Если Windows запрещает PowerShell/COM, не отключайте корпоративные
политики. start-windows.bat может запускать сервер, но создание ярлыка
в нём также зависит от PowerShell. VBScript для ярлыка больше не нужен.

Проверка YouTube:
Выберите период «Год» в «Моя аналитика» и сравните с YouTube Studio.
Если нули остаются при наличии просмотров, проверьте выбранный канал,
дату Windows и наличие сообщений об ошибках. Предупреждение «Есть
проблемы с ключами» внизу — отдельно проверьте Настройки → Ключи API.

Ярлык с постоянным именем TubeStudio заменяет предыдущий и указывает
на папку, из которой выполнена установка/обновление. Если есть несколько
копий программы, последняя успешно создавшая ярлык копия получает этот ярлык.
Это не поиск новых версий в интернете. Обновляйте файлы в одной папке,
чтобы сохранить данные. При ошибке создания ярлыка используйте батник запуска.

ИЗМЕНЕНИЯ v0.12.2
Установщик определяет реальную папку рабочего стола Windows, включая
перенаправление в OneDrive, и записывает фактический путь сохранённого ярлыка.
После сохранения .lnk перечитывается и проверяется. VBScript для запуска
больше не требуется: ярлык вызывает windows/launch.ps1 через PowerShell.

Если ярлыка нет:
1. Запустите create-desktop-shortcut.bat в папке обновлённой программы.
   От своего обычного пользователя, НЕ от имени другого администратора.
2. Окно остаётся открытым. Проверьте строку SUCCESS и полный путь .lnk.
3. Нажмите F5 на рабочем столе; проверьте, что смотрите именно указанную
   папку рабочего стола, а не другую папку OneDrive/профиля.
4. При ERROR сохраните текст окна и launcher-logs/shortcut-install.log.
   Если папка программы недоступна для записи, журнал создаётся во временной
   папке Windows: %TEMP%\TubeStudio-launcher-logs\shortcut-install.log.
   Если PowerShell не запустился совсем, журнал может отсутствовать:
   тогда нужен текст ошибки из окна BAT.
5. Не отключайте защиту Windows или корпоративные политики ради ярлыка.
   Прежний запуск start-windows.bat остаётся доступным.

Исправления проверены по коду и локальным тестам в Linux.
Успешная работа на вашем Windows требует отдельной проверки.

ИЗМЕНЕНИЯ v0.12.19
Исправлен скрытый управляющий символ в пути PowerShell ручного BAT.
Для проверки файлов, Node.js и существующего ярлыка запустите
diagnose-windows.bat. Он не запускает сервер и не создаёт ярлык.
Отчёт: launcher-logs\windows-check.log; возможен резервный путь %TEMP%.
PASS не заменяет ручной запуск. Подробности: WINDOWS-CHECK-README.md.
