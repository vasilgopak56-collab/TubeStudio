# 0.12.140-preview.1 — согласие на генерацию раскадровки из озвучки

## Что изменено
- В «Раскадровке из озвучки» сервер требует отдельного подтверждения перед каждым текстовым запросом генерации: библия стиля, батчи сцен, повторы транспорта, исправления некорректного JSON и резервные модели. Неподтверждённый запрос не отправляется, даже если запуск задания сделан напрямую через API.
- Реализованы проверки непосредственно перед отправкой для AnyModel, Anthropic и Gemini, используемых этим маршрутом. Решение действует только на один конкретный запрос и тариф; при истечении двух минут, отказе или отмене этот запрос блокируется. При изменении тарифа потребуется новый запуск.
- Начальное предупреждение поясняет, что запросов может быть несколько и промежуточные промпты при остановке не сохраняются. Карточка решения показывает фактического провайдера и модель. Отдельное подтверждение распознавания из .139 сохраняется.
- Исправлены две ошибки выпуска .139: версия MCP теперь соответствует версии приложения, а подробная Markdown-документация создана заново из встроенной справки. В браузерном тесте ветвления добавлено ожидание окончания сохранения принятого шага, прежде чем читать ревизию.

## Ограничения
- Серверное подтверждение распространяется только на распознавание и текстовую генерацию в «Раскадровке из озвучки». Обычная раскадровка из текста и остальные платные инструменты им пока не защищены.
- Это не лимит стоимости и не резерв бюджета. Пользователь разрешает один запрос, а не конкретную сумму. Уже отправленные запросы могут быть оплачены и при ошибке, отказе от последующего шага или отмене. Смотрите реальные расходы у провайдера.
- После остановки или отказа промежуточные библия стиля/сцены нового запуска не сохраняются в файл результата. Если перед запуском сохранены изменения фрагментов, прежний результат может быть сброшен. При повторном запуске уже оплаченные шаги могут выполняться заново: сначала проверьте состояние и расходы.
- При потере связи не запускайте задачу повторно без проверки: она может продолжаться. Перезагрузка страницы не восстанавливает управление старым заданием; неподтверждённые согласия истекают, но отправленные запросы могут быть оплачены.
- Механизм не защищает от пользователя или программы, которые уже получили доступ к локальному приложению и могут принимать решения через API; это не защита от вредоносного ПО.
- Тесты с моделями используют только фиктивные ответы и ключи. Реальные API, тарификация и настоящий запуск на Windows не проверялись. Статическая проверка Windows не заменяет запуск системы.

## Установка
Сделайте резервную копию и остановите сервер. Обновите файлы приложения, сохранив существующие `.env`, папку данных и проекты; запустите `update-windows.bat`. Убедитесь в версии работающего сервера. Исторические инструкции .139 и ранее описывают тогдашнее поведение.
