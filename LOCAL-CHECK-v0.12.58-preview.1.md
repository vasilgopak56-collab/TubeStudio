# Локальная проверка 0.12.58-preview.1

Изменения: четыре главы справки, версия, документация выпуска, тесты. При сравнении исходников приложений с архивом 0.12.57 изменились только help.ts и две строки версии (server version.ts, mcp store.ts). Бизнес-логика и промпты не менялись.

Проверки в Linux:
- npm run typecheck — успешно во всех рабочих пространствах.
- npm run build — успешно.
- npm run test:unit — 741 тест успешно.
- node --test tests/e2e/help-docs.test.mjs — 18 тестов успешно.
- npm run check:windows — статическая проверка успешно; нативный запуск Windows не выполнялся.

Сверены с исходниками detector.ts, humanizer.ts, rater.ts, scorecard.ts и страницами этих инструментов. Новые тесты проверяют ограничения документации, поиск/читаемость четырёх глав на 1440×1000 и живую проверку Humanizer без LLM. Первый запуск теста имел неоднозначный селектор «Сценарий» (совпал с меню); селектор уточнён до textbox, итоговый полный запуск 18/18.

Визуально просмотрены четыре настольных снимка таблиц полей. Горизонтальное переполнение и JS-ошибки проверяются тестом. Для CRUD стилей/промптов используются изолированные временные данные и копия шаблонов; внешние запросы браузера блокируются. Платные AI-запуски, реальные результаты моделей, Google OAuth и мобильные экраны не тестировались. Остальные исторические браузерные сценарии целиком не запускались.

Руководство сгенерировано из встроенной справки, 62 главы, покрытие 42 пунктов меню. ZIP не содержит node_modules, личных data, .env, логов и устаревших DOCX/PDF.
