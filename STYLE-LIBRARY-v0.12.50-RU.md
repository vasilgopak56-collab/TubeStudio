# TubeStudio 0.12.50-preview.1 — собственная библиотека стилей

## Что изменилось

Взята ваша исходная версия 0.12.48-preview.1 с модулем сравнения каналов. Это добавление библиотеки и организация меню, не замена сценариста или прежних визуальных профилей.

- Новый раздел **Производство → Библиотека стилей**.
- 40 описаний из присланной библиотеки + отдельный согласованный **2D POV History · выразительные герои**. Итого 41 встроенный стиль.
- Старый `animated_2d_history`, остальные стили ниши и прежние P1–P18 не заменены. При пустом выборе библиотеки генерация работает по прежней логике.
- Свои стили: добавление, копирование, редактирование, удаление с подтверждением; поиск, группы, фильтр встроенных/своих.
- Встроенные карточки защищены: сначала **Копия**, затем правки. Исходник остаётся.
- Выбор библиотеки доступен в **Раскадровке**, **Из озвучки** и на этапе раскадровки в **Одной кнопке**. Обложки и сценарист не меняют стиль автоматически.
- Левое меню разделено на 8 сворачиваемых групп. Есть **Раскрыть всё / Свернуть всё**, состояние запоминается в браузере; при переходе к инструменту раскрывается его группа. В узкой панели иконок группы тоже сворачиваются.

## Как пользоваться

1. Откройте **Производство → Библиотека стилей**.
2. Найдите карточку и нажмите **Для раскадровки** или **Из озвучки**.
3. В форме проверьте поле **Стиль из библиотеки**. Можно выбрать стиль и непосредственно в форме.
4. Выбранная библиотека заменяет визуальную отрисовку ниши и прежний визуальный пресет. Стиль ниши по-прежнему задаёт сегментацию/темп. Поле **Свой стиль** имеет высший приоритет — очистите его, если старые указания конфликтуют с выбором.
5. Начните с первого батча и нескольких связанных кадров/клипов, а не целого эпизода. Локальные тесты проверяют передачу промптов, не гарантируют художественный результат конкретной модели.
6. Чтобы вернуться к старому поведению, выберите **Не использовать — прежний стиль / пресет**.

## Добавление своего стиля

**Добавить стиль** → название, группа, описание, постоянные визуальные признаки, тип анимации, инструкция анимации и negative → **Сохранить стиль**.

Три типа анимации:
- **Сюжетное действие**: исходное состояние → физическое действие → результат → реакция. Камера поддерживает сцену, но не заменяет событие.
- **Рисование / появление**: порядок появления линий/элементов, как для whiteboard. Правила физического действия персонажа не навязываются.
- **Свободная анимация**: используется текстовая инструкция выбранного стиля.

Промпты предпочтительно писать на английском; интерфейс и описание могут быть на русском. Стиль не переписывает озвучку. Внутри эпизода сохраняйте идентичность персонажа; между эпохами меняйте волосы, одежду, оттенок кожи, профессию и реквизит, сохраняя общий язык рисунка.

## Импорт, экспорт и хранение

- **Экспорт своих** скачивает только пользовательские стили. Встроенные уже поставляются с программой, дублировать их при переносе не нужно.
- **Импорт JSON** принимает экспорт TubeStudio или исходный массив `styles.json` из присланного ZIP. PDF/Markdown через эту кнопку не импортируются.
- Импорт создаёт новые копии, не перезаписывает существующие ID. При ошибке ни одна запись из файла не добавляется. Повторный импорт создаёт ещё один набор копий.
- Лимиты: JSON до 5 МБ; до 200 пользовательских стилей, локальный файл библиотеки до 4 МБ. При переполнении сохранение отклоняется без потери прежних записей.
- Пользовательские данные: `DATA_DIR/visual-styles.json` (обычно `data/visual-styles.json`). Файл включается в общий резервный ZIP штатного механизма. Не копируйте чужой файл поверх своего — используйте импорт.
- Удаление стиля не меняет старые результаты. Если удалённый стиль выбран в новом задании, генерация отклоняется до запроса к AI, а не незаметно подменяется другим стилем.
- В результатах раскадровки сохраняется снимок выбранного стиля с ревизией. JSON-экспорт сохраняет этот снимок. Редактирование библиотеки не меняет уже готовые результаты.
- Одновременные правки одного стиля из разных вкладок требуют обновления устаревшей вкладки.
- Повреждённый файл не превращается в пустую библиотеку и не затирается при следующем сохранении. Восстановите его из резервной копии.
- Добавление, поиск, импорт и экспорт локальные, платные AI не вызывают. Генерация раскадровки/изображений оплачивается по прежним настройкам провайдера.

## Источники и границы

`docs/style-library-source.md` сохранён как источник описаний предоставленной библиотеки. Названия Golpo — метки происхождения описаний, не интеграция с Golpo и не обещание точного повторения его рендера. Это собственный формат и собственное хранилище TubeStudio.

Согласованный визуальный навык и его референсы: `skills/2d-pov-history-style/`. Изображения и PDF не отправляются в модель автоматически: сейчас применяется текстовый профиль. Навык не перенастраивает сценарист и не создаёт тайных платных вызовов.

Генератор **Видео и Shorts** по-прежнему делает черновой монтаж, в том числе Ken Burns. Выбор action-стиля изменяет animation-промпты раскадровки; он не превращает существующий монтажный движок в генератор физической анимации.

## Обновление Windows

1. Сделайте резервную копию данных через настройки; сохраните свою `.env`.
2. Полностью остановите TubeStudio штатным `stop-windows.bat`.
3. Распакуйте архив во временную папку. Содержимое вложенной папки `tubestudio` скопируйте в вашу текущую папку программы с заменой файлов. Не создавайте случайно второй уровень `tubestudio/tubestudio`.
4. Не удаляйте и не заменяйте свои `data`, `.env` и ключи. Архив не содержит пользовательских данных или ключей.
5. Запустите `update-windows.bat`, затем обычный ярлык/`start-windows.bat`.
6. После запуска проверьте версию **0.12.50-preview.1** и новый пункт **Библиотека стилей**. Если показывается старая версия — обновите страницу и проверьте, что запущена нужная копия программы.

Проверки выполнены в Linux; запуск BAT/ярлыка на вашей Windows и реальные платные генерации не выполнялись.
