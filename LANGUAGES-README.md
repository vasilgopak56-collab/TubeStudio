## Где выбирать

- Настройки → язык контента по умолчанию.
- Поиск тем, Сценарист, SEO, Обложки.
- AI-детектор, Живой голос, Оценка сценария.
- Озвучка → язык списка голосов.
- Голос канала → язык образцов автора.
- Одна кнопка → язык контента; «Из настроек» использует общее значение.
- Настройки → Исследование → язык выдачи. «Авто» использует язык контента. Поиск ключей, видео/аномалий наследует эти настройки, отдельный дублирующий список не добавлен.

Языки перечислены в порядке запроса. Используются стандартные коды языков (японский ja, корейский ko, иврит he, украинский uk), а не коды стран JP/KR/IL/UA.

## Что изменено

Выбранные языки сопоставляются с полными названиями для промптов нейросетей. Профиль голоса больше не переименовывает все языки, кроме английского, в русский и не применяет французский профиль к испанскому тексту. Старые профили с несовпадающим внутренним языком надо пересоздать из образцов.

В озвучке смена языка сбрасывает явно выбранный голос и запрашивает голоса нового языка. Если сохранённый Edge-голос относится к другому языку, по умолчанию выбирается совпадающий голос из полученного каталога; если такого нет — многоязычная модель Fish. На нерусском языке ошибка Fish больше не вызывает скрытую подмену на русский Dmitry. Явно выбранную пользователем модель программа уважает; она должна поддерживать язык текста.

## Ограничения

- Интерфейс остаётся русским. Это выбор языка создаваемого контента, а не перевод всех кнопок и справки.
- Наличие языка в списке не гарантирует качество каждой внешней модели. Доступность голосов и произношение зависят от провайдера; для платной генерации нужны собственные ключи и баланс.
- Выбор языка озвучки не переводит исходный текст: он должен уже быть написан на нужном языке. Перед полноценной генерацией прослушайте образец.
- Словари локальных ИИ-маркеров и определение обращений настроены для русского и английского. На других языках не подставляются чужие словари, используются общие метрики. Такие оценки приблизительны и не доказывают авторство.
- Подсчёт слов и ритма для китайского, японского и других текстов без обычных пробелов приблизительный. Выбирайте объём в символах и сверяйте реальную озвучку. Оценка длительности не заменяет таймкоды из аудио.
- Раскадровка из озвучки распознаёт оригинальный язык автоматически, без перевода. Image/video-промпты по-прежнему создаются по правилам соответствующего инструмента, обычно на английском — список языков не меняет их формат.
- Полная PDF/Word-документация в архиве — v0.11; этот файл содержит дополнение v0.12. Создание ярлыка на компьютере пользователя пока отдельно не диагностировано.

## Установка

Сохраните резервную копию, остановите текущий сервер, скопируйте содержимое папки tubestudio поверх своей установки, не удаляя `.env` и папки данных, затем запустите `update-windows.bat` и дождитесь завершения сборки. После запуска обновите вкладку Ctrl+F5. Для правки исходников откройте `DEVELOPMENT-RU.md`.
