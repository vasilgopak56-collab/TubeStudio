TubeStudio — коротко о главном
==============================

ПЕРЕД ПЕРВЫМ ЗАПУСКОМ
1. Если архив скачан из интернета: щёлкните по архиву правой кнопкой →
   «Свойства» → внизу отметьте «Разблокировать» → «ОК». Только потом
   распаковывайте. Так Windows не будет мешать запуску.
2. Распакуйте архив в папку, где лежит прежняя TubeStudio, например
   D:\Desktop\Программы\TubeStudio
   Появится подпапка TubeStudio-<версия>. Если Проводник предложит
   папку «TubeStudio-<версия>-windows» — так тоже можно: программа
   найдёт данные и прежнюю версию на уровень выше.

ПЕРВЫЙ ЗАПУСК
Откройте подпапку TubeStudio-<версия> и дважды щёлкните
«Запустить TubeStudio.cmd». Программа сама:
  • остановит старую версию, если она работает;
  • скопирует проекты и настройки в папку TubeStudioData рядом
    (старая папка не удаляется и не меняется);
  • перенесёт ключи из старого файла .env в защищённое хранилище Windows;
  • создаст на рабочем столе ярлык «TubeStudio»;
  • откроет программу в браузере.
Устанавливать Node.js не нужно — всё нужное уже внутри.

КАЖДЫЙ ДЕНЬ
  • Запускайте программу ярлыком «TubeStudio» на рабочем столе.
  • Пароль не нужен: ярлык открывает программу с одноразовым ключом.
  • Закрыли вкладку браузера — просто нажмите ярлык ещё раз.
  • Закрыть программу — кнопка «Выход» внизу левого меню. Если идёт
    работа (генерация, озвучка, монтаж), программа предупредит.

С ЧЕГО НАЧАТЬ (ВЫПУСКИ 1 «ТЕМЫ И СЦЕНАРИЙ» И 2 «ВИЗУАЛ»)
В левом меню — группа «Студия»:
  1. «Каналы» — профиль канала: ниша, язык, длина ролика и
     1–5 каналов-образцов.
  2. «Идеи для канала» — кнопка «Найти идеи»: Радар находит ролики
     небольших каналов, набравшие во много раз больше обычного.
  3. «Сценарий» — «Взять идею →» открывает сценарий с готовой темой.
     Проверка текста бесплатна: хук, вступление, оговорки, повторы.
     Проверка фактов (поиск Google): неверное исправляется,
     непроверяемое убирается — дальше идёт исправленный текст.
  4. «Озвучка» — голос канала через Lumean, цена видна до заказа.
     Можно взять свой готовый шаблон Lumean: «Голос → Мой шаблон Lumean».
  5. «Визуал» (Выпуск 2) — картинки и анимация через G-Labs: сцены по
     озвучке, промпты в стиле канала, картинки, проверка «Принять /
     Переделать», клипы и файлы для монтажа.
Ключи AnyModel, YouTube, Lumean и G-Labs вставляются в «Настройки».

МОЗГОВОЙ ШТУРМ КАНАЛА (ВЫПУСК 2.1)
  1. Откройте «Помощник» справа внизу → «Мозговой штурм канала».
     Выберите проект, связанный с вашим каналом, или создайте новый.
  2. Выберите текстовую модель AnyModel, опишите задачу своими словами,
     укажите регион (например US). Нажмите «Посмотреть план и стоимость».
     Подтверждение запускает только подготовку поискового плана.
  3. Отдельно посмотрите и подтвердите поиск на YouTube, а затем запрос
     восьми идей. Необязательная проверка публичных загрузок каналов
     использует квоту YouTube API; её лимит виден до подтверждения.
  4. Выберите идею и дату первого ролика. Подтвердите создание черновика
     оформления и плана. Профиль канала, календарь и четыре картинки
     G-Labs меняются или запускаются только по отдельному подтверждению.
  5. Готовые картинки можно скачать из раздела «Картинки G-Labs».
     Проверьте текст и обрезку баннера для разных устройств.

  YouTube — неполная выборка, а оценки и предложенные темы — гипотезы.
  Проверка @адреса ищет публичный канал, но не подтверждает, что адрес
  свободен. Проверьте его в YouTube Studio. Результат не сохраняется.
  Исторические факты нужно проверить вручную.
  Цена AnyModel — ориентир, не предел списания; расход G-Labs показан
  отдельно и заранее может быть неизвестен. Закрытие окна Помощника
  не останавливает задачу; закрытие всей программы может её прервать.
  Если связь прервалась, проверьте проект и состояние задачи, прежде
  чем повторять запрос: он мог быть выполнен и оплачен.

КАК ПОДКЛЮЧИТЬ G-LABS (ТАРИФ MAX)
  1. Запустите G-Labs → вкладка «Webhook» → «Start» (или включите
     «Auto-start», чтобы запускалось само).
  2. Там же скопируйте «API key». В TubeStudio: «Настройки» → «Ключи API»
     → строка «G-Labs» → карандаш → вставьте ключ → «Сохранить ключ».
  3. Адрес по умолчанию http://127.0.0.1:8765 менять не нужно. Проверка —
     «Настройки» → «G-Labs» → «Проверить связь».
  Картинки и клипы тратят квоту аккаунтов G-Labs, деньги TubeStudio — нет.
  Если Webhook недоступен: в «Визуале» скачайте TXT с промптами
  (1 строка = 1 промпт) и загрузите его в G-Labs вручную.
Прежние разделы — в меню под кнопкой «Ещё — прежние разделы».

ВАШИ ДАННЫЕ И ДЕНЬГИ
  • Проекты, настройки и ключи лежат в папке TubeStudioData рядом с папкой
    программы. При обновлении её не удаляйте.
  • Ключи API хранятся зашифрованными (защита Windows для вашей учётной
    записи), открытым текстом на диске их нет.
  • Лимит расходов на сервисы — 20 $ в месяц. Когда он исчерпан, платные
    запросы останавливаются. Изменить: «Настройки» → «Лимит в месяц, $».
  • Озвучка Lumean оплачивается со счёта Lumean (LMC) и в лимит 20 $
    не входит. Цену программа показывает до заказа; повторное нажатие
    не создаёт второй заказ.

ОБНОВЛЕНИЕ
Распакуйте новую версию в ту же папку TubeStudio и запустите её
«Запустить TubeStudio.cmd». Она остановит старую, подхватит те же данные
и обновит ярлык. Папку старой версии после этого можно удалить.
Старую версию 0.12 (start-windows.bat в её папке) больше не запускайте:
она возвращает ярлык на себя, а после выключения компьютера может
не открыться с ошибкой «Папка данных уже занята».

ЕСЛИ ЧТО-ТО НЕ ТАК
  • Компьютер выключили, не закрыв программу, — ничего страшного:
    при следующем запуске она сама снимет оставшуюся блокировку.
  • «Остановить TubeStudio.cmd» — остановить программу, если кнопка
    «Выход» недоступна.
  • Журналы лежат в TubeStudioData\logs (launcher.log и
    server-console.log). Пришлите их, если нужна помощь.
