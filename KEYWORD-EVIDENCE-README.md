# Keyword Research — v0.12.27

**Исследование → Ключевые слова** (`/keywords`). Подсказки и поиск теперь разделены. В новом режиме нет выведенной из просмотров «частотности», балла конкуренции/популярности/шанса или автовыбора по этим эвристикам.

## Работа
1. Введите одну фразу 2–120 единиц UTF-16, язык и необязательный регион из двух заглавных латинских букв. Переход по ссылке (`q`, даже с `auto=1`) только заполняет поле. Не вводите секреты: выбранная операция отправляет фразу/язык/регион Google.
2. **Получить подсказки** — один свежий запрос к неофициальному `suggestqueries.google.com/complete/search`, `client=firefox`, `ds=yt`, `hl`, необязательный `gl`. Нет расширения фразы алфавитом/вопросами, Data API, AI или кеша. Сервис может измениться/не ответить; это не гарантированный официальный интерфейс YouTube.
3. Подсказки — до 30 уникальных непустых строк по 120 единиц UTF-16 в порядке ответа. Дубли объединяются по NFKC/нижнему регистру/ё→е/сжатию пробелов; сохраняется первый исходный текст. Пустые/слишком длинные пропускаются, исходная фраза искусственно не добавляется. Показано число полученных и отображённых строк и отсечение после 30, если оно было. Позиция не означает популярность/спрос.
4. **Подставить в форму** не запускает поиск. **Проверить фразу в поиске (до 102 ед.)** — отдельное действие для текущей формы. Оно запрашивает ровно одну свежую страницу `search.list`, `type=video`, `part=snippet`, `maxResults=50`, `order=relevance`, `safeSearch=moderate`, язык и необязательный регион. Затем один пакет `videos.list` для ID этой страницы и один пакет `channels.list` по уникальным каналам страницы. Следующая страница не запрашивается, кеш не используется. Для пустой страницы метаданные не запрашиваются.
5. Прочитайте все строки и методику. Поиск сохраняет порядок API, ID/заголовок/канал/дату из этой страницы, известные просмотры и подписчиков, статус метаданных/подписчиков. Недоступное видео остаётся строкой, а не исчезает из выборки. Если получение метаданных завершилось ошибкой, новая выборка не сохраняется: прежняя остаётся видимой; уже выполненные запросы могли израсходовать квоту.
6. Фразы выбираются вручную, до 30 уникальных. **Копировать** и **В SEO видео** работают с этим временным выбором. Переход в SEO заменяет текущий черновик ключей, но генерацию не запускает. Выбор не является частью снимка и теряется после ухода из раздела. Поиск также позволяет выбрать проверенную фразу. Автовыбор по «объёму/конкуренции» и AI-описание канала новая страница не вызывает.

## Что означают числа
- **Медиана просмотров**: только известные неотрицательные целые публичные накопительные счётчики возвращённых видео. Число известных и полученных строк показано отдельно. При чётном количестве — среднее двух центральных значений; без известных значений — null/«нет данных», не 0.
- **Подписчики**: знаменатель — уникальные ID каналов этой страницы, не количество видео. Если один канал представлен многими видео, его подписчики учитываются один раз. Скрытые и отсутствующие значения исключены из медианы и знаменателя «известных», а не заменены нулём. Публичные значения могут быть округлены YouTube.
- **Каналы с <10 000**: количество среди каналов с известными подписчиками, не процент всего рынка и не признак низкой конкуренции. Порог — описательный срез, не правило успеха.
- **Заголовки с фразой**: нормализованная подстрока (NFKC/регистр/ё/пробелы), знаменатель — все строки страницы. Без морфологии/семантики; HTML-сущности заголовка не декодируются. Это не точность поискового совпадения или замер спроса.
- Метаданные запрашиваются последовательно, не строго одновременно. Возраст видео, язык содержания, реальный статус Shorts/формат не выравниваются. Медиана разновозрастных счётчиков не является месячным объёмом поиска. Номер строки API не является реальной позицией у зрителей или поиском в их браузере.
- Нет частотности, поискового трафика/CTR/возможности ранжирования/монетизации, полного охвата рынка, причинного вывода или прогноза просмотров. Нет подсказок/пустая страница ≠ нет спроса. Отсутствие `nextPageToken` не гарантирует полный охват.

## Стоимость и приватность
Подсказки не используют единицы YouTube Data API или ключ, но это внешний запрос. Поиск: 100 базовых единиц + 1 videos + 1 channels при непустой странице, всего 102. Пустая страница — 100. Сетевые повторы и резервные ключи могут увеличить расход; `baseUnits` фиксирует только базовую успешную цепочку, не точный счёт Google за все попытки. Отмена не возвращает потраченную квоту. AI в этом разделе не вызывается.

Общая диагностика ключей приложения (включая минимальный запрос модели) и настроенный трекер работают независимо; открытие приложения не гарантирует отсутствия сети/расхода. История/JSON/ZIP/подстановка фразы сами не повторяют этот поиск или подсказки.

## История и совместимость
- Каталог `keyword-evidence-runs`: отдельный неизменяемый UUID-снимок каждой успешной операции. История показывает последние 50 обоих типов вместе, старые файлы автоматически не удаляются. JSON закреплён за видимым снимком, не изменённой формой. Ошибка/отмена до фиксации не заменяет прежний результат; отмена после успешного сохранения не удаляет его.
- Схема v1, файл до 256 КиБ, временный файл + rename, режимы 0600/0700 там, где ОС поддерживает. Не шифрование и не гарантия Windows ACL. Повреждённые/неподдержанные/символические ссылки пропускаются со счётчиком; при >5000 элементов каталога архивировать часть нужно при остановленном сервере.
- Сырой файл хранит источник; `summary` вычисляется при чтении по методике v1 и дополнительно возвращается в GET/JSON интерфейса. Поле `summary` в сыром файле не принимается. Строгая схема — не цифровая подпись и не доказательство подлинности счётчиков.
- Общий ZIP данных переносит `keyword-evidence-runs`. Снимки содержат введённые фразы/параметры и публичные строки: храните приватно. ZIP может содержать другие частные данные и активный OAuth — см. BACKUP-README.md.
- Новые снимки доступны как источник **Ключевые слова** в Daily Ideas: первые 10 подсказок либо названий видео в порядке снимка, без баллов/оценок спроса. Для поиска — ID/даты/известные просмотры. Отдельный локальный предпросмотр и явная AI-кнопка Daily Ideas сохраняются. Пустой источник для AI недоступен. Последние 50 новых снимков дополняют старый список источников.
- Старый `keyword-runs` сохранён в архиве с предупреждением, полный JSON доступен. Старые API, настройки и зависимые прежние разделы (включая старую проверку перед публикацией) сохранены для совместимости. Прежние эвристики там не становятся измеренным спросом; полного перерасчёта/миграции нет. Новая страница не вызывает эти платные старые действия.
- Новые `/keyword-evidence/*` маршруты защищены паролем приложения, токен Chrome не допущен. Тело POST до 8192 байт. OAuth/MCP-права не расширены.

## Предел этапа
Базовый проверяемый режим пункта 2, не полный аналог платного Keyword Research и не закрытие всего плана. Реальные Google/подсказки, качество выборки и обновление Windows ещё не прошли приёмку. CTR Reporting и автоматические результаты A/B остаются открытыми. Синтетические тесты не заменяют живую проверку.
