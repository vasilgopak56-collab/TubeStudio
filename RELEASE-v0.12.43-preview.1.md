# TubeStudio v0.12.43-preview.1 — проверка переноса через интерфейс

## Изменение приложения
В Настройки → Данные сообщение импорта теперь переносит длинные имена файлов в пределах карточки. Браузерная проверка выявила горизонтальное переполнение на 390 px при имени пропущенного файла без пробелов; исправлено overflow-wrap:anywhere. Формат ZIP, лимиты, правила включения/исключения, объединение файлов и авторизация не менялись. Новых API-прав, провайдеров или автоматической генерации нет. Расширение не разрабатывалось; изменена лишь общая версия приложения, возвращаемая существующим ping.

## Новая проверка браузерного пути
Добавлен tests/e2e/backup-ui.test.mjs: 9 сценариев на синтетических данных, два отдельных аутентифицированных loopback-сервера с разными DATA_DIR/PROMPTS_DIR/.env.

- На 1440/390 px ссылка экспорта действительно скачивает ZIP; скачанные байты передаются в импорт второй установки, а не подменённый ответ.
- Сверены импортированные файлы и сохранность целевого .env/целевого промпта, которого нет в ZIP. Второй сервер остановлен и перезапущен; через интерфейс открыты проект со сценарием Unicode/RTL/литеральным script-тегом и история ручного расчёта с прибылью 200 USD. HTML не исполняется. Это не проверка всех разделов приложения.
- Отмена подтверждения не отправляет POST и не меняет данные; тот же файл можно выбрать снова.
- Повреждённый ZIP отклонён реальным сервером, данные не меняются; повторный выбор повторяет попытку.
- Пропущенное длинное имя показано полностью без горизонтальной прокрутки. Пропуски/предупреждения не выданы за полный успех.
- Пока один импорт ожидает ответа, показано «Импортируем…», пользовательский выбор заблокирован стилем pointer-events-none. Задержка ответа введена тестом; это не новая серверная блокировка параллельных импортов.
- Сетевая ошибка введена тестом через прерывание запроса: показана ошибка, повторная попытка успешна. Это не воспроизведение реального обрыва интернета или отказа диска посередине записи.
- Старая v1-копия показывает предупреждение; корректный минимальный v2 ZIP без пропусков показывает число файлов и напоминание о перезапуске.

Запросы переноса, проекты и расчёты настоящие локальные. Не относящиеся к переносу /api/health и /api/anymodel/models подменены для исключения диагностики провайдеров. Серверный fetch заблокирован; попыток обращения к провайдерам — 0. Нативный системный диалог выбора/сохранения файла не проверялся: Playwright использует браузерные download и file input.

## Проверки
Типы и production-сборки web/server/MCP, 594 модульных теста и 295 E2E без extension.test.mjs прошли; ошибок/пропусков 0. Девять новых браузерных сценариев входят в 295, не добавляются к нему. Отдельно повторены 7 API-сценариев переноса: 42 файла, контрольные файлы во всех 28 разрешённых каталогах, ошибок 0. Машинные отчёты: PREVIEW-CHECKS.json и docs/checks/backup-{ui,transfer}-v0.12.43-preview.1.json. Проверка Windows-файлов выполнена на Linux и не является Windows-приёмкой.

Отдельно просмотрены 10 PNG: импорт с предупреждением 1440/390, восстановленный расчёт 1440/390, длинное пропущенное имя, неправильный ZIP, ожидание, сетевая ошибка, архив v1, полный успех — последние шесть на 390 px. Переполнения страницы в этих состояниях нет. Это точечная визуальная проверка, не полный аудит доступности/качества RTL во всех разделах.
