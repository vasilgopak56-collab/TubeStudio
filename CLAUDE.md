# TubeStudio — инструкции для Claude

## Что это
Локальная программа для производства YouTube-роликов. Работает только на ПК владельца (Windows 11 x64).
Путь ролика: каналы → идеи (Радар) → сценарий с проверкой → озвучка (Lumean) → визуал (G-Labs) → монтаж.
Версия 3.5.0. Рабочая ветка: `release-1` (ветка `main` устарела, там 0.12.148 и копия базы знаний).
Владелец — автор YouTube-каналов, не разработчик: объясняй простыми словами, команды давай для PowerShell.

## Стек и структура
- Монорепозиторий (npm workspaces):
  - `apps/server` — Hono, TypeScript, zod, pino, sharp;
  - `apps/web` — React 18, Vite 7, Tailwind 3, TanStack Query, React Router 7;
  - `apps/mcp` — MCP-сервер.
- `launcher/`, `windows/`, `windows-portable/` — запуск, остановка, ярлык и переносимая сборка для Windows (Node внутри).
- `extension/` — расширение Chrome, не развивается.
- `scripts/` — сборка и проверки; `apps/server/test/*.test.ts` — модульные тесты; `tests/e2e/` — приёмочные.
- `knowledge/`, `skills/` — база знаний встроенного Помощника и навыки.
- Выпуски собирает CI на Windows: `.github/workflows/release-1.yml` (Node 22).

## Команды (из корня проекта)
- `npm ci` — установить зависимости
- `npm run typecheck` — проверка типов
- `npm run test:unit` — модульные тесты (у каждого своя временная папка данных, реальных ключей нет)
- `npm run build` — сборка
- `npm run dev` — режим разработки (сервер + веб)
- `npm run test:e2e` — приёмочные проверки, тяжёлые: только по моей просьбе
- Для озвучки, видео и поиска пауз нужен FFmpeg в PATH.
- Проект собирается и проверяется на Node 22.

## Правила работы
1. **Меняй только то, о чём я прошу.** Не улучшай, не рефакторь, не форматируй чужой код и не добавляй функции, элементы интерфейса или запасные варианты «заодно». Увидел проблему — сообщи, но не правь без команды.
2. Не подменяй модели на более дешёвые, не обрезай промпты, не добавляй хранение в localStorage.
3. Перед правкой нескольких файлов покажи короткий план и дождись моего «да».
4. **Ключи и данные.** Никогда не читай, не печатай и не копируй `.env`, папку `TubeStudioData` (данные владельца лежат вне проекта) и хранилище ключей Windows. Не проси вставлять ключи в чат. Не коммить секреты.
5. **Платные запросы** (AnyModel, Lumean, G-Labs, YouTube) в тестах не делай. В коде они требуют явного подтверждения, а повтор после таймаута недопустим (риск двойной оплаты). Не ослабляй эти защиты.
6. После правок кода запускай `npm run typecheck` и `npm run test:unit` и честно сообщай результат: сколько прошло, сколько упало. Различай «проверено на тестовых данных» и «проверено на реальных аккаунтах». Не объявляй готовым то, что не проверено.
7. **Git.** Работай в отдельной ветке от `release-1`, коммиты небольшие, `push` только по моей просьбе. Ветку `main` не трогай.
8. Не читай без нужды тяжёлые файлы: `apps/web/src/lib/help.ts` (≈1 МБ), `DOCUMENTATION-RU.md` (≈900 КБ), `apps/server/src/services/assistantKnowledge.ts` (≈550 КБ, генерируется скриптом), `tests/e2e/assistant-desktop.test.mjs` (≈440 КБ), `README.md`, `ASSISTANT-START-RU.md`, `docs/IMPLEMENTATION-STATUS.md`, а также 250+ файлов `RELEASE-*` и `LOCAL-CHECK-*` в корне. Нужна справка по теме — ищи `grep`-ом нужный фрагмент.
9. Канал The Frost Ledger уже создан и оформлен. Не создавай его заново и не заменяй профиль канала без моего просмотра.
