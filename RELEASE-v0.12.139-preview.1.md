# 0.12.139-preview.1 — отдельное подтверждение аудиораспознавания

## Что изменилось
- В разделе «Раскадровка из озвучки» каждое распознавание фрагмента AnyModel ожидает отдельного серверного подтверждения. Наличие только начального подтверждения интерфейса или прямой POST на API недостаточно, чтобы отправить звук.
- Окно показывает номер фрагмента, провайдера и модель. Решение ограничено одним вызовом и действует не более двух минут; на другие фрагменты, повторы и будущие задачи оно не распространяется. Отказ, отмена или истечение срока блокируют именно ожидающий запрос.
- Перед отправкой заново проверяются бюджет и тариф. Решение привязано к конкретному запуску, задаче, параметрам запроса и версии тарифа; изменение тарифа делает решение непригодным. Аудио, ключ и текст запроса не публикуются в событии согласия.
- При потере соединения интерфейс пытается восстановить поток и сохраняет возможность остановки. Не запускайте задачу повторно, пока не проверили результат. При перезагрузке страницы возможность управлять старой задачей не восстанавливается; неотвеченные согласия истекут, но уже отправленные запросы могут быть оплачены.

## Важные ограничения
- Защита распространяется только на запросы аудиораспознавания через AnyModel, а не на генерацию промптов или остальные инструменты. Для генерации промптов сохранено только предварительное предупреждение интерфейса; API может его обойти. Режим warn сам по себе не требует согласия для остальных вызовов.
- Это не лимит расходов. Сумма заранее неизвестна, бюджет не резервируется; в том числе при параллельных запросах предел может быть превышен. Сверяйте фактические списания у провайдера. Подтверждение означает разрешение на один запрос, а не на конкретную сумму.
- До двух обращений могут одновременно ожидать решения. Отказ для одного фрагмента не отменяет уже одобренные другие. Готовые фрагменты сохраняются даже при ошибке другого, после чего проверьте результат и повторяйте только отсутствующие фрагменты.
- Подтверждение основано на локальной сессии и не защищает от человека или программы, которые уже имеют доступ к приложению и могут принимать решения через API. Это не защита от вредоносного ПО на компьютере.
- Предыдущие документы и заметки о протоколе .73/.138 являются историческими и могут описывать более раннее состояние.

## Проверки и установка
Локальные тесты используют только фиктивный провайдер, без реальных ключей и платных запросов. Windows-проверка статическая: запуск на настоящей Windows-машине не проверялся.
Сначала сделайте резервную копию программы и папки данных, остановите сервер; обновляйте файлы приложения, не затирая свои `.env`, данные и проекты. Затем выполните `update-windows.bat` и запустите программу. Проверяйте номер версии работающего сервера, а не только распакованных файлов.
