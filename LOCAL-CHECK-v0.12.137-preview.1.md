# Локальные проверки 0.12.137-preview.1

Проверки проводились в Linux на временных данных. Реальные ключи и пользовательские данные не использовались.

- `npm run typecheck`, `npm run build`: успешно. Vite предупредил о крупном JS-бандле; скорость не измерялась.
- Полный `npm run test:unit`: 1423/1423. После расширения проверки резервного восстановления адресный набор из 14 тестов копирования и целостности снова прошёл 14/14.
- В адресных тестах проверены: повтор и параллельный запрос одного ID; отклонение другого источника с тем же ID; завершённое, неизвестное, отсутствующее и повреждённое состояние попытки; сбой декодирования; подмена аудио или PCM без изменения размера, отсутствующий PCM и символьная ссылка; запрет платного пути до отправки при повреждении; изменение PCM во время имитированного платного запроса и отсутствие сохранённого результата; восстановление снимка, файлов и ID из резервной копии с последующим повтором. Вызовы провайдера имитированы.
- Выборочная desktop-регрессия: 54/54. В том числе потеря ответа после завершения копирования и повтор с тем же ID после потери до отправки, проверка старого функционала аудио, выбора сценария, справки и версии. Полный desktop-набор не запускался.
- `npm run check:windows`: статические файлы запуска проверены. Программа и сценарии обновления на настоящей Windows не запускались.
- Сбои питания, одновременные внешние записи, реальные ответы моделей и цены не проверялись. Проверка не является защитой от локального злоумышленника; отдельную копию данных продолжайте хранить приватно.
