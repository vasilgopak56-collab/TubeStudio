## Что проверено

Независимый adapter использует настоящий локальный Node HTTP-сервер с синтетическим MP3, а не только подменённый global fetch. Отдельный тест выполняется без AnyModel API key. Сохранение/список профилей, локальная подготовка и preview не вызывают сервис. Ключи не возвращаются в API и не записываются в проект. Точный model, input, voice, response_format=mp3, получатель и Bearer/без авторизации проверены. Текстовые профили не подставляются; новый профиль не выбирается автоматически.

Строгие schema/Origin/auth/consent; URL без credentials/query/hash, внешнего HTTP, LAN, приватного IPv4 и конечного /audio/speech. DNS private/mixed/failure не отправляет ключи. Публичный DNS закрепляется в transport. HTTP 503 и 307 не повторяются и не перенаправляются; произвольное тело ошибки скрыто. Невалидные MIME/MP3, обрыв и oversized Content-Length не превращаются в успешный MP3. Неизвестная попытка блокирует повтор. Часть ограничена 1800 символами, ответ 20 МиБ и 180 секундами после создания HTTP-запроса; полный стресс временного/потокового предела отдельно не принимался.

Ключ/профиль изменён в очереди — отправка блокируется. Изменение проекта аннулирует preview. При block с неизвестной ценой ноль HTTP-запросов. Локальный адрес не объявляется бесплатным. Отмена до отправки не вызывает сервис, отмена ожидания не разрешает повтор; поздняя отмена после получения не скрывает полный MP3. Ошибка локального учёта сохраняет MP3 и не вызывает генерацию повторно. Это не полный учёт всех возможных списаний.

Независимый профиль/голос закреплены в подготовке, попытке, квитанции и аудиоартефакте. Полученные части и локальная сборка читаются после удаления профиля; свежая отправка не может незаметно использовать другой профиль. Подготовка без tts сохраняет прежний путь AnyModel. Сборка FFmpeg и отдельное подтверждение добавления в проект сохранены. Старые материалы не заменяются.

UI: сохранение отдельного TTS-профиля без сетевой пробы, ключ очищается после сохранения, явный выбор типа/профиля/model/voice; preview и согласие сбрасываются при смене голоса. Один подтверждённый вызов сохраняет MP3; 503/307 не дают кнопку повтора или fallback. Проверены тёмные 1440×1000 и светлые 1024×900, изображения просмотрены; pageerror и горизонтального переполнения нет.

## Границы

Только совместимый audio/speech MP3; не любые API, WAV/stream, произвольные заголовки, Responses, нативные другие TTS или voice cloning. Скорость 1/тон 0. До 100 неизменяемых plaintext-профилей, без редактирования/удаления/миграции. Ключи вне ZIP, 0600 на Linux не доказывает Windows ACL.

Реальные ключи, платные сервисы, качество произношения, YouTube и настоящая Windows не проверялись. Нет утверждения об универсальной совместимости или художественном качестве. Синтетический тон не является речью. Согласие помощника не закрывает общий warn-протокол и финансовый пакет.

Один сервер на DATA_DIR; без параллельного импорта или ручной правки файлов. Нет fsync/power-loss/exactly-once гарантии между серверами. Архив резервной копии содержит пользовательские тексты/аудио, публиковать его нельзя. Не создавайте другую подготовку для обхода неизвестной оплаченной попытки. Отчёты прежних версий исторические; текущие журналы — docs/checks/v0.12.86.
