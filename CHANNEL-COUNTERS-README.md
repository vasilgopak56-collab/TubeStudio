# Счётчики конкурентов — v0.12.18

## Что изменилось
В карточке конкурента — публичные подписчики, накопительные просмотры и число публичных видео с точным временем наблюдения UTC. «Новых в выборке ≤30 дн.» не обозначает все публикации канала. История открывается через **Видео → История счётчиков**; таблица прокручивается внутри карточки, включая мобильный экран.

Отсутствующие, скрытые, небезопасные числа и счётчики без явного подтверждения API не становятся нулями. Только целое неотрицательное число/строка цифр, в безопасном диапазоне JavaScript, считается проверенным; реальный ноль допустим. Снимок старше 48 часов не используется как актуальный. При отсутствии канала в ответе новый снимок не создаётся, выводится причина; при ошибке запроса старые наблюдения сохраняются.

## История и совместимость
- Один последний снимок за дату UTC; повторное обновление этой даты заменяет всю строку, а не переносит прежнее известное значение на место неизвестного.
- Хранятся до 400 дат, показываются последние 60. Пропуски не заполняются, нет соединяющей их линии графика.
- Старые строки без точного `t` и признаков `subsKnown/viewsKnown/videosKnown` сохранены как есть. Числа читаются с пометкой «архив, не подтверждено» и не становятся доказательством сравнения.
- GET списка/алертов не переписывает историю. Нет массовой миграции и удаления пользовательских записей.

## Сравнение с датой −7 дней
Нужны свежий последний снимок и снимок ровно с датой UTC на 7 дней раньше. При допустимой разнице времени суток фактический интервал должен быть 156–180 часов. Произвольный более старый или более новый снимок не заменяет базу. На экране показаны ISO-даты UTC и реальная длительность; это не обещание ровно 168 часов.

В записанных строках внутри периода проверяются порядок, точное время и известность каждого счётчика. Неизвестные подписчики блокируют только их дельту. Уменьшение накопительных просмотров в любой записанной точке блокирует дельту просмотров как коррекцию — без обнуления или маскировки последующим восстановлением. Отрицательная разность подписчиков допустима. Отсутствующие дни не интерполируются: разность концов не равна сумме дневной Analytics и не доказывает отсутствие коррекций между наблюдениями.

## Алерт подписчиков
Требуются снимки соседних дат UTC с интервалом 12–36 часов, проверенные нескрытые счётчики, положительная база и положительная разность не ниже настроенного процента. Нулевая база, архив, пропуск предыдущей даты и скрытый счётчик не порождают алерт. Порог ≤0 отключает его. На канал — не более одного алерта подписчиков за дату UTC.

Основание неизменно хранится с алертом: даты, длительность, значения до/после, разность, процент, порог и источник `public-channel-counter`. Повторное обновление не пересчитывает уже сохранённое основание. Публичный счётчик не выдаётся за точный прирост аудитории. Старые алерты остаются с предупреждением о неподтверждённом периоде.

## Дайджест и перенос
Контекст AI-дайджеста получает nullable-счётчики, даты/причины и недельное сравнение, а не выдуманные нули. Запуск AI остаётся отдельным действием/ранее настроенным расписанием. `competitors.json` и основания переносятся обычным ZIP экспорта/импорта данных. Экспорт данных может содержать личные сведения: не публикуйте его. Полный архив исходников не включает `.env`, пользовательские данные, OAuth и журналы.

## Обновление
1. Завершите задания, остановите сервер и сделайте отдельную копию папки программы, `.env`, DATA_DIR и промптов.
2. Скопируйте содержимое папки `tubestudio` из нового архива в существующую папку с заменой исходников. Не создавайте вложенную папку tubestudio и не удаляйте свои данные.
3. Запустите `update-windows.bat`, дождитесь завершения, откройте программу и обновите вкладку Ctrl+F5. Linux/macOS: `npm install`, `npm run build`, `npm start` при установленном Node.js.
4. Проверьте карточку конкурента; старые строки сразу после обновления могут показывать «нет подтверждённых данных». Новые снимки появляются только после обновления статистики, задним числом подтверждение не добавляется.

## Границы этапа
Это локальная доработка пункта 4. Не добавлены фоновые уведомления ОС/почта, гарантированный сбор при выключенном сервере, массовая история, прогноз аудитории или вывод о монетизации. VPH других инструментов, Reach/единица CTR, автоматическая оценка A/B и Windows-установка не менялись. Реальные Google, платные API, пользовательский Windows и ярлык ещё требуют живой приёмки. Исторические PDF/DOCX не пересобраны.
