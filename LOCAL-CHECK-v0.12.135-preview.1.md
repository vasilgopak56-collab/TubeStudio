# Локальные проверки 0.12.135-preview.1

Проверены исходники и финальная сборка на Linux, Node 24. Тесты использовали временные проекты, искусственные ответы и фиктивные ключи, а не данные пользователя.

- `npm run typecheck` и `npm run build` — успешно для сервера, web и MCP. Сборщик предупреждает о крупном главном JS-бандле; скорость приложения не измерялась.
- `npm run test:unit` — **1409/1409**; в том числе семь новых сценариев версии озвучки: точное совпадение, изменённый/ручной текст, ошибочный или чужой источник, запрет устаревшей версии до сетевого запроса, реальный путь сервиса с имитированным провайдером, удаление источника во время ожидания и перенос снимка вместе с аудио.
- Адресные проверки desktop UI новой функциональности и справки — **37/37**: три проверки выбора и перехода из редактора, 34 проверки справки/примыкающих разделов.
- Повторный набор `tools-desktop`, сохранения сценария и чтения проектов на окончательно собранной версии — **76/76**. Первый запуск этого набора во время параллельной сборки завершился **75/76**: тест раздела прибыли получил тайм-аут ожидания элемента. После завершения сборки повторен весь набор, включая этот тест; он прошёл. Точная причина тайм-аута не установлена.
- Резервный перенос — **8/8**, 91 тестовая запись и 37 папок; два TTS-вызова имитированы. Дополнительно новый снимок и тестовый аудиофайл перенесены в отдельную папку. Импорт не заявляется транзакционным.
- `npm run check:windows` — статическая проверка установочных файлов пройдена; на настоящей Windows приложение, обновление и ярлык не запускались.
- Полный набор desktop-тестов не запускался; указанные 113 проверок — выбранные наборы, а не полная настольная регрессия.
- Реальных запросов к AnyModel/Google и платных операций не выполнялось. Соответствие аудио тексту, фактическая цена, доступность голоса и пользовательская приёмка не проверены.
