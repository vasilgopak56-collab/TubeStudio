# Журнал A/B — TubeStudio v0.12.12

Первая локальная версия истории A/B из пункта 12 плана. **Моя аналитика → Журнал A/B** доступен без подключения OAuth. Это журнал плана и ручных наблюдений, не система проведения экспериментов в YouTube.

## Рабочий процесс

1. Создайте новую проверку: название, необязательные канал и ID видео из 11 символов (не URL), тип — заголовки, обложки либо оба изменения. Канал, ID и тип закрепляются после первого сохранения, включая пустые значения. Для другого видео/типа нужна новая проверка.
2. Запишите гипотезу и варианты A/B, при необходимости C. Для обложки укажите описание или имя файла. Изображения, файлы и URL не загружаются и не открываются; приложенного изображения в снимке нет.
3. Сохраните план. Показы/CTR/периоды можно оставить пустыми. Это неизвестные значения, не нули.
4. Проведите проверку самостоятельно во внешнем инструменте. Если есть отдельные показатели по вариантам, перенесите их в журнал вместе с периодами, названием исходного отчёта, датой сверки и часовым поясом. Программа не проверяет достоверность чисел или владение каналом.
5. Сохраните новую версию. Для завершённой проверки можно записать собственное решение A/B/C либо «Недостаточно оснований» с обязательным обоснованием. TubeStudio не выбирает победителя автоматически. Можно завершить без решения.
6. Снимки открываются из истории без внешних запросов. «Продолжить этот снимок» копирует его в форму: при несохранённых правках требуется подтверждение замены. Открытие истории само по себе черновик не меняет. «Начать новую проверку» создаёт независимую цепочку.

Черновик не автосохраняется и хранится только в открытом разделе. Перед переключением вкладки раздела, переходом на другую страницу или перезагрузкой сохраните снимок; подтверждение замены защищает только действия «Продолжить этот снимок» и «Начать новую проверку», а не все переходы браузера.

## Как читать сравнение

- Показы вводятся целым числом 0–1 000 000 000 000; CTR — числом от 0 до 100 процентов. Строки вместо чисел, отрицательные значения, бесконечность и неподходящие поля сервер отвергает.
- При 0 показов CTR не определён: оставьте его пустым. Известные 0% при положительных показах сохраняются как 0%, не как неизвестность. Можно зафиксировать CTR без известного числа показов, но объём наблюдений останется неизвестным.
- Для каждой пары показывается только разница введённых CTR в **процентных пунктах**, правый минус левый. Например, A=4%, B=5% → B−A=1 п.п., не «рост на 1%». Неизвестный CTR хотя бы одного варианта → разница неизвестна. Клики из округлённого CTR не восстанавливаются, проценты между версиями не суммируются и не усредняются.
- Разность не является статистической значимостью, причинным эффектом или победой. Большой объём показов не доказывает сопоставимость аудитории, трафика и времени. При последовательной смене это не рандомизированный эксперимент. Режим «Одновременное сравнение» — также только ручная пометка, не проверка рандомизации.
- Общий CTR ролика нельзя приписывать каждой обложке. Просмотры нельзя подставлять вместо показов. Если отдельного CTR варианта нет, оставьте поле пустым. Доля времени просмотра, доля показов и CTR — разные показатели; не переносите один вместо другого.
- Даты — календарные даты из вашего источника, без преобразования из часового пояса Настроек. Укажите обе даты либо оставьте обе пустыми. Разные периоды и отсутствующие даты отмечаются предупреждениями. Будущие даты допускаются для плана, но не подтверждают состоявшееся наблюдение.
- Если одновременно менялись заголовок и обложка, журнал не отделяет вклад каждого изменения. Ручной итог явно подписан как решение автора, не вывод TubeStudio или YouTube.

## История и экспорт

Каждое сохранение — новый UUID-файл `DATA_DIR/ab-test-runs/<uuid>.json`. `experimentId` объединяет цепочку, `parentId` указывает исходный снимок. Можно продолжить старую версию: создаётся **ветка**, более поздние записи не сливаются с ней. Сохранение не перезаписывает прежние файлы; это не криптографическая защита от ручного изменения файлов на диске.

- История показывает последние 50 снимков всей установки, включая версии и ветки. Старые файлы не удаляются. Из результата доступны переходы к предыдущему снимку и началу проверки, если файлы ещё существуют.
- При повреждённых/недоступных файлах есть предупреждение; файлы не удаляются. При более чем 5000 подходящих файлов сканирование завершается явной ошибкой вместо молчаливо частичной истории. Файл ограничен 64 КиБ, запрос — 30 000 байт. Символические ссылки на каталог/снимки отвергаются.
- JSON, Markdown и копирование используют **сохранённый результат**, а не несохранённую форму. Markdown экранирует пользовательскую разметку. JSON — для просмотра/обработки, не отдельная команда импорта.
- Общий ZIP-перенос включает `ab-test-runs` и сохраняет связи версий. Совпавшие файлы при общем импорте заменяются по обычным правилам восстановления: сначала сделайте копию текущих данных, завершите задания, после импорта перезапустите программу.
- Журнал может содержать приватные показатели и пользовательские заметки. Сам сервис не читает `.env`, OAuth-токены или API-ключи, но не очищает вручную вставленные секреты. Не вставляйте их в текст. Общий ZIP может включать OAuth-токены других разделов: не публикуйте его.

## Границы реализации

Без Google/провайдеров/AI, автоматического получения CTR/показов/результатов экспериментов, смены заголовков/обложек, загрузки изображений, автоматического распределения аудитории, проверки статистической значимости или собственного A/B-движка. OAuth-подключение и выбранный на «Обзоре» канал не привязывают этот ручной журнал автоматически.

Полный веб-доступ защищён действующим APP_PASSWORD, если он задан. Ограниченный токен Chrome не получает доступа к журналу; scopes и инструменты MCP не расширены. Это не ограничение для других локальных программ, имеющих доступ к файловой системе вашей учётной записи.

Пункт 12 остаётся частичным: доход, автоматические показы/CTR, многоканальная панель и живая приёмка реального OAuth ещё открыты. История A/B реализована как ручной журнал, не как автоматическая интеграция экспериментов. Ключи из Drive не использовались; для этого локального раздела они не требуются.
