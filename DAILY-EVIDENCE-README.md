# Daily Ideas — проверяемая сохранённая база, v0.12.35

Продолжение пункта 10. Это ручная подборка пяти AI-гипотез по одному сохранённому источнику, не ежедневное расписание, не текущие тренды, не подтверждённый спрос и не прогноз просмотров.

## Что добавлено

1. После локального **Предпросмотра контекста** раскрыть **Строки E1–E10, показанные AI**. Видны все передаваемые строки, ID/точная дата сохранения источника и их количество. Точный system/user остаётся в отдельном блоке. Явный **Сгенерировать 5 идей (AI)** по-прежнему требует актуального хеша выбора, проекции и промпта.
2. У каждой сохранённой идеи раскрыть строку E1–E10: это материалы, на которые сослалась модель, не доказательство её объяснения. Ссылки не проверяют факты, права или качество идеи.
3. В **Сохранённой базе подборки** раскрыть все строки, показанные AI, включая неиспользованные в ссылках конкретной идеи. Берутся из `current.preview.context`, а не из нового чтения исследования/трекера или формы. Удаление источника не лишает сохранённую подборку её контекста.
4. **Остановить предпросмотр** прерывает HTTP-ожидание без AI/записи подборки. Уход отменяет запрос, поздний ответ не применяется на другом маршруте. Уход во время генерации отменяет задание; дополнительно результат не меняет маршрут, если пользователь уже выбрал другой URL.

## Поля строки и ограничения

- E1–E10 и порядковый номер относятся к первым до 10 строкам ограниченной проекции в порядке сохранённого файла. Это не новое ранжирование и не место ролика в поиске. Показаны N из общего числа строк в источнике.
- Название — сохранённый текст до 300 единиц UTF-16. До 8 тегов по 80. Границы суррогатных пар не разрываются. Нет нового поля «обрезано»: старый формат не хранит исходные длины. По достижению лимита нельзя достоверно сказать, был ли текст обрезан. Полный исходник не выдумывается.
- Валидный ID видео ведёт на YouTube только по явному переходу пользователя. Строка-фраза может иметь `videoId:null`: ID/ссылка не придумываются. Раскрытие строк не открывает YouTube и не запрашивает метаданные.
- Дата публикации — буквальное значение, сохранённое в источнике. Если null, явно неизвестна. Старое некорректное значение не превращается в текущую дату и не выдаётся за проверенную дату. Время сохранения источника не равно времени наблюдения каждого счётчика.
- Просмотры — только известное сохранённое число по прежним правилам проекции. Известный ноль отображается как 0, null — «Неизвестно», а не ноль. Не обновляются при чтении. Время отдельного наблюдения может отсутствовать; не заменяется датой сохранения.
- Теги — только переданный ограниченный массив. Пустой массив не доказывает, что на YouTube тегов нет. Проекция новых исследований и поисковых снимков ключей может вообще не передавать теги.
- Все строки выводятся текстом React, без HTML/Markdown исполнения. Unicode/RTL и длинные слова переносятся внутри контейнера. Внешние страницы, факты, политики и права автоматически не проверяются.

## Совместимость, стоимость и безопасность

Формат `daily-idea-runs/<UUID>.json` остаётся version 1. Промпт, хеш/точный запрос, схема ответа, пять идей, ограничения чтения, общий бюджет, повторы/резервные модели, история, панель и ZIP прежние. Перезаписи/миграции старых подборок нет. JSON/ZIP содержат приватные тексты, контекст и инструкции; 0600 не является шифрованием. Отчёт JSON не является отдельным импортом.

Перед чтением после открытия файла дополнительно проверяются его тип и размер; чтение по-прежнему ограничено: 2 МиБ для источника, 8 МиБ для трекера и 256 КиБ для индекса/подборки. Это не защита от владельца файлов, который может пересчитать хеш. Ошибочные/неподдерживаемые подборки пропускаются, не дополняются выдуманными данными.

Предпросмотр/раскрытие/история/панель/JSON/ZIP не вызывают генерацию Daily Ideas и не обновляют YouTube. Общая диагностика приложения и ранее настроенный трекер работают отдельно. Генерация — только отдельная кнопка, может быть платной, с общими повторами/резервами; скрытого AI-исправления JSON нет. Отмена не гарантирует возврата уже списанной оплаты.

Новых AI-автозаданий, источников, OAuth/MCP/Chrome-прав, публикации и изменения видео нет. Реальные провайдеры/Windows-приёмка остаются открыты. Перед обновлением остановить приложение, сохранить `.env`, DATA_DIR и промпты; общий ZIP проверить в отдельной установке.
