# Транскрипты — v0.12.5

## Где открыть и что сделать
Исследование → **Транскрипты** (`/transcripts`). Выберите источник:

1. **Субтитры YouTube.** Вставьте ID видео из 11 символов или обычную HTTPS-ссылку watch / youtu.be / shorts / live / embed. Выберите язык дорожки и нажмите «Получить субтитры».
2. **Вставить текст.** Введите название, выберите TXT/SRT/WebVTT, вставьте материал и нажмите «Сохранить и разобрать текст». Эта кнопка разбирает формат, а не вызывает AI.
3. **Файл TXT / SRT / VTT.** Загрузите UTF-8 файл до 1 МиБ и 300 000 символов. Старые ANSI/Windows-1251 файлы нужно пересохранить в UTF-8.

Импорт только сохраняет исходник. У обычного текста нет придуманных таймкодов. SRT/VTT сортируются по времени; неподходящие блоки пропускаются с предупреждением. Лимиты: 300 000 символов и 10 000 фрагментов. Максимум HTTP-запроса — 1 400 000 байт: чрезмерно экранированный JSON может быть отклонён раньше.

## Почему YouTube может не сработать
Получение публичных субтитров неофициальное: программа читает доступный ответ проигрывателя и дорожку JSON3. Живая совместимость с YouTube не подтверждена. Пустые ответы, согласие/вход, возрастные/региональные ограничения, новые проверки и изменения формата могут сделать этот путь недоступным. Это не гарантия скачивания субтитров любого видео.

- Не передаются cookies/учётные данные; нет входа, обхода защиты или скачивания аудио.
- API-ключ YouTube и квота YouTube Data API не используются; сетевые обращения к YouTube выполняются.
- Выбирается только дорожка запрошенного языка (включая региональный вариант); при наличии ручной и автоматической предпочтительна ручная. Другой язык не подставляется молча, автоперевод не включается.
- Автосубтитры помечены. Текст не сверяется с аудио.
- Если дорожка недоступна, программа показывает ошибку и оставляет пути вставки / файла. Данные не выдумываются. Получите текст разрешённым вам способом.
- Адреса и перенаправления ограничены HTTPS-узлами YouTube и путями watch/timedtext; внешние адреса не открываются.

## AI-разбор и новый сценарий
После сохранения исходника доступны две отдельные кнопки:
- **Краткий разбор (AI)** — резюме, основные мысли, структура и вопросы для проверки.
- **Новый сценарий (AI)** — самостоятельная переработка с новым заходом и композицией, а не просьба копировать чужой текст.

Выберите язык результата из общего списка 19 языков (18 запрошенных + сохранённый польский), ориентир 500–3000 слов и при необходимости новый ракурс. Работает с сохранённым источником, не с несохранённой правкой в верхнем поле. Допустимо 100–60 000 символов: длинный источник не обрезается молча; выделите часть и сохраните как новый текст.

Текст и сведения об источнике отправляются вашему настроенному LLM-провайдеру только по AI-кнопке. Используются общие настройки AnyModel / прямых резервов и учёт расхода. Для remix применяется роль сценарной модели. Возможны платные резервные вызовы и один повтор исправления некорректного JSON; сетевые повторы определяются общими правилами провайдера. Фактическая модель указана в результате. Ручного переопределения модели на этом экране нет.

Объём приблизительный. Для японского/китайского/тайских и других текстов сегментация слов отличается от разделения пробелами. Если результат отличается от цели более чем на 30%, выводится предупреждение: автоматического платного дописывания нет.

Внешний фактчекинг не выполняется, ссылки/цитаты/факты не считаются проверенными. Возможны ошибки источника и AI. Проверяйте имена, числа, утверждения, оригинальность и права на материал. Используйте свои или разрешённые транскрипты. Система не устанавливает права и не гарантирует уникальность текста.

## История, экспорт, отмена
- Каждый исходник и AI-ответ — отдельный локальный UUID-снимок `DATA_DIR/transcript-runs`. AI-снимок хранит `parentId`, исходник, ответ, язык и фактическую модель. Повторный AI-разбор берёт первоначальный текст, а не предыдущий AI-сценарий.
- На экране последние 50 снимков; старые файлы не удаляются автоматически. Открытие истории не вызывает YouTube/LLM.
- Таймкоды из источника показываются по 100 фрагментов; TXT и JSON включают весь сохранённый текст. Для YouTube время ведёт в исходное видео.
- Копирование исходника/сценария, исходник TXT, сценарий TXT, разбор Markdown и полный JSON. Для работы в других разделах скопируйте сценарий либо используйте TXT. Автоматической записи в проект пока нет.
- «Редактировать как новый текст» переносит исходный текст в форму TXT; для сохранения нужен отдельный импорт, старый снимок сохраняется. Таймкоды при таком редактировании не переносятся.
- «Остановить» отменяет ожидание, сеть и AI-очередь. Новый завершённый снимок при отмене не сохраняется; уже принятый провайдером запрос может быть оплачен.
- История входит в общий экспорт/импорт ZIP; вместе с ней могут переноситься приватные тексты. Не публикуйте архив. `.env` не включается; ключи сохраняйте отдельно.
- Редактируемый промпт: редактор промптов → Транскрипты → `transcripts/analysis.md`. Изменения читаются при следующем AI-запуске; действующие тексты промптов входят в общий ZIP-перенос.

## Обновление
Сделайте полную резервную копию существующей папки. Закончите задания и остановите сервер. Скопируйте **содержимое** папки tubestudio из нового архива в существующую папку с заменой файлов (не вложенную папку). Сохраните `.env`, DATA_DIR и при необходимости свои промпты отдельно до замены. Запустите `update-windows.bat`, дождитесь успеха и обновите страницу Ctrl+F5. На macOS/Linux установите зависимости и выполните `npm run build`, затем `npm start`.

Основные PDF/DOCX остаются исторической версией v0.11; новый модуль описан здесь и во встроенной Справке. Это первая версия пункта 7, не завершение всего плана.
