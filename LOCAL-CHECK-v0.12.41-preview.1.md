# Отдельная проверка v0.12.41-preview.1

Архив содержит исходники без node_modules/dist, ключей и пользовательской папки data. Не заменяйте рабочую установку без резервной копии. Сначала распакуйте в отдельный каталог. Проверьте требуемую версию Node.js по основной инструкции README и установите зависимости через npm ci.

## Воспроизводимые локальные проверки
```bash
npm run typecheck
npm run test:unit
npm run build
npm run check:windows
node --test --test-concurrency=1 --test-name-pattern='Прибыль:' tests/e2e/tools.test.mjs
```
Для браузерных тестов нужен Chromium; задайте CHROME_PATH, если он не найден. Временные серверы используют loopback-порты; они должны быть свободны. Для PNG калькулятора задайте TEST_ARTIFACTS_DIR в доступный каталог.

Общая регрессия без расширения в Bash:
```bash
files=()
for f in tests/e2e/*.test.mjs; do
  [[ "$f" == */extension.test.mjs ]] || files+=("$f")
done
node --test --test-concurrency=1 "${files[@]}"
```
В этой сборке: 592 модульных, 279 E2E без расширения (включают 11 калькулятора), ошибок 0. Полный npm run test:e2e включает файл расширения; это не команда выполненного прогона. Проверки используют синтетические данные и моки, не доказывают работоспособность живых API.

## Ручная приёмка калькулятора
На 1440 и 390 px: режим учёта установки → «Проверить токены, ставки и формулы» → проверить AM/прямые расходы и предупреждение смешанного ID → сохранить → раскрыть сохранённое основание → выгрузить Markdown/JSON → открыть историю после изменения текущих ставок. Итог истории не должен измениться. Неизвестная активная ставка не становится нулём; при изменении основания перед сохранением ожидается 409 и обновление расходов. Архив v1 открывается с явным отсутствием подробного основания, без подстановки сегодняшних ставок. Переход на другую страницу во время ответа не должен возвращать старый результат в новый экран. Старый уже некорректный v2 не исправляется чтением.

## Следующий внешний этап
На целевой Windows отдельно проверить start-windows.bat, ярлык, diagnose-windows.bat, обновление и перенос/восстановление тестовой резервной копии. Не восстанавливать поверх единственной рабочей копии. Linux-проверка файлов не принимает эти действия.

Реальные Google/OAuth/Reporting, монетизированный канал, единица CTR, установленный MCP-клиент и платные AI-провайдеры проверяются отдельно с участием владельца аккаунта и согласованным бюджетом. Команда npm run smoke использует реальные ключи и может расходовать деньги/квоту: здесь она НЕ запускалась. Расширение Chrome исключено пользователем; не включайте его разработку в этот этап.
