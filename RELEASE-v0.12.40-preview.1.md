# TubeStudio v0.12.40-preview.1 — согласованность списков MCP

## Статус
Исходники для отдельной проверки, не установщик и не полностью принятый релиз. Включают непринятые браузером/визуально изменения калькулятора из v0.12.38-preview.1 и изменения пауз из v0.12.39-preview.1. Текущие целевые проверки не заменяют полный E2E.

## Что изменено
- ts_list_saved возвращает listToken и принимает необязательный expectedListToken. Fingerprint включает категорию, наблюдённые UUID-имена, ID/snapshotToken просканированных корректных строк и охват. Размер страницы и offset не привязаны.
- Изменения наблюдаемого набора/байтов просканированных записей обнаруживаются между вызовами даже при прежней дате/заголовке. STALE_LIST без частичного списка требует начать чтение заново.
- Пустая категория тоже получает токен; старые вызовы без токена сохранены. Токены стабильны между процессами для одинаковых наблюдений.
- Пять инструментов и прежние scopes; stdio/read-only. Нет сохранения списка, фонового сканирования, сетевого MCP, новых источников/прав и внешних вызовов. Поля финансового основания и основания пауз в MCP не раскрыты.
- Веб-инструкция различает listToken/expectedListToken и snapshotToken/expectedToken; инструкция MCP обновлена. Путь скриншота E2E больше не привязан к /data/mcp-release: используется TEST_ARTIFACTS_DIR или системный временный каталог.

## Проверки
Проверки v0.12.40-preview.1: типы и production-сборки web/server/MCP прошли; **591 модульный тест и 9 целевых MCP-сценариев**, ошибок 0. Среди MCP-сценариев — настоящий дочерний stdio-процесс, проверка списка, прежние права, веб-конфигурация, её авторизация и мобильная ширина. Просмотрена страница MCP на 1440/390 px, переполнения страницы нет. Windows — только файловая проверка на Linux. **Полный набор E2E, браузерная/визуальная приёмка калькулятора, установленный внешний AI-клиент пользователя и нативная Windows-приёмка не проверены.**

Модульные проверки включают категории/пустые списки, добавление/удаление, изменения без смены метаданных, порядок, invalid/skipped, игнорирование index.json, неизменность файлов, совместимость SDK и честный scanLimited: изменение содержимого файла за пределами 5000 может остаться незамеченным. Полный E2E не запускался. В этой версии сценарии калькулятора не запускались.

## Ограничения
Оптимистический отпечаток наблюдений — не транзакция, не цифровая подпись, не защита от процесса с правами пользователя и не постоянный revision ID. Не гарантирует отсутствие конкурентных или отменённых изменений. scanLimited остаётся признаком неполного чтения; скрытые от чтения файлы не превращаются в проверенные данные. Названия/тексты могут содержать секреты: автоматического удаления секретов нет; передавайте их только доверенному клиенту/провайдеру.
