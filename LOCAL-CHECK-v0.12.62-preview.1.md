# Локальная проверка 0.12.62-preview.1

Среда: Linux, Node 24, локальный Chromium. Все окна браузерных тестов 1440×1000. Изолированные временные папки и искусственные данные. Реальные ключи и .env не наследуются. Мобильные сценарии не запускались.

| Проверка | Результат | Что это означает |
|---|---|---|
| npm run typecheck | PASS | Типы server, web, MCP |
| npm run build | PASS | Сборка трёх рабочих областей; предупреждение Vite о размере чанков остаётся |
| npm run test:unit | **765/765 PASS** | Изолированная регрессия, в том числе серверные правила сравнения |
| Настольные director + help-docs + research-comparison-desktop | **41/41 PASS** | 8 сценариев режиссёрского пакета, 25 проверок справки/связанных экранов, 8 сценариев сравнения |
| npm run check:windows | PASS | Статическая проверка файлов на Linux, не запуск в Windows |

Команда настольного прогона:

```
node --test --test-concurrency=1 tests/e2e/director.test.mjs tests/e2e/help-docs.test.mjs tests/e2e/research-comparison-desktop.test.mjs
```

## Что проверено адресно

1. Текущая глава сравнения: 20 шагов, 16 пояснений полей, 10 проблем, числовой пример и техническая методика. Проверки связывают ключевые инструкции с текущими ограничениями исходников.
2. Все 63 главы присутствуют; сгенерированная DOCUMENTATION-RU.md совпадает с источником встроенной справки. Нет символов замены U+FFFD в текущем учебнике.
3. Поиск текста новой главы, таблица полей, свёрнутая по умолчанию методика и её раскрытие в светлой теме. При чтении нет POST/API-запусков, внешних обращений, ошибок JavaScript и горизонтального переполнения документа.
4. Выбор кандидата/контекста не собирает данные автоматически. Явный сбор двух каналов вызывает ровно пять подставных запросов без продолжения страниц; словесные подсказки сами не подтверждают тему.
5. Несохранённые галочки не меняют сводку. Явное сохранение меняет ручное решение без новых вызовов провайдера.
6. Закрепление добавляет копию в проект; переход в Сценарист и применение брифа явные и не вызывают AI.
7. Ошибка и отмена нового сбора сохраняют открытый прежний результат. Неизвестные данные не подменяются нулём; пустая страница и недоступные сведения различаются.
8. Перезапуск сохраняет данные; приватный ZIP включает источники, решение и проект; закреплённый бриф читается после удаления исходного сравнения.
9. Парольная защита действует, токен расширения Chrome не даёт доступ к приватным данным/изменению решения.

Для последнего блока создан отдельный desktop-вариант существующего набора сравнения. Исторический research-comparison.test.mjs с мобильными окнами сохранён без правок и не запускался. Подставной провайдер не отправляет запросы в реальный YouTube.

Визуально просмотрены таблица новой главы в тёмной теме и раскрытая методика в светлой. Снимки и журналы — docs/checks/v0.12.62/. Это не просмотр каждой строки каждого разрешения.

## Ограничения результата

- Не проверены реальная выдача YouTube, фактическая квота, доступность моделей и художественное качество AI.
- Не выполнялись платные AI-генерации, живой OAuth и внешние видеозапуски.
- Не выполнен запуск на настоящей Windows и полная живая регрессия всех разделов.
- Справка всего исследовательского блока повторно сверена с кодом, но это не сертификат правильности всех старых алгоритмов и не полная приёмка всего приложения.
- Остальные главы повторно аудируются по плану REMAINING-BEFORE-LIVE-TESTS-RU.md; следующие — сценарии и идеи.
