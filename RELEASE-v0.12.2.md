# TubeStudio v0.12.2

Исправления резервных копий и диагностика ярлыка Windows.

## Обновление существующей установки
1. Завершите задания и сделайте файловую копию существующей папки программы, включая данные и отдельно защищённый .env. Закрытие браузера не останавливает фоновый сервер.
2. Распакуйте архив отдельно. Скопируйте содержимое папки tubestudio поверх своей существующей папки программы, без вложенной tubestudio/tubestudio.
3. Не удаляйте .env и папки данных. Их в исходном архиве нет.
4. Запустите update-windows.bat и дождитесь окончания сборки. Скрипт пытается остановить только распознанный фоновый сервер этой установки; сервер, запущенный вручную в терминале, предварительно остановите сами.
5. Прочитайте отдельный результат создания ярлыка. Если ярлыка нет — запустите create-desktop-shortcut.bat от обычного пользователя и сохраните текст ошибки/launcher-logs/shortcut-install.log.
6. Запустите TubeStudio. После переноса данных через ZIP перезапустите сервер и проверьте восстановленные разделы.

## Важно
- История аудиораскадровок, конвейеры, исследования, версии и текущие промпты теперь поддерживаются при ZIP-переносе. Подробнее: BACKUP-README.md.
- В архиве данных могут быть OAuth-токены. Не публикуйте пользовательские резервные копии.
- Код установки ярлыка доработан, но успех на конкретном Windows ещё не подтверждён. При блокировке политиками не отключайте защиту.
