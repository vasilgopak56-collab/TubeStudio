# TubeStudio v0.12.42-preview.1 — видимая версия приложения

## Изменения
- Под названием TubeStudio в развёрнутом меню видна версия сборки интерфейса; в мобильной шапке — рядом с названием. В мобильном меню версия тоже показана, в свёрнутом — доступна в подсказке логотипа.
- Vite вшивает версию из корневого package.json при сборке: замена исходников без пересборки не делает старый интерфейс «новым».
- Новый локальный GET /api/version возвращает только {version} и Cache-Control: no-store. Нет чтения настроек/ключей, проверок API, обновления OAuth, сетевого запроса провайдеру или записи пользовательских данных. Прежняя авторизация сохранена, ограниченный токен расширения получает 403.
- Интерфейс сравнивает свою версию с версией работающего сервера. При несовпадении показывает обе и предлагает завершить обновление, перезапустить TubeStudio и обновить страницу. При старом сервере без маршрута, ошибке или некорректном ответе пишет, что совпадение не подтверждено. Есть кнопка «Проверить версии» и локальная повторная проверка при возвращении фокуса вкладки; автоматической установки обновления нет.
- Версия не служит проверкой подписи/целостности всех файлов и не доказывает успешность реальных интеграций. Весь интерфейс предыдущей .41 ещё не умеет показывать индикатор; после первой установки этой функции может потребоваться Ctrl+F5.

## Проверки
Типы всех трёх workspace, production build web/server/MCP и Windows-файлы на Linux прошли. 594 модульных теста, ошибок 0. Семь целевых E2E: авторизация/ограниченный токен; совпадение; свёрнутое меню; мобильное меню; несовпадение и повторная проверка; старый/недоступный маршрут; некорректный ответ. Они входят в общий результат, а не добавляются к нему. Общая регрессия без extension.test.mjs: 286 passed, 0 failed, 0 skipped; семь новых сценариев входят в 286. Машинный отчёт: PREVIEW-CHECKS.json.

Отдельно просмотрены семь PNG: совпадение, несовпадение и недоступный ответ на 1440/390 px, а также открытое мобильное меню. Номер не обрезан, перекрытий и горизонтального переполнения страницы нет. Данные изолированные синтетические; реальные платные API не вызывались. Это проверка указанных состояний, не полный аудит доступности.

## Статус Windows и следующие шаги
Пользователь подтвердил открытие приложения вручную и через ярлык. Его диагностика файлов/Node/ярлыка установки с исходниками .41 прошла; версия именно работающего сервера тогда не была установлена. Предупреждение об отсутствующем .env само по себе не означало падение. Эти свидетельства не подтверждают обновление до .42; его ещё нужно проверить на целевой Windows. Не подтверждены сохранение/восстановление данных на ней, реальные Google/OAuth/Reporting/CTR, платные AI-сценарии и установленный внешний MCP-клиент. Сборка остаётся preview. Расширение Chrome не разрабатывалось; его E2E исключены по решению пользователя.

Архив содержит исходники без зависимостей, dist, ключей и пользовательских данных. Инструкции безопасного обновления: LOCAL-CHECK-v0.12.42-preview.1.md. Не удаляйте рабочие .env и data.
