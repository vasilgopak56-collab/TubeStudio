# TubeStudio v0.12.46-preview.1 — обновление зависимостей

Это проверочная сборка, не финальный релиз. Основа: v0.12.45-preview.1 с Windows Pre-stop Fix 1.0.1.

## Изменения

- Vite 5.4.21 → 7.3.7; @vitejs/plugin-react → 5.2.0. Переход на Vite 8 не понадобился.
- react-router-dom / react-router → 7.18.5, React остаётся 18.3.1.
- Zod 3.25.76 → 4.6.7 в сервере и MCP; адаптированы типы, словари и значения по умолчанию.
- Транзитивные зависимости: body-parser → 2.4.0, fast-uri → 3.1.9, postcss-selector-parser → 6.1.5.
- При миграции явно сохранено прежнее поведение вложенных настроек/конвейера и необязательных параметров обложки/сценария.
- Частичное обновление календаря не добавляет create-defaults для пропущенных status, format, remindDays. Добавлено семь регрессионных тестов.
- Версии интерфейса, сервера, MCP и manifest резервной копии согласованы. Серверные ответы и backup используют общий APP_VERSION.
- Windows stop-helper 1.0.0 не менялся; исправление pre-stop 1.0.1 сохранено.

## Среда

Node.js: ^20.19.0 либо >=22.12.0; рекомендуется актуальный Node.js 24 LTS. Node.js 24.19.0 из вашего Windows-отчёта подходит. Установка на старом Node.js 20.0 не поддерживается новой сборкой.

Проверки Linux: см. DEPENDENCY-AUDIT-v0.12.46.md и docs/checks/dependencies-v0.12.46.json. Нативная Windows-проверка именно этой версии ещё требуется. Результаты старых релизов в README и PREVIEW-CHECKS — исторические.

## Что не менялось

Форматы пользовательских JSON, логика Reach/CTR, расчёт прибыли, политика ZIP-переноса и доступ MCP не переписывались. Никаких запросов к вашим реальным AI/YouTube аккаунтам при проверках не выполнялось. Расширение Chrome не изменялось и исключено из браузерного прогона.

## Ограничения

Нулевой npm audit означает отсутствие известных предупреждений в использованной базе npm на момент проверки, а не гарантию отсутствия всех уязвимостей. Это не приёмка живых провайдеров. Масштаб CTR по реальному непустому CSV пока не подтверждён. Пустой Reach остаётся «неизвестно», не нулём. Импорт ZIP остаётся нетранзакционным.
