# Похожие каналы / Niche Finder — v0.12.4

## Как пользоваться
1. Откройте **Исследование → Похожие каналы** (`/niches`). Нужен настроенный ключ YouTube Data API. Ключи нейросетей для этого раздела не нужны.
2. Выберите тему либо исходный канал (ссылка, @handle, UC-ID). Можно уточнить тему и в режиме канала. Без неё берутся до трёх ключевых слов канала, иначе — название. Это текстовый поиск, не список рекомендаций YouTube и не семантический поиск.
3. Выберите язык (общий список 18 запрошенных языков + сохранённый польский), до 5/10/20 результатов и 10/20/30/50 последних загрузок на канал. Исходный канал добавляется отдельно и не входит в прокси насыщенности.
4. Выберите тип видео и RPM длинных видео из Настроек. Для коротких используется строка «Shorts». Ставки фиксируются в снимке, поэтому старые результаты не меняются при последующем изменении настроек. Если строки RPM удалены, программа просит восстановить их, не придумывает ставки.
5. Нажмите **Найти похожие каналы**. Задача показывает прогресс; **Остановить** прерывает дальнейшие действия. Уже отправленные запросы могут расходовать квоту. Промежуточные данные не считаются завершённым сравнением.
6. Используйте фильтры и сортировку уже полученной выборки — новых запросов нет. Неизвестные значения исключаются числовыми фильтрами. Скачать JSON экспортирует полный снимок, а не только видимые после фильтрации карточки.
7. Кнопки ведут в анализ канала или добавляют в трекер конкурентов. Добавление выполняется только по явной кнопке и отдельно расходует квоту. Открытие страницы анализа само по себе не запускает новый анализ.

## Что означают показатели
- **Средние / медианные просмотры:** только публичные видео выбранного типа, старше 48 часов и с известными просмотрами. Свежие ролики не тянут среднее вниз. Это выборка последних загрузок, не история канала за всё время. Настоящий ноль остаётся нулём; отсутствие данных — «неизвестно».
- **Частота публикаций:** `(n − 1) × 7 / дни между крайними датами` выбранных видео. Требуются минимум два видео и интервал не менее суток. Не месячный прогноз и не гарантия будущей частоты. Для длинных/коротких расчёт только по выбранному типу в исходной выборке, без добора более старых роликов.
- **Возраст:** время от публичной даты создания канала до снимка, не дата первого опубликованного видео.
- **Последняя загрузка:** возраст наиболее свежей корректно датированной загрузки в общей выборке (до фильтра типа).
- **Совпадение текста:** доля уникальных нормализованных слов запроса, найденных подстрокой в названии/описании канала или названиях его загрузок. Не оценка качества, семантики или официальной похожести.
- **Монетизация:** всегда «неизвестна». Нет проверенного источника статуса участия в партнёрской программе.
- **Условный доход среднего видео:** среднее `просмотры × RPM / 1000` по той же зрелой выборке, отдельно с заданной ставкой для коротких/длинных. Это сценарий при условном RPM, не реальные заработки и не доход за месяц. Если длительность зрелого видео неизвестна, денежный показатель не рассчитывается. RPM — предположение пользователя, не измерение аудитории канала.
- **Насыщенность — прокси:** доля найденных каналов с ≥100 тыс. публичных подписчиков. Рассчитывается только при ≥5 известных значениях и ≥70% покрытия кандидатов. Порог прозрачен, но это не научная оценка конкуренции, размера рынка, спроса или вероятности успеха; результаты зависят от поискового запроса и ранжирования YouTube.
- **Shorts:** приблизительное отнесение по длительности >0 и ≤180 с, не официальный формат. Среди коротких могут оказаться обычные видео. Прямые эфиры и премьеры не выделяются в отдельную категорию.

## Квота, кеш и ошибки
- Одна страница поиска каналов: 100 ед.; метаданные найденных каналов: до 1 ед.; последние загрузки и статистика видео: до 2 ед./канал. Для исходного канала дополнительно разрешается ссылка и собираются его загрузки.
- Показанная до запуска оценка — консервативная `101 + 2 × лимит + (104 в режиме канала)`. Например 121 ед. для темы/10 каналов или 225 для канала/10 результатов. Она не включает повторы/переключения ключей и не является фактическим счётчиком. Кеш и неполная выдача уменьшают расход; повторы могут увеличить.
- Поиск и метаданные кешируются до 6 ч; загрузки — до 12 ч. Переключатель обновления обходит кеш поиска, исходного канала, метаданных и загрузок. Если сохранён старый кеш без отметок доступности просмотров, включите обновление.
- При локальном сбое загрузок конкретного канала сохраняется предупреждение и неизвестные показатели видео. Ошибка ключа/квоты или отмена прерывает задачу и не записывает новый завершённый снимок. Завершённые результаты других запусков не удаляются.
- Поиск ограничен одной страницей и максимум 20 каналами. Это не полный обход всех каналов ниши. Публичная статистика может запаздывать. Язык поиска — подсказка релевантности, не строгий фильтр языка каждого канала.

## Хранение и перенос
Каждый результат — отдельный UUID-файл `DATA_DIR/niche-runs/<id>.json`; общей перезаписываемой таблицы индекса нет. История показывает 50 последних корректных снимков по их дате; более старые файлы остаются на диске и в резервной копии. Открытие истории не вызывает YouTube или LLM.

Каталог входит в общий ZIP экспорт/импорт Настроек. Экспорт отдельного JSON — для чтения в редакторе/других программах, не замена ZIP-восстановлению. Файлы содержат ваши поисковые запросы: не публикуйте их, если они конфиденциальны.

## Код и проверки
- Сервер: `apps/server/src/services/niches.ts`, `routes/niches.ts`, ограниченный helper `searchChannels` в `youtube.ts`.
- Экран: `apps/web/src/pages/Niches.tsx`, типы `features/niches/types.ts`, навигация и встроенная Справка.
- `npm run test:unit`: формулы, неизвестные значения, типы/даты, смешанный RPM, прокси, фальшивый YouTube, кеш/обновление, история, отмена и ошибки ключа.
- `npm run build && npm run test:e2e`: экран, фильтры, JSON, переход/явный трекер, языки, мобильные 390 px, история, ошибки; настоящий локальный маршрут/SSE без ключей. Внешние платные вызовы не выполняются.

## Безопасное обновление
1. Завершите задания. Сделайте резервную копию всей установленной папки; экспорт данных не включает `.env` с ключами, сохраните его отдельно.
2. Распакуйте новый архив отдельно. Скопируйте **содержимое** папки `tubestudio` в существующую папку с заменой программных файлов; не создавайте вложенную папку `tubestudio/tubestudio`.
3. Не удаляйте `.env`, `data`, `apps/server/data` и пользовательские тексты промптов. Если вы меняли файлы промптов из поставки, сохраните их до копирования и верните после него.
4. Запустите `update-windows.bat` и дождитесь успешной установки/сборки. Затем откройте программу через ярлык и обновите страницу (при необходимости Ctrl+F5).
5. Убедитесь, что в меню появился раздел «Похожие каналы». Работа обновления/ярлыка на реальном Windows требует проверки на вашем компьютере; Linux-тесты это не подтверждают.
