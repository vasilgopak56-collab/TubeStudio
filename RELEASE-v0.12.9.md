# TubeStudio v0.12.9 — локальный MCP только для чтения

Первая версия пункта 15 плана. Весь продуктовый план ещё не завершён.

## Что добавлено

- Отдельный workspace `apps/mcp` на официальном MCP SDK, stdio без сетевого порта.
- Пять инструментов: статус, список сохранений, проекция записи, выбранный сценарий, сохранённый транскрипт/summary/remix.
- Шесть категорий с явным разрешением. По умолчанию только проекты и анализы; финансовые снимки требуют отдельного opt-in.
- Минимальные проекции вместо произвольного JSON, ограниченное чтение файлов, UUID вместо путей, отказ от symlink, счётчики неполного сканирования, страницы текста и защита от смешения ревизий.
- Система → MCP-подключение: JSON с фактическими путями, выбор scopes, копирование, состояние сборки, Справка и мобильный экран. Настройка клиента остаётся ручной; найденная сборка не доказывает подключение.
- Корневые build/typecheck включают MCP. Исходники открываются в обычном редакторе; `MCP-README.md` описывает настройку и границы.

## Безопасность и ограничения

Только чтение, без загрузки `.env`, провайдеров, записи, удаления, обновления YouTube, произвольных файлов и переноса generation/write-инструментов старого yt-ideation-mcp. Не HTTP/облачный remote MCP. APP_PASSWORD защищает веб-страницу/служебный API, но не файловый доступ внешнего процесса вашей учётной записи.

Пользовательские тексты/названия не сканируются автоматически на секреты. Разрешённое содержимое получает MCP-клиент и, возможно, его модельный провайдер; подключайте только доверенных клиентов. Scope не ограничивает другие инструменты клиента. Нет реальной приёмки конкретного настольного клиента или Windows, живых API/OAuth/оплачиваемых генераций. Исторические PDF/DOCX v0.11 не пересобраны.

## Обновление Windows

1. Завершите задания и MCP-подключения. Сделайте файловую резервную копию текущей папки TubeStudio при остановленном сервере. Экспорт из Настроек полезен дополнительно, но не включает `.env`.
2. Распакуйте архив отдельно. Скопируйте **содержимое** вложенной папки `tubestudio` в существующую папку программы с заменой файлов. Не создавайте `tubestudio` внутри старой `tubestudio`. Включите новую `apps/mcp` и корневой `package-lock.json`.
3. Не удаляйте `.env`, `data` или настроенную внешнюю `DATA_DIR`, пользовательские промпты. Архив их не содержит. Новых папок пользовательских данных MCP не создаёт.
4. Запустите `update-windows.bat`, дождитесь успешных `npm install` и `npm run build`, затем откройте программу. Результат создания ярлыка проверяйте по сообщению самого обновления; Windows-ярлык этим выпуском заново не проверен.
5. Откройте MCP-подключение, скопируйте конфигурацию в доверенный stdio-клиент и проверьте `ts_status`, список и один сценарий. При переносе программы обновите пути клиента.

Для разработки: `npm install`, `npm run typecheck`, `npm run build`, `npm run test:unit`, `npm run test:e2e`. Тесты используют изолированные искусственные данные. Не запускайте smoke с настоящими ключами без отдельного согласования живой приёмки.

## Проверки выпуска

- Проверка типов всех трёх workspace и production-сборка прошли.
- Все 206 модульных тестов прошли. В том числе 15 новых MCP-проверок: обязательный абсолютный корень, scopes, точные проекции, отсутствие лишних полей, UTF-16/emoji, snapshotToken и неизменность прочитанных файлов, транскрипты, неизвестные метрики, сегменты, паузы, финансовый opt-in, traversal/UUID/повреждённые/большие файлы, symlink, явный предел 5000 файлов, SDK-handshake и отсутствие write-инструментов.
- Все 84 браузерных/интеграционных теста прошли. В том числе 7 новых: настоящий stdio-процесс официального SDK, ограничения/ошибки, отсутствие загрузки .env, веб-конфигурация с фактическими путями, opt-in и пустой выбор без записи, 390 px/Справка, пароль на служебном маршруте и отсутствие MCP HTTP endpoint.
- Проверки выполнялись на синтетических временных данных; реальные ключи, платные провайдеры и Drive-файлы не использовались. Это локальная интеграция и регрессия, не живая приёмка всех сервисов.
- Не проверены установленный у пользователя AI-клиент, Windows-пути/ярлык, живые API и OAuth. Исторические PDF/DOCX v0.11 не пересобраны. Предупреждение Vite о крупном чанке Справки сохраняется; сборка успешна.
