# TubeStudio v0.12.41-preview.1 — калькулятор: приёмка и исправление дробных счётчиков

## Результат
Закрыт локальный браузерный/визуальный пробел калькулятора из .38. Общая сборка остаётся preview: нативная Windows и реальные интеграции здесь не приняты. Это архив исходников, не установщик.

## Исправление
Вставка балансовых ID в другом порядке могла менять младшие биты суммы дробных счётчиков. Сохранение использовало порядок журнала, а проверка v2 — порядок строк основания; собственный новый файл мог не открываться. Регрессионный пример {z:0.1,a:0.2,m:0.3} до исправления воспроизвёл отказ чтения. Теперь агрегат вычисляется по тем же отсортированным строкам основания. Формулы и строгая проверка сохранённых данных сохранены, денежное округление/допуски не добавлены. Старые снимки не перезаписываются и не чинятся по текущим ценам. Уже несогласованные v2 прежних preview автоматически не восстанавливаются.

Также исправлена повреждённая русская фраза «до момента снимка». Уточнены два тестовых ожидания: уникальный селектор сводки и сравнение JSON-основания в Markdown с сохранённым объектом, а не поиск имени обёртки.
