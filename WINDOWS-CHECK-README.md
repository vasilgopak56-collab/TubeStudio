# Проверка установки Windows — v0.12.19

## Безопасное обновление

1. Завершите задания и остановите TubeStudio. Закрытие вкладки браузера не останавливает сервер.
2. Сохраните защищённую резервную копию всей установки, фактической папки данных (включая внешний DATA_DIR, если задан), .env и промптов. Не пересылайте эту копию в чат: она может содержать ключи и OAuth-токены.
3. Распакуйте архив отдельно. Скопируйте **содержимое** папки `tubestudio` в существующую папку, заменяя исходники, а не создавая вложенную установку. Не удаляйте .env и данные. В архиве нет пользовательских данных, ключей, node_modules и dist.
4. Запустите `update-windows.bat`. Он обновляет зависимости и сборку; это уже не read-only операция и требует доступа к npm. Ошибка сборки означает, что обновление не завершено. Ошибка ярлыка отдельно указывается в окне.
5. При необходимости запустите `create-desktop-shortcut.bat` от своего обычного пользователя. В исправленном BAT путь к PowerShell содержит буквальное `\v1.0`, без управляющего символа, который ломал ручное создание ярлыка.
6. Запустите `diagnose-windows.bat`. Скопируйте строки PASS/WARN/FAIL; отчёт сохраняется в `launcher-logs\windows-check.log` или `%TEMP%\TubeStudio-launcher-logs\windows-check.log`.
7. Закройте диагностику и отдельно запустите ярлык, затем повторно при работающем сервере. Проверьте сохранность проектов, правильную версию и отсутствие второго сервера. Это ручная приёмка; диагностический PASS её не заменяет.

## Что проверяется

- Наличие обязательных файлов, корректность UTF-8, отсутствие недопустимых управляющих символов, CRLF для BAT, точный путь PowerShell для установочных BAT. Русские PS1 требуют UTF-8 BOM для Windows PowerShell 5.1.
- Поддержка `--env-file-if-exists` у найденного Node.js — по `node --help`, без загрузки .env. Проверка не использует список разрешённых NODE_OPTIONS: он не равен списку CLI-флагов. Рекомендуется актуальный Node.js 22 LTS или 24 LTS.
- Наличие node_modules и файлов сборки. Это **не** проверка целостности зависимостей или соответствия сборки исходникам.
- Только на Windows: доступная папка рабочего стола, включая перенаправление, и существующий `TubeStudio.lnk`. Проверяются целевой PowerShell, рабочая папка, точная команда запуска и значок. Ярлык другой копии установки считается ошибкой.

Диагностика не создаёт и не сохраняет ярлык, не запускает приложение, браузер, npm или обновление и не вызывает API. Не читает .env, проекты, OAuth и журналы приложения. Запись ограничена собственным диагностическим отчётом. Версия в отчёте — версия package.json исходников, **не** доказательство версии запущенного сервера. Обнаружение имени/команды ярлыка не доказывает его фактический запуск.

## Статусы и коды

- `PASS`: только конкретная перечисленная проверка прошла.
- `WARN`: неполная проверка, например нет сборки или отличается значок. Не означает полной готовности.
- `FAIL`: отсутствующий/неверный файл, неподдерживаемый Node.js, отсутствующий/чужой ярлык или недоступная Windows-проверка.
- Код 0: нет FAIL среди выполненных проверок. WARN всё ещё требует внимания.
- Код 1: есть FAIL или диагностика не завершилась.
- Код 2: режим `--diagnose` выполнялся не на Windows, FAIL нет; рабочий стол и .lnk не проверены.

Для разработчика: `npm run check:windows` выполняет только переносимые проверки файлов. `node scripts/windows-check.mjs --diagnose` добавляет проверку среды и существующего ярлыка; `--report` отдельно включает запись отчёта.

Если PowerShell или COM блокируется политикой, не отключайте защиту. Сохраните текст ошибки. `start-windows.bat` может оставаться способом запуска сервера, но его создание ярлыка также использует PowerShell. Не утверждайте, что весь BAT гарантированно работает при полном запрете PowerShell.

Проверки исходников и синтетических ответов выполнены на Linux. Windows PowerShell, OneDrive, корпоративные политики и настоящий двойной запуск ярлыка требуют проверки на компьютере пользователя. Данные старой установки и её резервная копия в этом выпуске не открывались и не изменялись; сохранность конкретной установки здесь не подтверждена.
