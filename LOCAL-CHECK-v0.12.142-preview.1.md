# Локальная проверка v0.12.142-preview.1

Среда: Linux, Node 24, изолированные временные каталоги и подставные ответы моделей. Реальные платные запросы и пользовательские ключи не применялись.

- Сборка, проверка типов и статическая проверка Windows-файлов — успешны. Статический Windows-check не запускает приложение в Windows.
- Полная модульная регрессия финального кода — 1440 тестов, 0 ошибок.
- Целевые серверные тесты генерации, подтверждений, импорта аудио и восстановления — 27 тестов, 0 ошибок, включая изменение аудио во время ожидания согласия, устаревший предпросмотр, повреждённый журнал и запрет продолжения с записью в проект.
- Настольные тесты аудио, импорта и согласий — 17 тестов, 0 ошибок. Проверено продолжение после перезапуска реального локального тестового сервера, с фиктивным провайдером; готовые библия и первый батч не запрашивались повторно.
- Полная настольная регрессия версии 0.12.142 на момент упаковки ещё выполняется и не заявляется пройденной. Ранее полная настольная регрессия версии 0.12.140 завершилась: 678 тестов, 0 ошибок; это не полная проверка версии 0.12.142.

Ограничения и порядок использования указаны в RELEASE-v0.12.142-preview.1.md. Проверка реальных тарифов, модели и Windows на компьютере пользователя не выполнялась.
