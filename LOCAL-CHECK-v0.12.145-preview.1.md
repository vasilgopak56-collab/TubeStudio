# Локальные проверки v0.12.145-preview.1

Среда: Linux, изолированные каталоги и тестовые данные. Это не приёмка на Windows и не проверка реального платного провайдера.

- TypeScript: проверка серверного, веб- и MCP-пакетов пройдена.
- Production build: сервер, веб-интерфейс и MCP собраны; сборщик предупреждает о крупных веб-бандлах.
- Модульные тесты: 1456 пройдено, ошибок 0.
- Целевые интеграционные/desktop-тесты: 18 пройдено, ошибок 0: мягкая остановка, блокировка данных, получение озвучки, подтверждения и восстановление раскадровки. Провайдеры и данные подставные; это не полный E2E всего приложения.
- Статическая проверка файлов Windows пройдена на Linux. Команды Windows PowerShell, запуск реального приложения, обновление и Windows ACL на Windows не проверены. Дополнительный тест `test-stop-windows.bat` предназначен для отдельной проверки искусственных процессов; см. WINDOWS-STOP-TEST-README.md.
- Тесты мягкой остановки проверяют неправильный токен, незавершённый HTTP-запрос, активное задание, освобождение блокировки и повторный запуск. Отказ исключает принудительное завершение. Часть других фоновых процессов может не учитываться.
- Реальные платные AI-запросы, списания и восстановление пользовательских данных не проверялись. Подробный порядок перехода и ограничения: RELEASE-v0.12.145-preview.1.md.
