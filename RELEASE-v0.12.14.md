# TubeStudio v0.12.14

## v0.12.14 — панель сохранённых своих каналов

Моя аналитика → **Каналы**: явный запрос дневной сводки views / estimatedMinutesWatched / subscribersGained / subscribersLost, отдельные неизменяемые снимки и локальная панель. На каждый ID канала — один последний снимок за **точный выбранный период**. Покрытие дней и дата сохранения видны отдельно; неизвестные значения не подменяются нулями. Нет общего итога или рейтинга каналов.

Можно последовательно выбрать другой канал в Google; успешный вход заменяет единственное активное подключение, сохранённые снимки остаются. Несколько одновременных OAuth-подключений и массовое автообновление не добавлены. Финансовые права дополнительно не запрашиваются; Google может сохранить ранее выданные разрешения.

Markdown/JSON открытого снимка и прочитанной панели, история 50, каталог 100 периодов плюс ручной точный период, общий ZIP-перенос. MCP и токен Chrome не получают доступ к новым приватным снимкам. Другие отчёты автоматически не импортируются в панель. Подробности: CHANNELS-README.md, RELEASE-v0.12.14.md.

Пункт 12 и весь план ещё не закрыты: остаются автоматические показы/CTR/результаты A/B, одновременные подключения и живая приёмка. Исторические PDF/DOCX v0.11 не пересобраны.

## Обновление
Завершите задания, сохраните резервную копию. Остановите сервер; скопируйте содержимое папки tubestudio из архива в существующую папку программы с заменой исходников. Не создавайте лишнюю вложенную папку, не удаляйте .env и локальные данные. Запустите update-windows.bat, дождитесь успешной сборки и обновите вкладку Ctrl+F5. Node.js нужен, node_modules и готовые dist в архив исходников не входят. Расширение Chrome остаётся 1.1.0; этот выпуск не меняет его файлы.

## Проверки
- Проверка типов всех трёх workspace и production-сборка прошли.
- Все 301 модульный тест прошли, включая 23 новых для панели: строгие даты/поля/схемы, named-column projection, нули/неизвестность/переполнение, знаковая разность подписок, дубли/повреждённые дни, предел 366, покрытие, UUID/суммы/версии/размеры/ссылки, один последний снимок на ID и точный период, однозначный порядок, предел 50 каналов, история 50 без усечения панели, каталог 100 с ручным старым периодом, повреждённые файлы без удаления, backup, отсутствие подключения/будущие даты до сети, фиксированный базовый запрос/0600/неизменяемость, отказ/смена/refresh-гонка OAuth, выбор аккаунта/отмена и сохранённый безопасный Markdown, предел сканирования 5000.
- Все 126 браузерных/интеграционных тестов прошли. Включая 9 новых для вкладки Каналы: ручной запрос без автозагрузки сводки, старый неизвестный базовый scope, безопасный Unicode/покрытие, подтверждение/отмена выбора аккаунта и настоящий локальный callback со сменой канала, два канала с одинаковыми названиями и выбор последнего точного периода, закреплённые JSON/Markdown, применение периода только по кнопке, локальное чтение/история/обновление, ошибки без потери снимка, пустые/нулевые/неполные ответы, HTTP-схемы/лимиты, пароль и запрет Chrome-токена, мобильные 390 px/Справка и настоящий ZIP export → import с сохранением UUID панели.
- Новые тесты выполнялись на временных искусственных данных; внешние запросы сервера блокировались тестовой фикстурой. Реальные ключи и Drive-файлы не использовались. Мобильный снимок просмотрен, горизонтальное переполнение страницы проверено автоматически; широкие таблицы прокручиваются внутри карточек.
- Не проверены живой OAuth/реальная статистика канала, Windows/ярлык, установленное MV3 и платные провайдеры. Это локальная регрессия, не живая приёмка всей программы. Исторические PDF/DOCX v0.11 не пересобраны. Предупреждение Vite о крупном чанке Справки не мешает успешной сборке.
