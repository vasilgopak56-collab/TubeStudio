## Запуск
**Ярлык Windows:** автоматически создаётся/обновляется после успешной установки через `start-windows.bat` и обновления через `update-windows.bat`. Он указывает на папку, из которой запущена установка; ярлык с тем же именем заменяется. Для ручного пересоздания запустите `create-desktop-shortcut.bat` из папки программы. На рабочем столе появится TubeStudio с фирменной иконкой. Двойной щелчок запускает сервер в фоне и открывает браузер после готовности; если сервер уже работает, открывается только браузер. Node.js по-прежнему нужен. При первом запуске без зависимостей/сборки откроется обычное окно установки. Журналы фонового запуска — `launcher-logs/`. Закрытие браузера не останавливает сервер; он работает до завершения процесса Node.js или перезагрузки Windows. После перемещения папки пересоздайте ярлык. Обновление ярлыка не меняет `.env` и данные, включая подключение YouTube.

**В один клик:** Windows — `start-windows.bat`, macOS/Linux — `start-mac.command` (ставит зависимости, собирает, запускает, открывает браузер). Ключи вставляются в **Настройки → карандаш** (пишутся в `.env`, применяются без перезапуска).

Вручную:
```bash
cp .env.example .env      # вписать ключи
npm install
npm run dev               # web: http://localhost:5173, api: http://127.0.0.1:8787
# продакшен
npm run build && npm start   # всё на http://127.0.0.1:8787
```
Нужен Node 20+ (ffmpeg понадобится с этапа 5 — озвучка).

### Этап 7 — Обложки (`/thumbnail`)
- **AI-генерация:** 9 шагов (стиль, персонаж с фото «Мой персонаж» в IndexedDB, эмоция, одежда, композиция, палитра с образцами, свет/FX, текст и место), у каждого «Пропустить» и «Пусть решит AI».

- **Polish Studio** (WebGL, офлайн): 5 пресетов, Свет/Цвет/Детали/Эффекты/HSL 8×3, «Удерживайте для сравнения», сброс, экспорт 1280×720 JPG ≤ 2 МБ / PNG, «Сохранить изменения» (в проект).

### База знаний YT-Genius (14 скиллов) + Humanizer
Что взято и куда встроено:
- **Живой голос** (`/check/humanizer`, метод Humanizer github.com/blader/humanizer + `human-voice.md`). Два уровня, как рекомендует KB:
  1) *при написании* — правила §1–§26 и T1–T11 в системном промпте Сценариста;
  2) *отдельная проверка* — детерминированный детектор (`services/humanVoice.ts`: словари RU/EN, структурные признаки, TTS-правила, сила ●●●/●●/●) → оценка `100 − 5 × штраф на 100 слов` (порог 85) → LLM-правка проблемных сцен по 4 шагам (`prompts/humanizer/rewrite.md`) → сверка фактов (числа, «цитаты», имена) и меток `[[SCENE n]]`/`[IMAGE n]`/`[VISUAL CUE]`, длина сцены ±15% → до 3 проходов. Правка отклоняется, если добавлены числа, изменены цитаты, сдвинуты метки, вышла длина или упала оценка. UI: живая оценка без LLM с подсветкой правил, «было → стало» по сценам (пословный diff), принять/отклонить, [FACT-CHECK], «оставлено намеренно», отчёт в формате KB, голос автора по образцу.
  Сценарист по умолчанию делает автопроход (±6% на акт, объём сохраняется), бейдж «живой голос 78 → 92». Из AI-детектора — кнопка «Очеловечить».
- **Сценарист** (`yt-script-architect`): 10 законов, распределение хук 5–8% / завязка 15–20% / эскалация 30–35% / поворот 20–25% / кульминация 10–15% / смысл 8–12%, хук в три удара (образ → противоречие → вопрос), ре-хуки каждые 30–90 с, журнал петель, [FACT-CHECK]-список утверждений, библиотека структур **S1–S20** (`prompts/script/structures.md`, выбор «Авто» или вручную). Темп по KB: RU 120, EN 150, DE 118, ES/PT 150 сл/мин.
- **Оценка сценария** (`yt-quality-gates`): тест «гениальности» — 10 критериев 0–10, порог публикации: среднее ≥ 8 и ни одного < 6.
- **Поиск тем** (`yt-idea-engine`): 22 линзы оригинальности (L1–L22), эмоциональное ядро, скоринг-карта 100 баллов (9 критериев × вес; ≥85 — делать немедленно) — входит в итоговую оценку вместе с реальными outlier-данными YouTube.
- **SEO** (`yt-packaging`/`title-archetypes`): 5 разных архетипов заголовков, важное в первых 40 символах, без недоказанных «самый/первый».
- **Раскадровка** (`yt-visual-director`): 18 визуальных пресетов P1–P18 (`prompts/visual/presets.md`) поверх стиля ниши.
- Словарь AI-маркеров AI-детектора расширен по `human-voice.md`; в отчёте детектора — оценка живого голоса.

### Исследование как во vidIQ (`/research`, `/keywords`, `/competitors`)

### Дайджест, комментарии, оценка перед публикацией, расширение Chrome
- **Дайджест конкурентов** (`services/digest.ts`): хиты трекера за N дней (сортировка по Outlier, затем VPH) → 1 вызов LLM: почему сработало, закономерности, темы-ответы, чего избегать. Авто раз в `digestDays` (`research.competitors.digestAuto`, по умолчанию выкл.) из планировщика конкурентов. Хранение — `data/digests.json` (30 шт.). Квоту YouTube не тратит.
- **Анализ комментариев** (`/comments`, `services/comments.ts`): `commentThreads.list` (1 ед./100), видео или канал (N самых обсуждаемых из 20 последних), до ~45 тыс. символов топ-комментариев → LLM: тональность, аудитория, просят/хвалят/ругают (доли + цитаты), вопросы, споры, идеи, подсказки для сценария. `data/comment-runs/`.

Опционально `analyzeKeyword` (≈ 102 ед.). `data/scorecards/`.

- **Shorts** (`services/shorts.ts`): LLM → 1–5 самодостаточных Shorts (title, hook, script 75–130 слов, onScreen, cta, quote, why, hashtags); опционально TTS и вертикальный черновик на каждый. Артефакт `shorts`.
