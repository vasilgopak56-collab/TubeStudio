## Итог разбора
- **Ядро — YT-Genius-KB** (14 навыков на русском). Это уже переработанная версия Skills.pdf: путь от темы до публикации, поиск идей, оценка идей, проверка фактов, сценарий, удержание, проверки качества. На этом строится «мозг» TubeStudio.
- **Для G-Labs и Google Flow берём:** гайд по Gemini Omni, систему промптов Nano Banana, формулу Veo 3.1, листы персонажей, словарь движений камеры, эмоции персонажа (AI Actor), паспорт кадра (картинка → JSON) и разбор видео-донора через Gemini.
- **Уже есть в TubeStudio:** библиотека из 40 стилей (22 Studio + P1–P18) и стиль 2D POV History.
- **Не подходит:** всё, что сделано под Seedance, Higgsfield и Vidu, а также реклама и «говорящие головы». Этих генераторов нет в G-Labs, а форматы не ваши. Эти файлы оставлены как справочные.
- **Чего в Библиотеке не было, добавлено от себя:** Радар «Идеи для канала» (новые форматы, которые обгоняют свой канал), озвучка через Lumean с субтитрами и таймингами слов, сцены под длину клипов Flow/Veo (до 8 с), роли моделей в AnyModel, выгрузка в G-Labs (полуавтомат на BASIC, полный автомат через Webhook на MAX).

## Решения приняты 04.11.2026
1. ✅ **Оговорки:** не больше 1 примерно на 2 минуты озвучки, остальная проверка фактов — в отчёте TubeStudio. [Бюджет оговорок в тексте](cards/100.md)
2. ✅ **Громкость:** весь ролик −14 LUFS, музыка под голосом притихает автоматически. [Звук и громкость](cards/310.md)
3. ✅ **Длина сцены:** фраза озвучки на 4–8 секунд под клип Flow/Veo. «Ритм» для документалок, «Предложение» для быстрых 2D-каналов. [Нарезка сценария на сцены](cards/200.md)
4. ✅ **Поиск идей как на вашем скриншоте:** делаем, это Радар Выпуска 1. [Идеи для канала: новые форматы, которые обгоняют свой канал](cards/045.md)
## Что ещё нужно от вас
1. **Lumean:** создать ключ (полный набор прав «full»), вставить его в TubeStudio → Настройки и выбрать голос для каждого канала. [Озвучка через Lumean: автоматически, с субтитрами и таймингами](cards/190.md)
2. **G-Labs (план MAX):** во вкладке Webhook нажать Start (или включить Auto-start) и вставить API key в TubeStudio → Настройки → Ключи API → G-Labs. Скриншоты больше не нужны: в 2.0.0 всё идёт через Webhook. [Выгрузка промптов в G-Labs и импорт результатов](cards/270.md)
3. **Ваши каналы:** ниша, язык, длина роликов и ссылки. Образец SquireExplains уже разобран. [Профиль канала и бренд-кит](cards/020.md)
4. **AnyModel:** пополнить баланс, сейчас \$0,54. [Модели для текста в AnyModel](cards/170.md)
## Как пользоваться
- В виде «Все карточки» карточки идут по шагам работы над роликом. Вид «По выпускам» показывает, что войдёт в каждый выпуск.
- Вид «Ждут вашего ответа» собирает карточки, где нужно ваше решение или ваши скриншоты.
- В «Источниках Библиотеки» у каждого файла есть вердикт, причина и путь в архиве.
