Нужно для сюжетных роликов с крупными планами. Для плоских стилей и безликих персонажей хватает микродвижений позы.
### Логика
1. **Не называть эмоцию.** «Она грустит» ничего не даёт. «Нижние веки блестят — влага, но не слёзы» даёт грусть.
2. **Всё в числах:** 1 мм, 35% радужки, раз в секунду, 0,3 секунды.
3. **Дуга:** сдержанность → срыв → восстановление. Эмоция, которую скрывают, читается как правда.
4. **Сдержанность усиливает.** Улыбка, убранная за 0,1 секунды, сильнее показанной.
5. **Сначала физиология** (зрачки, дыхание, глоток), потом жест.
6. **Тишина:** без музыки, диалога и титров.
### Длительность
3–5 с — две фазы (сдержанность и срыв) · 8–12 с — полная дуга · 15 с — полная дуга с медленной первой фазой.
### Шаблон
```plain text
SHOT: [ECU / MCU / CU] — [эмоция] ([длительность]s)
CAMERA: static locked-off or handheld with natural breathing, telephoto shallow depth of field. The camera never pushes in; it waits.
CHARACTER: [кто + один предмет, в который уходит дрожь]
PHASE 1 — SUPPRESSION: [исходная поза] → [глаза] → [брови] → [губы] → [глоток или вдох]
PHASE 2 — THE CRACK: [дыхание] → [взгляд уходит и возвращается] → [блеск у век] → [дрожь в руке или предмете]
PHASE 3 — RECOVERY: [глубокий вдох] → [взгляд твёрдый] → [веко опускается на ~35%] → [последний жест]
END BEAT: [на чём держится кадр]
SOUND: No music. No voices. [дыхание + один фоновый звук]
```
В источнике 13 готовых рецептов: сдержанное горе, тайная радость, обида, онемение, усталость, сдержанный страх, сдержанный гнев, тихое неповиновение, тоска, стыд, облегчение, решимость, скрытая боль любви.
