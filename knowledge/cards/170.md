### Риски AnyModel
AnyModel — посредник. Он может быть недоступен, поменять цены или видеть ваши тексты. Поэтому:
- держим запасных провайдеров: AI API Lumean (тот же ключ, что и для озвучки) и бесплатный уровень Gemini API (ключ у вас уже есть). На бесплатном уровне Google может использовать тексты для улучшения своих моделей, поэтому туда идёт только публичное, например разбор чужих роликов;
- не отправляем туда личные данные и ключи;
- в TubeStudio жёсткий лимит \$20 в месяц: счётчик по каждой модели и остановка при достижении лимита.
