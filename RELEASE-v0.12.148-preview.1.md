# TubeStudio v0.12.148-preview.1 — защита локального сервера от запросов чужих страниц

## Исправлено

В изолированном тесте .147 без APP_PASSWORD страница на другом origin отправила обычную HTML-форму на `/api/system/cache/clear`: сервер ответил 200 и удалил тестовый кэш. Запрет на чтение ответа в браузере сам по себе не предотвращает выполнение команды. Другие доступные команды также необходимо рассматривать как потенциально опасные; конкретные внешние платные вызовы в этом эксперименте не запускались.

В .148 до обработчиков проверяются Host и, для `/api` и `/files`, браузерные Origin и Fetch Metadata. Отклонённые запросы получают 403. Только адреса `localhost`, `127.0.0.1`, `[::1]` с допустимым портом разрешены в Host; несоответствие адреса абсолютного запроса и Host также блокируется. `Forwarded` и `X-Forwarded-*` не считаются подтверждением происхождения. Имена хостов нормализуются стандартным URL-парсером; проверка относится к локальному HTTP-серверу, а не к произвольному развёртыванию.

Google OAuth: GET `/api/yt-oauth/callback` допускает возврат из другого origin, но по-прежнему требует действительный одноразовый ограниченный по времени state. Для Chrome extension разрешены только GET `/api/ext/ping`, GET `/api/ext/videos`, POST `/api/saved-topics` с корректным форматом `chrome-extension://…`; когда задан APP_PASSWORD, обычная проверка токена расширения остаётся обязательной. Это исключение **не устанавливает подлинность расширения**. При отсутствии Origin и Fetch Metadata локальные инструменты по-прежнему допускаются; отсутствие этих заголовков не является подтверждением доверия.

## Важные ограничения

- Это дополнительная защита браузерного происхождения, не межсетевой экран и не полноценная аутентификация. Вредоносные локальные приложения, другие расширения с необходимыми разрешениями, XSS на самом origin, старые браузеры, клиенты или прокси без заголовков могут её обойти. Задайте APP_PASSWORD и не устанавливайте недоверенные расширения; пароль не решает все угрозы.
- Не предоставляйте серверу доступ из интернета или локальной сети. В .148 удалённые имена, LAN-адреса, домены и внешние reverse proxy не поддерживаются и блокируются. Открывайте приложение по `http://127.0.0.1:8787` либо по локальному адресу, показанному запускающей программой. Работу через локальный Vite проверили отдельно. Если вам нужен удалённый доступ, его необходимо отдельно проектировать и защищать, а не обходить эту проверку.
- Проверки Chrome extension здесь синтетические, реальное MV3-расширение и текущий YouTube не тестировались; возможно, оно потребует отдельной адаптации. Реальный вход Google/OAuth и AnyModel не проверялись. Состояние одного платного запроса может оставаться неизвестным после обрыва; защита происхождения не является лимитом расходов.
- Автотест в Linux и локальный Chromium не заменяют приёмку на вашей Windows и в вашем браузере. Если перестал работать локальный интерфейс или расширение, не отключайте защиту: сообщите адрес и текст ошибки без ключей, токенов, паролей, содержимого проектов и сырых логов.

## Перед обновлением

1. Завершите операции и проверьте исход незавершённых платных запросов. На старой версии по возможности не открывайте неизвестные страницы при работающем TubeStudio.
2. До замены программных файлов остановите **старый** сервер. Не запускайте одновременно вторую копию; если остановка не подтверждена, не продолжайте обновление и не удаляйте блокировку данных. См. RELEASE-v0.12.144-preview.1.md и RELEASE-v0.12.147-preview.1.md.
3. Сохраните отдельную приватную резервную копию фактической папки DATA_DIR и пользовательских промптов; `.env` сохраните отдельно. Не подменяйте ваши данные пустыми данными архива. Оставьте старую версию до проверки новой.
4. До перехода завершите или сохраните JSON незавершённых попыток аудиораскадровки: попытки .147 и старше в .148 доступны только для ручного экспорта. Новый запуск может стоить денег.
5. Обновите программные файлы, запустите одну копию и проверьте версию, свои проекты и настройки. Не передавайте никому `.env`, токены и приватные резервные копии.
