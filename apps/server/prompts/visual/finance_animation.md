BRAND KIT CREATION -



Create a complete, dense Brand Identity System Document for a financial storytelling
YouTube channel named "Money Tales". The channel targets millennials using an authentic,
imperfect, traditionally animated 2D hand-drawn cartoon style.

The primary purpose of this document is to lock down the visual rules so that future assets
feel human-made, textured, and consistent across individual, single-frame scene
generations—whether a scene includes a character mascot or focuses entirely on an
environment or a conceptual object.

Apply the following architectural identity system to the layout:

1. THE AUTHENTIC HAND-DRAWN ART STYLE DIRECTIVE
- Visual Style: 2D traditional hand-drawn cartoon illustration with an organic, visible marker
line-wobble and intentional human imperfections. Outlines must be variable-weight, solid
ink-black (#111111), featuring slightly unjoined corners and raw pen-stroke textures.
- Shading & Textures: Completely flat, slightly uneven color fills that mimic manual marker or
gouache layers. Shading is achieved using classic, hand-stippled dot arrays or simple
parallel diagonal ink sketch lines. Absolutely no smooth digital airbrushing, no perfect
computer gradients, and no 3D rendering.
- Scene Diversity: Visual layouts must function both with and without the character mascot.
Scenes alternate between character actions (e.g., at home, at a bank counter) and pure
conceptual environments/objects (e.g., a hand-drawn money vault, an imperfectly sketched
scales of balance). No text captions or text subtitles are allowed within the actual scene
graphics.

2. THE BALANCED COLOR PALETTE
- Core Tone: Bright and engaging without being overly saturated or neon. Colors must feel
like a premium, hand-picked ink set.
- Base Canvas: Pristine White (#FFFFFF) or ultra-light textured sketchbook cream.
- Scenic & Element Fills: A balanced, multi-color cartoon system using friendly, rich tones:
warm ochre yellow, deep terracotta, soft denim blue, and organic sage green. Colors should
be applied as flat blocks with organic boundaries.

3. TYPOGRAPHY SYSTEM
- Headline Font: A clean, high-contrast, bold geometric sans-serif typeface (like Poppins
Bold or similar) that looks crisp against hand-drawn lines.
- Secondary/Data Font: An uncomplex, highly legible sans-serif font (like Inter Regular) for
numeric data visualizations or graphic text layouts.
- Implementation Rule: The graphic text must be clean, minimal, and modern. Do not clutter
the scene composition; text layers should look integrated and leave generous negative
space around the artwork.
